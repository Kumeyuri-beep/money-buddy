# เรียนรู้: หน้ารายการ บิล และเปลี่ยนรหัสผ่านสำหรับผู้ใช้ใหม่

**ทำอะไร:** (1) หน้ารายรับ-รายจ่าย: สรุปยอดอยู่บนพื้นทึบ (ตัวแดง/เขียวเล็กต้องผ่านคอนทราสต์ ไม่วางบนแสงฉากหลัง) และมี + / − หน้ายอด · ตัวกรองบนมือถือกินที่น้อยลง (ค้นหา+เดือนเต็มแถว ประเภท+กระเป๋าคู่กัน) · ตัวอย่างค้นหาไม่ใช้ "CashFlow" (2) บิลแสดงรอบเป็น "พฤศจิกายน 2569" แทน "2026-11" (3) หน้าบังคับเปลี่ยนรหัสผ่านครั้งแรก ช่องรหัสเดิมเรียก "รหัสผ่านชั่วคราวที่ได้รับ" ผู้ใช้ใหม่จะรู้ว่าคือรหัสที่เพื่อนให้มา

**ทำไม:** ผลสำรวจผู้ใช้ใหม่บนมือถือ

**ข้อผิดพลาดที่จับได้ระหว่างทำ:** ครั้งแรกจัดตัวกรองเดือน+ประเภทคู่กัน ภาพ 360px แสดงชื่อเดือนถูกตัด ("พฤศจิกายน 2") จึงเปลี่ยนให้เดือนเต็มแถว — เหตุผลที่ต้องดูภาพจริง ไม่ใช่เดาจากโค้ด

**ทดสอบอย่างไร:** เทสต์ซอร์ส + ภาพ 360px
