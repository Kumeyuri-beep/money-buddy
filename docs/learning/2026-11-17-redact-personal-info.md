# ตัดข้อมูลส่วนตัวออกจากเอกสารก่อนเปิด repo เป็น public (17 พ.ย. 2569)

**ทำอะไร:** เอาชื่อเล่น ชื่อผู้ใช้ Windows และ path เต็มของไฟล์ key ผู้ดูแลออกจากเอกสาร ใส่คำกลางๆ แทน (`<admin-env-path>`, `<project-path>`) · กฎกันอ่านโฟลเดอร์ key ใน `.claude/settings.json` เปลี่ยนจาก path ที่มีชื่อผู้ใช้เป็นแบบใช้ `*` แทนชื่อ (ยังกันเหมือนเดิม) · เทสต์ `adminScripts.test.ts` ใช้ชื่อสมมติ `tester` · เพิ่ม `.gitleaksignore` ระบุ 9 ค่าที่เครื่องสแกนเตือนแต่เป็นข้อมูลปลอมในเทสต์

**ทำไม:** เตรียมเปิด repo เป็น public จึงไม่อยากให้คนนอกเห็นชื่อเล่น ชื่อบนเครื่อง และที่เก็บไฟล์ secret

**ไม่ได้ทำ:** ไม่แก้ประวัติ commit เก่า (ชื่อเหล่านี้ยังอยู่ใน commit เก่า) · ตั้งอีเมล author ของ repo นี้เป็น noreply ของ GitHub แล้ว (มีผลเฉพาะ commit ใหม่)

**ทดสอบ:** `npm test` ผ่านหมด · `git grep` หาชื่อเล่น/ชื่อผู้ใช้ Windows ใน HEAD ไม่พบ · gitleaks สแกนทุก branch ทุก commit: ไม่พบ secret
