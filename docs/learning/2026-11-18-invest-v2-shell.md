# Invest v2 PR-1: โครงเมนู + ปุ่มสกุล (R26)

**ทำอะไร**
- เมนู Tools เหลือ 4 รายการ (เอา Portfolio Lab ออก) และ "Dividend payout calendar" เป็นลิงก์ภายนอก เปิดแท็บใหม่ มีไอคอน ↗ และ `rel="noopener noreferrer"` (ไม่ใช่หน้าของแอป จึงไม่มี route)
- My goal ในเมนู Portfolio เป็นหน้าของโหมดนี้ (ตอนนี้ Coming soon · จะทำในคลื่น 2) ไม่ใช่ปุ่มไปแผนเกษียณแล้ว
- ปุ่ม $ USD / ฿ THB: ค่าเริ่มต้น USD และจำค่าต่อผู้ใช้ในค่า `portfolioCurrency` เดิม (ไม่ต้อง migration)
- เอาชื่อพอร์ต/คำอธิบายใต้แถบบนออก (ชื่อพอร์ตยังอยู่ที่ปุ่มเมนูพอร์ตมุมขวา) · เหลือป้าย "Updated ..." ชิดขวา
- เพิ่มโมดูล `displayCurrency.ts` (กฎ R26): แปลงเซนต์↔สตางค์ครั้งเดียวต่อค่า ปัดครึ่งออกจากศูนย์ ไม่มีเรต = null (ไม่เดา) ผลรวมตาราง = ผลบวกของค่าที่แปลงแล้ว
- แยกไฟล์หน้า (`src/ui/invest/pages/*`) ให้ worker แทนที่ทีละหน้าได้โดยไม่ชนกัน

**ทำไม:** เจ้าของอนุมัติแบบร่าง v2 รอบ 1 (18 พ.ย. 2569) · ต้องมีฐานกลางก่อนให้ worker ทำหน้าอื่นขนานกัน

**ทดสอบอย่างไร:** เทสต์หน่วยของ `displayCurrency` (ตัวอย่างมือ 5,000 บาท ที่ 32.40 = 15,432 เซนต์ · ปัดครึ่ง · ติดลบ · เรตผิด · ใกล้ 2^53) · เทสต์เมนู (ลิงก์ภายนอก ไม่มีลิงก์เสีย) · Playwright 1280/1440/360/390 ทั้งชุด

**เรื่องที่ต้องรู้:** ตัวอย่างมือในกฎ R26 เขียนผิดเป็น 236,982 สตางค์ ที่ถูกคือ 7,315 เซนต์ × 32.40 = **237,006** (เทสต์ใช้ค่าที่ถูก) · รอเจ้าของอนุมัติให้แก้ตัวเลขใน `docs/money-rules.md`
