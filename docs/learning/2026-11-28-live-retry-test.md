# ทดสอบปุ่มลองใหม่กับฐานข้อมูลจริง (28 พ.ย. 2569)

## ทำอะไร
เพิ่มข้อทดสอบใน `tests/live/investRls.live.ts`: นำเข้าสมุดบัญชี → ตรวจว่าข้อมูลลงทุน "ยังไม่เข้า" → ลองเฉพาะขั้นลงทุน → ตรวจว่า "ตรง" → ลองซ้ำถูกปฏิเสธ

## ทำไม
เดิมทดสอบด้วยฐานข้อมูลจำลองเท่านั้น การเทียบข้อมูลจากฐานข้อมูลจริง (เช่น รูปแบบเวลา) ยังไม่เคยพิสูจน์

## ทดสอบอย่างไร
`MONEY_BUDDY_LIVE_TESTS=yes npm run admin:live-contract` (ใช้ผู้ใช้ทดสอบเท่านั้น)
