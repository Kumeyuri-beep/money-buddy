# สรุปการเรียนรู้: ปุ่ม Export CSV ในหน้า Holdings (20 พ.ย. 2569)

- **ทำอะไร:** ปุ่ม Export CSV ส่งออกตารางที่เห็น (แท็บปัจจุบัน แถวที่กรองแล้ว + แถวรวม) เป็นไฟล์ในเครื่อง
- **ทำไม:** เจ้าของเลือกจากตารางความต่างจากแบบร่าง 20 (ข้อ 5)
- **ข้อควรรู้:** ใช้ตัวช่วยของ Report ร่วมกัน (`csvText` กัน formula injection, `minorToDecimal` แปลงหน่วยย่อยเป็นทศนิยมไม่ผ่าน float) · ค่าที่ไม่มีราคา/เรตเป็นช่องว่าง ไม่ใช่ 0 · ปุ่มแสดงเฉพาะคอม (มือถือจดไว้ใน HANDOFF "รอปรับมือถือ")
- **ทดสอบ:** vitest `investHoldingsCsv` (8 เทสต์ ตัวเลขตรงตัวอย่างมือ R24) · Playwright ดาวน์โหลดจริงและตรวจเนื้อหา
