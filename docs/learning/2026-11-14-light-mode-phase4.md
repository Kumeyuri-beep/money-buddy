# โหมดสว่าง เฟส 4: เทสต์ตรวจสีตัวหนังสือทุกหน้า ทั้งสองโหมด

## ทำอะไร
- ไฟล์ใหม่ `tests/e2e/contrast.spec.ts` เปิดทุกหน้า (8 หน้า) + เมนู pop up + dialog เพิ่มรายการ/เพิ่มบิล ที่ 360/390/1280 ทั้งโหมดมืดและสว่าง (58 เทสต์)
- วิธีวัด: ซ่อนสีตัวหนังสือทั้งหน้า → ถ่ายภาพ → วัดสีพื้นหลังจริงใต้ตัวหนังสือทุกตัว (รวมกระจก ไล่เฉด ก้อนแสง) → เทียบกับสีตัวหนังสือด้วยสูตร WCAG · เกณฑ์ 4.5:1 (ตัวใหญ่ 3:1)
- ไม่นับปุ่มที่ปิดใช้งาน (WCAG ยกเว้น) และข้อความที่ถูกบัง
- มีเทสต์ควบคุม: ใส่ตัวหนังสือจาง/ตัวหนังสือสีเดียวกับพื้นเข้าไปในหน้า แล้วตัวตรวจต้องจับได้ (กันเทสต์ผ่านเพราะตรวจไม่เจอ)

## ทำไม
เทสต์ contrast ฝั่งหน่วย (เฟส 2) ตรวจจากค่าสี token แต่ไม่เห็นหน้าจริง เฟสนี้ตรวจจากภาพที่เรนเดอร์จริง ถ้ามีใครแก้ CSS แล้วตัวหนังสือจางหรือมองไม่เห็นในโหมดใดโหมดหนึ่ง CI จะล้ม

## บทเรียนระหว่างทำ
ครั้งแรกเทสต์ล้มเพราะปุ่มเมนูทองลอยบนมือถือบังตัวหนังสือบางส่วนตอนเลื่อน เทสต์จึงอ่านสีพื้นผิด (ไม่ใช่ตัวหนังสืออ่านไม่ออกจริง) แก้ด้วยการข้ามข้อความที่ถูกบังที่ 5 จุดแล้วรอตรวจตอนเลื่อนถึงช่วงที่ไม่ถูกบัง
