# สรุปการเรียนรู้: แยก latestFxRate ออกจากโมดูลสมุดบัญชี (20 พ.ย. 2569)

- **ทำอะไร:** ย้ายฟังก์ชัน `latestFxRate` ไปไฟล์ `fxRate.ts` (ไม่เปลี่ยนพฤติกรรม) `metrics.ts` และ `reportSeries.ts` import จากไฟล์ใหม่ · `portfolioMoney.ts` ส่งออกซ้ำให้ผู้เรียกเดิม
- **ทำไม:** `portfolioMoney.ts` import สมุดบัญชี ทำให้ไฟล์คิดผลตอบแทนผูกกับโมดูลที่แตะเงินสดทางอ้อม (R25.3-R25.4 ผลตอบแทนไม่รวมเงินสด)
- **ทดสอบ:** เทสต์ใหม่ `investReturnsImports` ไล่สายนำเข้าของ metrics/twr/reportSeries/reportRows ต้องไม่เจอโมดูลสมุดบัญชี/เงินสด (ลองใส่ import เดิมกลับแล้วล้มจริง) · เทสต์เดิมทั้งหมดผ่าน
