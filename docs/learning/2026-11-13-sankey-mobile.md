# เรียนรู้: กราฟ Cash Flow บนมือถือ

**ทำอะไร:** แผนภาพ Sankey ต้องกว้างอย่างน้อย 640px บนจอ 360px จึงเห็นครึ่งเดียวและตัวหนังสือถูกตัด · บนมือถือ (≤720px) ซ่อนแผนภาพ แล้วโชว์ตารางข้อมูลชุดเดียวกัน (ที่เดิมซ่อนไว้ให้โปรแกรมอ่านจอ) เป็นรายการ "แหล่งเงิน/ปลายทาง · ชื่อ · จำนวนเงิน · สัดส่วน" ที่อ่านได้ทันที · จอใหญ่เหมือนเดิม

**ทำไม:** ผลสำรวจ design-critic ว่า Sankey บนมือถือต้องเลื่อนแนวนอนและแป้นพิมพ์เลื่อนไม่ได้

**ทดสอบอย่างไร:** ถ่ายภาพ 360px (ไม่มีแถบเลื่อนแนวนอน อ่านตัวเลขได้ครบ) · เทสต์ตรวจ role/CSS · ไม่เปลี่ยนตัวเลขหรือสูตร
