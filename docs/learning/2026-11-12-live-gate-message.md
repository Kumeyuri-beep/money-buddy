# เรียนรู้: ทำไมข้อความ error หาย
- ชุดทดสอบจริงมี "สวิตช์" `MONEY_BUDDY_LIVE_TESTS=yes` กันรันโดยไม่ตั้งใจ เพราะมันสร้าง/ลบผู้ใช้บนฐานข้อมูลจริง
- เดิมถ้าลืมตั้งสวิตช์ โค้ดจะ throw แต่ตัวพิมพ์ error ของ vitest บน Node v26 พังเอง เลยเห็นแค่ "No test files found" ทำให้เดาสาเหตุยาก
- ตอนนี้พิมพ์ข้อความเองแล้วจบทันที จะเห็นว่าต้องตั้งสวิตช์อะไร
- ทดสอบ: รันโดยไม่ตั้งตัวแปร ต้องเห็นข้อความไทย รันโดยตั้งตัวแปร ต้องผ่านทั้งหมด
