# เรียนรู้: สรุปงานข้ามคืน
- ทำครบ 7 ข้อของคิว แต่ละข้อเป็น PR ของตัวเอง ผ่าน CI และผู้ช่วยตรวจ แล้ว merge เอง (โหมดอัตโนมัติระดับ 2)
- งานที่แตะฐานข้อมูล (merge_settings) ใช้ลำดับ: dry-run แบบ rollback → ใส่ migration (แบบเพิ่ม) → รันเทสต์ SQL ทุกไฟล์ → live-contract บน branch → merge → live-contract บน main
- ข้อ 4 ไม่ต้องทำซ้ำเพราะทำไว้ครบแล้วใน PR ก่อนหน้า ตรวจด้วย grep แทนการทำซ้ำ
- ที่ยังต้องให้คนจริงลอง: หน้าจอบนมือถือและส่วนดึงยอดซื้อจากพอร์ต เพราะผมทดสอบได้แค่ในโค้ด
- คำถามที่รอเจ้าของรวมอยู่ท้าย `docs/HANDOFF.md` หัวข้อ 33
