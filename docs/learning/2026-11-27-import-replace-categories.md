# นำเข้าไฟล์สำรองเมื่อมีหมวดเดิมค้าง (ส่วนฐานข้อมูล · ยังไม่ได้ใส่จริง)

## ทำอะไร
- ฟังก์ชันใหม่ ลบหมวดเดิมและนำเข้าข้อมูลลงทุนจากไฟล์ใน **ธุรกรรมเดียว** (สำเร็จทั้งหมด หรือย้อนกลับทั้งหมด)
- "ยกเลิกการนำเข้า" ไม่ลบหมวดอีกแล้ว

## ทำไม
เดิมถ้ามีหมวดค้าง การกู้ไฟล์สำรองได้แค่ครึ่งเดียว และการยกเลิกนำเข้าลบหมวดเดิมทิ้ง
