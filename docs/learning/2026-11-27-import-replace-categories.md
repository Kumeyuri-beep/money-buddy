# นำเข้าไฟล์สำรองเมื่อมีหมวดเดิมค้าง

## ทำอะไร
- ฐานข้อมูล: ฟังก์ชันใหม่ ลบหมวดเดิมและนำเข้าข้อมูลลงทุนจากไฟล์ใน **ธุรกรรมเดียว** (สำเร็จทั้งหมด หรือย้อนกลับทั้งหมด) · "ยกเลิกการนำเข้า" ไม่ลบหมวดอีกแล้ว
- หน้าเว็บ (หน้านำเข้าไฟล์ และตัวย้ายข้อมูลจากเครื่อง): ก่อนนำเข้าจะนับหมวดเดิม ถ้ามีจะถามก่อน บอกจำนวนที่จะลบและจำนวนที่มาแทน ปุ่มเริ่มต้นคือ **ยกเลิก** (กด Enter หรือ Esc = ไม่นำเข้าอะไรเลย)

## ทำไม
เดิมถ้ามีหมวดค้าง การกู้ไฟล์สำรองได้แค่ครึ่งเดียว และการยกเลิกนำเข้าลบหมวดเดิมทิ้ง

## ข้อจำกัดที่ยังเหลือ
ถ้าขั้นสุดท้าย (ข้อมูลลงทุน) ล้ม สมุดบัญชีเข้าแล้ว หมวดเดิมยังอยู่ แต่ **ยังไม่มีปุ่มลองขั้นนั้นใหม่** (งานถัดไป)
