# ตลาดหุ้นในแอปให้ตรงกับฐานข้อมูล (27 พ.ย. 2569)

## ทำอะไร
ตัวเลือกตลาดของหุ้นสหรัฐเปลี่ยนจาก `NYSE, NASDAQ, AMEX, OTC` เป็น `NYSE, NASDAQ, Other` (ค่าที่เก็บคือ `OTHER`)

## ทำไม
ฐานข้อมูลจริงรับแค่ `NYSE`, `NASDAQ`, `OTHER` (ตรวจแบบอ่านอย่างเดียว) เลือก `AMEX`/`OTC` แล้วบันทึกจะล้มทุกครั้ง

## ผลข้างเคียง
ไฟล์สำรองที่มีคนแก้เองให้เป็น `AMEX`/`OTC` จะถูกปฏิเสธตั้งแต่ตอนตรวจไฟล์ (เดิมสมุดบัญชีเข้าแล้วค่อยล้ม)

## ทดสอบอย่างไร
- `npm test` (`instrumentExchanges` เทียบรายการในแอปกับ migration)
- บนคอม: พอร์ตลงทุน → หุ้นสหรัฐ → เพิ่มหุ้น → ช่อง Exchange มี 3 ตัวเลือก เลือก Other แล้วบันทึกได้
