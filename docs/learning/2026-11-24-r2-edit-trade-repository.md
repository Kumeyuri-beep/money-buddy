# Repository แก้รายการ + ลบสินทรัพย์ (PR A ของ R2 ข้อ 4) · 24 พ.ย. 2569

**ทำอะไร:** เพิ่ม `replaceTrade` (แก้รายการลงทุนที่บันทึกแล้ว = กลับรายการเดิมแล้วลงรายการใหม่ในธุรกรรมเดียว) และ `deleteAsset` (ลบสินทรัพย์ที่ไม่เหลือรายการ) ให้ชั้นเก็บข้อมูลฝั่ง Supabase · ยังไม่มีหน้าจอ (PR B)

**ทำไม:** หน้าจอแก้รายการต้องมีที่เรียกใช้ที่ปลอดภัย: ตรวจกติกาก่อนส่ง (แก้ได้เฉพาะรายการที่กติกาอนุญาต ห้ามย้ายวันขายไปก่อนวันซื้อ) และคำนวณต้นทุนที่ตัดออกของรายการขายใหม่โดยไม่นับรายการเดิม ฐานข้อมูลตรวจซ้ำอีกชั้นเสมอ

**ชนกันระหว่างสองแท็บ:** ถ้าข้อมูลของสินทรัพย์เปลี่ยนระหว่างแก้ (ลายนิ้วมือไม่ตรง PT409 หรือ deadlock 40P01) ผู้ใช้เห็นข้อความเดียว "Data changed — reload and try again." และไม่มีอะไรถูกเขียน
