# สรุปการเรียนรู้: ข้อเสนอแก้ไขรายการที่บันทึกแล้ว (20 พ.ย. 2569)

- **ทำอะไร:** เขียนเอกสารข้อเสนอ `docs/proposals/edit-recorded-transactions.md` ว่าจะให้ผู้ใช้ "แก้" รายการซื้อ/ขาย/ปันผลที่บันทึกแล้วอย่างไร (ยังไม่ทำจริง)
- **ทำไม:** ตอนนี้แก้ไม่ได้ ต้องลบแล้วลงใหม่ และลบไม่ได้ถ้ามีรายการขายตามหลัง
- **แนวคิดหลัก:** ไม่แก้บรรทัดสมุดเดิม แต่ "กลับรายการเดิม + ลงรายการใหม่" ในธุรกรรมฐานข้อมูลเดียว ล้มที่ขั้นใดก็ย้อนทั้งหมด ต้นทุนเฉลี่ยคำนวณจากการเล่นซ้ำจึงเปลี่ยนตามอัตโนมัติ
- **ทดสอบ:** เป็นเอกสาร ไม่มีโค้ด รออนุมัติจากเจ้าของก่อนทำรอบที่ 2
