# สคริปต์ลบผู้ใช้อย่างปลอดภัย

**ทำอะไร:** เพิ่มคำสั่ง `npm run admin:delete-user -- <ชื่อ>` ให้เจ้าของลบบัญชีทีละคน แทนการกดลบในหน้า Supabase

**ทำไม:** เคยเผลอลบผู้ใช้ทั้งหมด (รวมบัญชีตัวเอง) กู้ได้เพราะมีไฟล์สำรอง สคริปต์นี้เพิ่มด่านกันพลาด:
1. ลบได้ทีละคนตามชื่อ ไม่มี wildcard
2. โชว์จำนวนแถวที่จะหาย แล้วต้องพิมพ์ชื่อซ้ำ
3. ไม่ยอมลบบัญชีสุดท้ายหรือ kumeyuri ถ้าไม่ใส่ `--force`
4. ลบเสร็จอ่านกลับว่าไม่เหลือข้อมูลค้าง

**ทดสอบอย่างไร:** เทสต์หน่วยของตัวตรวจอาร์กิวเมนต์/เงื่อนไขปฏิเสธ/การยืนยัน + เทสต์โครงสร้างสคริปต์ + เทสต์ว่าคำสั่งอยู่ใน deny list ของผู้ช่วย AI (ผู้ช่วยรันไม่ได้ เจ้าของรันเอง) ลองจริงครั้งแรกกับบัญชีทดสอบ
