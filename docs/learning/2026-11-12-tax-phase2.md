# เรียนรู้: ภาษี เฟส 2 ค่าลดหย่อนครบขึ้น
- เพิ่มช่อง: คู่สมรส บุตร บิดามารดา ประกันชีวิต/สุขภาพ ประกันสุขภาพบิดามารดา ดอกเบี้ยบ้าน บริจาค · ทุกค่ามาจากเอกสารกรมสรรพากรที่อ่านข้อความออก (ติดป้าย "ตามเอกสาร ม.ค. 2568 ไม่ระบุปีภาษี")
- ประกันชีวิต+สุขภาพรวมกันไม่เกิน 100,000: ชีวิตได้ก่อน สุขภาพได้ส่วนที่เหลือ
- บริจาคหักได้ไม่เกิน 10% ของเงินได้ **หลัง** หักค่าใช้จ่ายและค่าลดหย่อนอื่น เลยคำนวณเป็นอันสุดท้าย
- ช่องที่อ่านต้นฉบับไม่ออก (เช่น เงื่อนไข PVD) ไม่ใส่ ทำรายการลิงก์ไว้ให้เจ้าของอ่านใน HANDOFF แทนการเดา
- ทดสอบ: `npm test` · ลองเอง: เงินเดือน 1,500,000 + คู่สมรสไม่มีเงินได้ + บุตร 2 (ได้เพิ่ม 1) + บิดามารดา 2 + ประกันชีวิต 120,000 + สุขภาพ 30,000 + สุขภาพพ่อแม่ 20,000 + ดอกเบี้ยบ้าน 120,000 + บริจาค 50,000 ควรได้เงินได้สุทธิ ฿865,000 ภาษี ฿88,000 (ตัวอย่างสมมติ)
