# โหมดสว่าง เฟส 2: ชุดสีสว่าง

**ทำอะไร:** เพิ่มชุดสีสว่างโทนเดียวกับ Aurora Glass (ทอง มิ้นต์ ฟ้า ชมพู บนพื้นสว่าง) ด้วยการทับ design tokens ของเฟส 1 ทั้ง 64 ตัว + token ใหม่ที่แยกบทบาท 6 ตัว + สีกราฟ/แถบสัดส่วน/การ์ดแชร์ · **ยังไม่มีปุ่มสลับ** (เฟส 3) แต่เปิดใช้ได้แล้ว 2 ทาง: เครื่องอยู่โหมดสว่าง (ตามเครื่อง) หรือ `data-theme="light"` บน `<html>` · `data-theme="dark"` บังคับมืด

**โหมดมืดไม่เปลี่ยน:** เทียบภาพ 26 ภาพ (8 หน้า × 3 ความกว้าง + เมนู pop up) ต่าง 0 พิกเซลหลังเฟสนี้ด้วย

**ออกแบบ (ผมเลือกเอง เพราะแบบ B ไม่อยู่ในโปรเจกต์ ให้ design-critic ตัดสิน):**
- พื้นฟ้าอมขาวอ่อน `#eef1f8` · ตัวหนังสือหมึก `#12151f` · กระจกเป็นขาวโปร่งมีขอบหมึกจาง
- **ทองเข้ม `#8a5a00`** เป็นสีเน้น (ตัวหนังสือ/ปุ่มหลัก/focus ring) เพราะทองสว่างของโหมดมืดอ่านไม่ออกบนพื้นสว่าง · ปุ่มหลักตัวหนังสือขาวบนทอง
- สีรายรับ/รายจ่าย/โอน/เตือนเป็นเฉดเข้ม (เขียว `#0b7a4f` แดง `#b3261e` น้ำเงิน `#1d4fb8` ส้มเข้ม `#9a5200`)
- สีกราฟและแถบสัดส่วนพอร์ตเป็นเฉดเข้มขึ้นเพื่อให้ต่างจากพื้น ≥ 3:1
- การ์ดแชร์ (รูปที่ส่งออก) ตามธีมตอนกดสร้างรูป

**ตรวจ contrast (เทสต์ `themeContrast.test.ts` คำนวณจากค่า token จริงทั้งสองโหมด):** ตัวหนังสือหลัก/รอง/เน้น ≥ 4.5:1 บนพื้นผิวทุกแบบ (รวมกระจกบนก้อนแสงที่เข้มสุด) · ตัวหนังสือบนปุ่มทอง ≥ 4.5 · สีสถานะ ≥ 4.5 บนการ์ด · ขอบช่องกรอก ≥ 3 · สีกราฟ ≥ 3 · การ์ดแชร์ · และเทสต์ว่าโหมดสว่างทับ token ครบทุกตัวที่โหมดมืดประกาศ + บล็อก "ตามเครื่อง" เหมือนบล็อก `data-theme` ทุกบรรทัด

**ที่เพิ่มในเครื่องมือเทียบภาพ:** dialog เพิ่มรายการ/เพิ่มบิล ที่ 360 และ 1280
