# เรียนรู้: เปลี่ยนชื่อกระเป๋า + ชื่อเริ่มต้นเป็นไทย

**ทำอะไร:** (1) ชื่อกระเป๋าเริ่มต้นตอนตั้งต้นเป็น "เงินสด / บัญชีธนาคาร / เงินออม" แทน CashFlow/Mainframe/Vault Zero (2) หน้าโปรไฟล์มีส่วน "ชื่อกระเป๋าเงิน" ให้เปลี่ยนชื่อเอง · เปลี่ยนเฉพาะชื่อที่แสดง ไม่แตะรหัสบัญชีหรือยอดหรือรายการ

**ผู้ใช้เดิม:** ใครที่ใช้ชื่ออังกฤษอยู่จะไม่ถูกเปลี่ยนให้เอง จะเปลี่ยนก็ไปที่โปรไฟล์

**ทำไมรหัสบัญชีสำคัญ:** รายการทุกรายการอ้างบัญชีด้วย "รหัส" ไม่ใช่ชื่อ จึงเปลี่ยนชื่อได้ปลอดภัย ยอดไม่เปลี่ยน

**ทดสอบอย่างไร:** เทสต์สัญญา (ทั้งในเครื่องและออนไลน์ของจริง 54/54) + เทสต์กติกาชื่อ + ภาพ 360px
