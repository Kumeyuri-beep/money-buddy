# การ์ดแชร์สัดส่วนพอร์ต (สรุปแบบง่าย)

## ทำอะไร
ในหน้าพอร์ตมีปุ่ม "สร้างการ์ดแชร์สัดส่วนพอร์ต" กดแล้วได้รูปสวยๆ ที่บอกว่าพอร์ตของคุณแบ่งเป็นกี่ % ต่อสินทรัพย์ แล้วกด "แชร์รูป" หรือ "บันทึกรูป (PNG)" เอง

## กติกาที่เจ้าของกำหนด และทำตามอย่างไร
| กติกา | ทำอย่างไร |
| --- | --- |
| แชร์เฉพาะสัดส่วน % ไม่มียอดเงิน | ตัวที่วาดรูปรับเข้ามาแค่ "ชื่อป้าย + สัดส่วน (bps)" ไม่มีทางเห็นยอดเงิน/จำนวนหน่วย มีเทสต์เช็กว่าไฟล์ที่วาดรูปไม่อ้างถึงพอร์ตจริง |
| ชื่อกองทุนซ่อนเป็นค่าเริ่มต้น | ป้ายในรูปเป็น "สินทรัพย์ 1, 2, 3…" จนกว่าคุณจะติ๊ก "แสดงชื่อกองทุน/หุ้นในรูป" เอง (มีคำเตือนว่าใครเห็นรูปจะรู้ว่าคุณถืออะไร) |
| สร้างรูปในเครื่อง | วาดด้วย canvas ในเบราว์เซอร์ ไม่ส่งอะไรขึ้นเซิร์ฟเวอร์ ไม่มีโค้ดเรียกเครือข่าย (มีเทสต์สแกนโค้ดว่าไม่มี fetch/beacon/URL ภายนอก) |
| ผู้ใช้กดแชร์เอง | ระบบไม่แชร์ให้เอง ปุ่ม "แชร์รูป" ใช้หน้าต่างแชร์ของเครื่อง (ถ้าเครื่องรองรับ) หรือจะบันทึกไฟล์ไว้ก่อนก็ได้ |

## เรื่องคณิตศาสตร์ (ทำไมไม่ใช้ % ธรรมดา)
สัดส่วนต้องรวมกัน 100% พอดี ถ้าปัดแต่ละอันแยกกันจะได้ 99.9% หรือ 100.1% ระบบจึงแบ่ง 10,000 ส่วน (bps) ด้วยวิธี "เศษมากสุดได้ส่วนที่เหลือ" ใช้จำนวนเต็มล้วน (BigInt) ไม่ใช้ทศนิยมลอยตัว
สัดส่วนเป็นค่าแสดงผลเท่านั้น ไม่ถูกนำกลับไปคำนวณยอดเงิน

## เกณฑ์ที่ใช้คิดสัดส่วน
- ถ้ากรอกราคาครบทุกสินทรัพย์ → คิดตามมูลค่า
- ถ้ายังไม่ครบ → คิดตามต้นทุน และบอกในหน้าจอชัดๆ (ไม่ผสมมูลค่ากับต้นทุนในรูปเดียวกัน)
