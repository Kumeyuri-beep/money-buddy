# เกษียณ เฟส 2: ผูกกับพอร์ตจริง (สรุปแบบง่าย)

## ทำอะไร
ในหน้า "วางแผนเกษียณ" ถ้ามีพอร์ตลงทุน จะมีรายการสินทรัพย์ให้ติ๊กเลือกว่า "อันไหนนับเป็นเงินเกษียณ" (ไม่ติ๊กอะไรไว้ให้ก่อน)
- ระบบใช้มูลค่าตามราคาที่คุณกรอกไว้ในหน้าพอร์ต แทนช่อง "เงินที่เก็บไว้แล้ว" (ไม่นับซ้ำ) และบอกที่มาของตัวเลข
- เห็น "ความคืบหน้า" ว่ามีเท่าไรของเงินที่ควรมี
- เห็นว่าแผน DCA ต่อเดือนของสินทรัพย์ที่เลือก เทียบกับเงินที่ต้องเก็บแล้วขาดเท่าไร

## สิ่งที่ระบบระวังให้
- ไม่มีราคา → ขึ้น "ยังไม่มีราคา" และเตือนว่ามูลค่ารวมไม่ครบ (ไม่แอบนับเป็น 0 และไม่เอาราคาทุนมาแทน)
- ราคาที่กรอกไว้เกิน 30 วัน → เตือนให้อัปเดต
- ความคืบหน้าไม่ขึ้น 100% ถ้ายังไม่ถึงเป้าจริง (ปัดแล้วใกล้ 100% จะโชว์ 99.99%)
- แผน DCA เป็น "แผนที่ตั้งไว้" ไม่ใช่เงินออมจริง ไม่ถูกนับรวม
- ไม่บันทึกอะไรเพิ่ม และไม่แก้ข้อมูลพอร์ตของคุณ

## ทดสอบอย่างไร
- `npm test` ผ่านทั้งหมด (เพิ่มเทสต์ความคืบหน้า ราคาเก่า 30/31 วัน ไม่มีราคา ไม่บวกซ้ำ DCA ที่พักแผน)
- ลองเอง: เปิดหน้า "วางแผนเกษียณ" → ติ๊กสินทรัพย์ที่มีราคา → กรอกข้อมูลแล้วกดคำนวณ → ดูกล่องความคืบหน้า · ติ๊กสินทรัพย์ที่ยังไม่มีราคา ต้องเห็นคำเตือน "มูลค่ารวมไม่ครบ"
