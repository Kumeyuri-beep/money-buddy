# ข้อความ "ถ้าปุ่มลองใหม่หาย" (27 พ.ย. 2569)

## ทำอะไร
หน้าข้อผิดพลาดของการนำเข้าไฟล์สำรองมีหัวข้อใต้ปุ่ม บอกว่าข้อมูลไม่หาย และต้องทำอะไรต่อ โดยแยกตามกรณี
- ข้อมูลลงทุนอาจยังไม่เข้า: ตรวจก่อน → ถ้าไม่แน่ใจแจ้งผู้ดูแล → ถ้าจะล้างเอง มีคำเตือนก่อนขั้นกด
- ข้อมูลเข้าแล้ว: ไม่ต้องนำเข้าใหม่
- ไฟล์ไม่มีข้อมูลลงทุน หรือไม่มีสินทรัพย์: ไม่แนะให้ล้างข้อมูล

แก้เพิ่ม: ปุ่ม "ตรวจยอดอีกครั้ง" ไม่นำเข้าเองถ้าข้อมูลออนไลน์หายไประหว่างนั้น

## ทำไม
การล้างข้อมูลย้อนกลับไม่ได้ ข้อความต้องไม่พาคนไปล้างโดยไม่จำเป็น
