# เทสต์หน้าจออัตโนมัติด้วย Playwright

**ทำอะไร:** `npm run e2e` เปิดแอปในเบราว์เซอร์จริง (Chromium แบบไม่มีหน้าต่าง) ที่ความกว้าง **360, 390 (มือถือ) และ 1280 (คอม)** แล้วเปิดทุกหน้าหลัก (ภาพรวม รายการ บิล พอร์ต ถัวเฉลี่ย เกษียณ ภาษี โปรไฟล์) กับเมนู pop up บนมือถือ แล้วตรวจ 3 อย่าง
1. **ไม่มีอะไรล้นจอ** (รายองค์ประกอบ: ของที่ยื่นออกนอกขอบจอและไม่ได้อยู่ในกล่องที่เลื่อนได้เอง)
2. **ปุ่ม/ช่องกรอกไม่ถูกบัง** (เลื่อนให้อยู่กลางจอแล้วดูว่าจุดกึ่งกลางยังเป็นของมันเอง ไม่ใช่ของที่ลอยทับ)
3. **ไม่มี error ใน console** (และไม่มีหน้าเว็บ error)

**ข้อมูล:** ใช้ harness (`src/dev/harness.tsx`) ข้อมูลสมมติเก็บใน IndexedDB ของเบราว์เซอร์ข้ามการล็อกอิน · **ไม่ต่อฐานข้อมูลจริง** ด้วย 3 ชั้น: (ก) เซิร์ฟเวอร์ทดสอบตั้ง `VITE_SUPABASE_URL/ANON_KEY` เป็นค่าว่าง แอปจึงไม่สร้างตัวต่อ Supabase (ข) เทสต์บล็อกทุกคำขอที่ไม่ใช่ localhost (ค) เทสต์ล้มถ้ามีความพยายามเรียกออกนอก

**ตัวตรวจจับได้จริงไหม:** มีเทสต์ "ตัวควบคุม" 3 ข้อที่ใส่ของเสียเข้าไปเอง (กล่องกว้าง 900px, ชั้นลอยทับปุ่ม, console.error + fetch ออกนอก) แล้วต้องจับได้ · ข้อค้นพบระหว่างทำ: แอปซ่อน overflow แนวนอนไว้ที่ราก ของที่ล้นจอจึงถูกตัดทิ้งเงียบๆ และ `scrollWidth` ของหน้าไม่ขึ้น จึงต้องตรวจรายองค์ประกอบ (รอบแรกที่นับ `overflow: hidden` ว่าเป็นกล่องเลื่อนได้ตรวจไม่เจออะไรเลย แก้แล้ว)

**ผลรอบแรก:** ทั้ง 27 หน้า/ความกว้างผ่านโดยไม่ต้องแก้ UI · ใช้เวลาราว 15 วินาทีในเครื่อง

**CI:** job `e2e` แยกจาก job `test` (ไม่ยืดเวลา job เดิม) ไม่ใช้ secrets · ถ้าล้ม เก็บผลไว้ 3 วัน
