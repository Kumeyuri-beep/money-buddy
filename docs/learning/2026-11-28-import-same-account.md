# กันนำเข้าหรือล้างผิดบัญชี (28 พ.ย. 2569)

## ทำอะไร
ถ้าอีกแท็บสลับไปเข้าอีกบัญชีระหว่างนำเข้าหรือล้างข้อมูล แอปจะหยุด ไม่เขียนหรือล้างอะไรกับบัญชีใหม่
ตรวจก่อนเริ่ม ก่อนส่งแต่ละก้อน ก่อนล้างแต่ละชุด และหลังอ่านข้อมูลมาเทียบยอด

## ทำไม
ไฟล์ที่เลือกไว้ค้างอยู่ในหน่วยความจำ ส่วนการล็อกอินใช้ร่วมกันทุกแท็บ

## ข้อจำกัด
ยังมีช่องว่างสั้นมากระหว่าง "ตรวจ" กับ "เขียน" ปิดได้สนิทต้องให้ฐานข้อมูลตรวจเอง (ต้องแก้ฐานข้อมูล อยู่ใน backlog)

## ทดสอบอย่างไร
`npm test` (ชุด "บัญชีเปลี่ยน...") · บนคอม: เปิดสองแท็บ เข้าคนละบัญชีทดสอบระหว่างหน้านำเข้าค้างอยู่
