# ลบโค้ดที่ไม่มีใครใช้

**วิธีตรวจ (ไม่ติดตั้งเครื่องมือภายนอก):** เขียนสคริปต์อ่านอย่างเดียวนับว่าแต่ละ `export` ในโฟลเดอร์ `src/` ถูกอ้างชื่อที่ไหนบ้างทั้งโปรเจกต์ (src, tests, scripts, html) และตรวจว่าแต่ละไฟล์ใน `src/` มีใคร import ไหม แล้วตรวจ dependency ใน `package.json` ว่ามีใครอ้างชื่อ

**ผล**
- ไฟล์ใน `src/` ที่ไม่มีใคร import: **0**
- dependency ที่ไม่มีใครใช้: **0** (ทุกตัวถูกใช้ รวม `@types/*` และ `typescript` ที่ใช้โดยเครื่องมือ)
- ของที่ **ไม่มีการอ้างถึงเลยทั้งโปรเจกต์ (ลบแล้ว):**
  1. `INVEST_RESULT_ACCOUNTS` ใน `src/domain/invest/ledgerLink.ts` (รายการบัญชีผลการลงทุนที่ไม่มีใครอ่าน; ชื่อบัญชีจริงอยู่ในฟังก์ชัน SQL `record_trade` และรหัสอยู่ใน `INVEST_ACCOUNT_IDS` ซึ่งยังอยู่)
  2. `setLocalOwner` ใน `src/storage/localOwner.ts` (ไม่มีโค้ดไหนตั้งเจ้าของข้อมูลในเครื่องอีกแล้ว ส่วน `getLocalOwner` ที่ใช้อยู่ยังอยู่ครบ)
- **ไม่ลบ (ตัดสินใจเอง ไม่ใช่ของไม่มีใครใช้):** ฟังก์ชันที่ production ไม่เรียกแต่มีเทสต์ครอบอยู่ ได้แก่ `parseSlipText`, `draftFromOcrText`, `projectDca`, `outstandingBeforePayday`, `convertToSatang`, `sumSatang`, `localDataAccess`, `ALL_FILTER`, `SUMMARY_CARD_IDS` — เป็นฟังก์ชันสูตร/ตัวช่วยที่มีเทสต์ขอบเขตตามกฎเงิน ถ้าลบต้องลบเทสต์ด้วย จึงจดไว้ให้เจ้าของตัดสิน
- `export` ที่ใช้เฉพาะในไฟล์ตัวเอง (ประมาณ 120 รายการ ส่วนใหญ่เป็น type/ค่าคงที่) ไม่ถือว่าเป็นโค้ดตาย ไม่แตะ

**ทดสอบอย่างไร:** `npm test` (2002 ผ่าน), typecheck, build ผ่านเหมือนเดิม
