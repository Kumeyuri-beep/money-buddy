# เครื่องหมายลบ "−" แบบเดียวกัน + ป้ายอ่านแถวตาราง — สรุปสำหรับมือใหม่

- เงินบาทเดิมใช้ "−" (U+2212) แต่ดอลลาร์และเปอร์เซ็นต์ใช้ "-" (ขีดกลาง) ตอนนี้ใช้ "−" ทุกที่ที่แสดงใน /invest (ฟังก์ชัน `usd`, `bpsText` และตัวจัดรูปของแท็บวิเคราะห์) ตัวเลขข้างในไม่เปลี่ยน เปลี่ยนแค่ตัวอักษรที่แสดง
- แถวในตาราง Portfolio ของ Dashboard มี `aria-label` อ่านครบ: ชื่อ (ชื่อย่อ), value, invested, gain (พร้อม %), allocation เช่น "หุ้น US1 (US1), value $750.00, invested $600.60, gain +$149.40 (+24.88%), allocation 100%" ประกอบจากข้อความที่จัดรูปแล้ว ไม่มีการคำนวณเงิน
- ทดสอบ: เทสต์หน่วย (รวมกรณีขาดทุน) และ e2e ของ /invest กับ us-stocks
