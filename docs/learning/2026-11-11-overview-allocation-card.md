# การ์ดสัดส่วนพอร์ตในหน้าภาพรวม (สรุปแบบง่าย)

## ทำอะไร
หน้า "ภาพรวม" (หน้าแรก) เดิมมีกล่องว่าง "เป้าเกษียณ + สัดส่วนพอร์ต (เร็วๆ นี้)" ตอนนี้แยกเป็น 2 กล่อง:
- **สัดส่วนพอร์ตลงทุน**: แถบสีบอกว่าพอร์ตแบ่งเป็นกี่ % ต่อกองทุน/หุ้น พร้อมรายการชื่อและ % (กดไปหน้าพอร์ตได้)
- **เป้าเกษียณ**: ยังเป็นกล่องว่าง "เร็วๆ นี้" (ยังไม่ได้ทำ)

## หลักที่ใช้
- ใช้ข้อมูลและวิธีคิดเดียวกับการ์ดแชร์ (`buildAllocationModel`) จึงตัวเลขตรงกันทุกที่: แบ่ง 10,000 ส่วนด้วยจำนวนเต็ม รวม 100% พอดี
- คิดตามมูลค่าถ้ากรอกราคาครบทุกสินทรัพย์ ไม่ครบคิดตามต้นทุนและบอกชัดๆ (ไม่ผสมกัน)
- แสดง **เฉพาะ %** ในการ์ด ไม่แสดงยอดเงิน (ยอดเงินดูที่หน้าพอร์ต) และแสดงชื่อจริงได้เพราะเป็นหน้าจอของคุณเอง ไม่ใช่รูปที่เอาไปแชร์
- ถ้ามีสินทรัพย์ที่ข้อมูลผิดพลาด/มูลค่าเป็น 0 หรือราคาเก่ากว่า 7 วัน จะมีคำเตือนใต้การ์ด
- ไม่มีสินทรัพย์ = บอกว่ายังไม่มี พร้อมปุ่มไปเพิ่ม · ใช้บัญชีในเครื่อง (Dexie) จะเห็นเป็นยังไม่มี เพราะพอร์ตลงทุนใช้ได้เฉพาะออนไลน์
