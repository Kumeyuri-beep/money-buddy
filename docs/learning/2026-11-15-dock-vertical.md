# dock แนวตั้งซ้ายแทนแถบข้าง (15 พ.ย. 2569)

**ทำอะไร:** บนจอกว้าง (1024px ขึ้นไป) ตัดแถบข้างทิ้งทั้งแถบ แล้วใช้ dock แนวตั้งลอยทางซ้ายแทน dock แนวนอนด้านล่างที่ทำไว้ก่อนหน้า
- บนสุด โลโก้ MB กับปุ่ม "เพิ่มรายการ" สีทอง · กลาง 7 เมนู ไอคอนสีพาสเทลคนละสี หน้าที่เปิดอยู่เป็นพื้นพาสเทลเต็มกับขีดด้านซ้าย · ล่างสุด ปุ่มบัญชี กดแล้วมีเมนูชื่อผู้ใช้ สถานะตรวจบัญชี "โปรไฟล์และตั้งค่า" และ "ออกจากระบบ"
- สถานะตรวจบัญชีมีป้ายเล็กมุมขวาบนของเนื้อหาด้วย เนื้อหาเว้นซ้ายไม่ให้ dock บัง

**ทำไมทำแบบนี้**
- ของที่เคยอยู่ในแถบข้าง (โลโก้ ชื่อผู้ใช้ ออกจากระบบ สถานะ) ต้องมีที่ไปครบ จึงย้ายเข้า dock และเมนูบัญชี ไม่ทิ้งฟังก์ชันไหนหาย
- ไอคอนขยายตามเมาส์ด้วย `transform: scale` อย่างเดียว (ไม่เปลี่ยนความกว้าง/สูง) ช่องว่างระหว่างไอคอนกว้างพอจนไม่ทับกัน จึงไม่ต้องคำนวณเลื่อนตำแหน่ง
- สีพาสเทลเป็น design tokens (`--dock-hue-*`, `--dock-ink-*`) โหมดสว่างใช้เฉดเข้มของสีเดิมสำหรับไอคอนตอนปกติ เพื่อให้อ่านชัด (มีเทสต์คำนวณ contrast ทุกสี)
- ทุกอย่างอยู่ใน `@media (min-width: 1024px)` มือถือและแท็บเล็ตไม่เปลี่ยน (มีเทสต์ยืนยันที่ 1023/900/390/360)

**ทดสอบอย่างไร:** เทสต์หน่วย (สูตรขยาย, contrast ของสี) + Playwright 1280/1440 × มืด/สว่าง (คีย์บอร์ดล้วน, เมนูบัญชี, ขยายแนวตั้ง, ป้ายสถานะ, ลดการเคลื่อนไหว/ความโปร่งใส) + เทสต์เดิมทุกหน้าที่ 1280/1440
