# เก็บตก PR #270: แก้รายการ / เมนูแถว Holdings

## ทำอะไร
- เมนู ⋯ ของ Holdings เปิดติดปุ่มทุกขนาดจอแล้ว (บนมือถือ/แท็บเล็ตเคยหลุดจอ เพราะการ์ดกระจกทำให้ตำแหน่ง `fixed` อิงกรอบการ์ด)
- กด Tab / Shift+Tab ในเมนู: เมนูปิดและโฟกัสไปต่อจากปุ่มของแถวเดิม
- ป้าย "Delete" เปลี่ยนเป็น **"Delete all records"** ให้ต่างจาก "Delete asset"
- หน้าตรวจผลกระทบ: กด Esc ถอยกลับฟอร์ม (ค่าที่กรอกยังอยู่) กดอีกครั้งจึงปิด · บันทึกไม่สำเร็จโฟกัสกลับหัวข้อ
- ป้ายตารางสั้นลง · repository ใช้ฟังก์ชัน `editedTradeOf` ตัวเดียวกับหน้าจอ (ไม่มีโค้ดกติกาซ้ำสองที่)
- เพิ่มเทสต์เติมฟอร์มด้วยตัวเลขใหญ่มากและค่า 0

## ทดสอบอย่างไร
unit + e2e ทั้งชุด และ `admin:live-contract` บน branch เพราะแตะ `src/storage/`

## ต้องลองบนคอม
- Transactions → Edit → Review change → กด Esc หนึ่งครั้งกลับฟอร์ม สองครั้งปิด
- Holdings → ⋯ เปิดติดปุ่ม · เมนูมี Delete all records / Delete asset
