# ข้อเสนอ: ผลตอบแทนไม่รวมเงินสด (R25)

**ทำอะไร:** เช็กว่ามูลค่าพอร์ตที่ใช้คิดผลตอบแทนรวมเงินสดไหม พบว่า**ไม่รวม** (มูลค่า = หน่วย × ราคา) การฝาก/ถอน/ปรับยอดเงินสดจึงไม่ใช่กระแสเงินของ Modified Dietz/IRR เขียนเป็นข้อเสนอใน `docs/proposals/R25-4-cash-not-in-return.md` พร้อมตัวอย่างคำนวณมือ (แบบปัจจุบัน 485 bps เทียบแบบรวมเงินสด 440 bps)

**ทำไม:** เจ้าของถามเพื่อให้การปรับยอดเงินสดไม่ทำให้ผลตอบแทนเพี้ยน ผลคือไม่ต้องแก้โค้ด แค่เพิ่มถ้อยคำให้ชัดในกฎ (รออนุมัติ)

**ทดสอบอย่างไร:** เอกสารล้วน ตัวเลขในตัวอย่างตรวจมือ 2 ทาง และโค้ดที่เกี่ยวข้องไม่อ่านสมุดบัญชี
