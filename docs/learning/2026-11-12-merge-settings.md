# เรียนรู้: แก้ปัญหาเปิดสองแท็บแล้วค่าตั้งค่าทับกัน
- เดิมเว็บอ่านค่าตั้งค่า "ทั้งก้อน" มาไว้ในหน้า แก้นิดเดียว แล้วเขียน "ทั้งก้อน" กลับ ถ้าอีกแท็บเพิ่งบันทึกอย่างอื่นไปในระหว่างนั้น ค่านั้นจะถูกเขียนทับด้วยค่าเก่า
- วิธีแก้: ให้ฐานข้อมูลเป็นคนรวมค่า เว็บส่งมาแค่ "คีย์ที่เปลี่ยน" (เช่น แค่รายชื่อสินทรัพย์เกษียณ) ฐานข้อมูลรวมเข้ากับค่าล่าสุดในคำสั่งเดียว คีย์อื่นจึงไม่โดนแตะ
- ส่งค่าว่าง (`null` หรือรายการว่าง) = ลบคีย์นั้น · ไม่ส่ง = ไม่แตะ
- ความปลอดภัยเหมือนฟังก์ชันอื่น: ต้องล็อกอิน ต้องเปลี่ยนรหัสผ่านแล้ว คนอื่นแก้ของเราไม่ได้ เพดานขนาด 16 KB ยังอยู่
- ทดสอบ: เทสต์ SQL 14 ข้อ (รวมคนอื่นแก้ไม่ได้ ผู้ใช้ที่ยังไม่เปลี่ยนรหัสใช้ไม่ได้ ไม่ล็อกอินเรียกไม่ได้) · เทสต์ unit ของตัววางแผนรวมค่า · live-contract เปิดสองแท็บบันทึกพร้อมกัน 8 รอบ ค่าอยู่ครบทุกรอบ
- migration นี้ใส่ฐานข้อมูลจริงแล้ว (dry-run แบบ rollback ผ่านก่อน) ตามกติกาโหมดอัตโนมัติระดับ 2 เพราะเป็นแบบ "เพิ่ม" อย่างเดียว
