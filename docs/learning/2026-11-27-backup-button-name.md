# ข้อความอ้างชื่อปุ่มสำรองให้ตรง (27 พ.ย. 2569)

## ทำอะไร
สามจุดบอกให้กด "สำรองข้อมูล" แต่ปุ่มจริงชื่อ "ดาวน์โหลดข้อมูลของฉัน" ในหน้าโปรไฟล์ แก้ให้ตรง

แก้เพิ่ม: กล่องยืนยันล้างข้อมูลและหน้าบิลเคยบอกว่าการล้างจะลบ "สำเนาก่อนอัปเกรด" ในเครื่องด้วย ซึ่งไม่จริงสำหรับบัญชีออนไลน์

## ทำไม
มือใหม่หาปุ่มตามชื่อไม่เจอ โดยเฉพาะตอนก่อนล้างข้อมูลซึ่งย้อนกลับไม่ได้
