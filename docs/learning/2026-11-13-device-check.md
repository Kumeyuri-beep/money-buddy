# เรียนรู้: ตรวจบนมือถือจริงผ่านแล้ว
- ที่ผมทดสอบได้มีแค่โค้ดและเทสต์ ส่วนหน้าตาและการใช้งานจริงบนมือถือต้องให้คนลอง เจ้าของลองแล้วผ่านทั้ง 5 อย่าง: ตารางภาษี, ตัวอย่าง 1,500,000 → 88,000, การ์ดเครื่องมือ, ค่าตั้งค่าบันทึกข้ามเครื่อง, ดึงยอดซื้อจากพอร์ต
- "ค่าตั้งค่าบันทึกข้ามเครื่อง" เป็นหลักฐานจริงว่างาน merge_settings ใช้งานได้บนระบบจริง ไม่ใช่แค่ในเทสต์
- ที่ยังไม่ได้ลอง: โปรแกรมอ่านจอกับตารางภาษีบนมือถือ
