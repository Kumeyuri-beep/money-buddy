# แดชบอร์ดพอร์ต (แท็บ "แดชบอร์ด" ในโหมดพอร์ต)

## ทำอะไร
ทำหน้าแดชบอร์ดแนว Snowball ให้แท็บแรกของโหมดพอร์ต มี 3 แถว: แถวบน 5 การ์ด (มูลค่าพอร์ต, เงินลงทุน, กำไรรวม, IRR, รายได้ปันผลต่อปี) แถวกลาง (กราฟย้อนหลัง, สัดส่วนพอร์ต, วันนี้ขึ้น/ลง) แถวล่าง (ปันผลรายเดือน, กำไรมาจากไหน 6 แหล่ง, เป้าหมาย) ปุ่ม ฿/USD ที่หัวโหมดเปลี่ยนสกุลของทุกการ์ดที่แสดงเงิน

## ทำไมออกแบบแบบนี้
- ตัวเลขทุกตัวมาจากฟังก์ชันโดเมนที่ผ่านเทสต์แล้ว (computeProfitSources, computeDividendMetrics, computeIrr, buildUsPortfolio) หน้าจอแค่แสดงผล ไม่คิดเงินเอง
- ข้อมูลไม่ครบ (ไม่มีราคา/อัตรา) แสดง "—" พร้อมเหตุผล ไม่ใช้ 0 หรือต้นทุนแทน (R20.7)
- การ์ดที่ต้องมีราคาอัตโนมัติ (กราฟย้อนหลัง, วันนี้ขึ้น/ลง) ใช้ CardUnavailable
- สไตล์เฉพาะคอมอยู่ใน `@media (min-width: 1024px)` มือถือเรียงคอลัมน์เดียว
