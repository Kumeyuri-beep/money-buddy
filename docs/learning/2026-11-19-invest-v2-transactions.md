# บันทึกการเรียนรู้: หน้า Transactions (invest-v2)

## ทำอะไร
แทนที่หน้ารายการเดิมของ Portfolio → Transactions ด้วยตารางรวมทุกรายการ: ซื้อ ขาย ปันผล ปันผลลงทุนต่อ แลกเงิน โอนเงินบาทเข้า/ออกพอร์ต และเงินเข้า/ออกแบบปรับยอด
มีแท็บ All / Trades / Incomes, ค้นหา, Filters (ชนิด สินทรัพย์ ช่วงวันที่), ล้างตัวกรอง, ชิปยอดรวม (Buy, Sell, Fee & tax, Dividends net), เมนู Add และปุ่มลบพร้อมหน้าต่างยืนยัน

## ทำไมออกแบบแบบนี้
- สูตรเงินทั้งหมดอยู่ใน `src/domain/invest/transactionsView.ts` (หน้าจอแค่แสดงผล) ใช้ตัวแปลงสกุลเดิมของ R26 ปัดครั้งเดียวต่อค่า
- มุมมอง THB ใช้เรตของรายการนั้นเอง (เงินสด/โอนใช้เรตล่าสุดที่กรอก) ถ้าไม่มีเรตจะขึ้น "Needs rate" ที่แถว และยอดรวมที่เกี่ยวข้องขึ้น Incomplete ไม่นับเป็น 0
- สินทรัพย์บาท (กองทุน) ในมุมมอง USD แสดงเป็นบาทตามต้นทาง และไม่รวมในยอด (R26 ขอบเขต)
- ลบใช้กฎ R17 ตัวเดิม (`checkTradeDeleteCoded`) ถ้าลบไม่ได้จะบอกเหตุผล ไม่ลบเงียบๆ
- เมนู Add ไม่มี "Fee or tax" ตามที่เจ้าของตัดสิน ฟอร์มซื้อ/ขาย/ปันผล/แลกเงินใช้ของเดิมใน UsStocksView
- ปุ่ม Edit ปิดไว้พร้อมคำอธิบาย เพราะระบบยังไม่มีการแก้รายการที่บันทึกแล้ว
- ถ้าเงินสด USD ติดลบ (เช่น ถอนมากกว่าฝาก) จะมีคำเตือนสีแดงให้เห็น
