# เรียนรู้: แก้ข้อความที่บอกผิดว่าข้อมูลอยู่ในเครื่อง

**ทำอะไร:** ตั้งแต่ M2 ข้อมูลเก็บในบัญชีออนไลน์ แต่บางข้อความยังเป็นของสมัยเก็บในเครื่อง ("ข้อมูลอยู่ในเครื่องคุณ", "เก็บไว้ในเบราว์เซอร์ของคุณเท่านั้น", "ลองปิดโหมดส่วนตัว") แก้เป็นข้อความที่ตรงกับระบบจริง · หน้าเริ่มต้นอธิบายคำว่า "กระเป๋า" และบอกว่าตอนนี้ยังเปลี่ยนชื่อทีหลังไม่ได้ · หน้าลบบัญชีบอกว่าพอร์ตลงทุนถูกลบด้วย

**ทำไม:** ข้อความผิดความจริงทำให้ผู้ใช้ตัดสินใจเรื่องสำรองข้อมูลผิด และขัดกับนโยบายความเป็นส่วนตัวที่เพิ่งกดยอมรับ

**ทดสอบอย่างไร:** เทสต์ตรวจว่าวลีเก่าหายและวลีใหม่อยู่ · ถ่ายภาพหน้าเริ่มต้นที่ 360px ไม่มีแถบเลื่อนแนวนอน
