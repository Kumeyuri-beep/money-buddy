# แก้ไฟล์เทสต์ categories ให้ตรงกับที่รันจริง (24 พ.ย. 2569)

**ทำอะไร:** ในไฟล์ `supabase/tests/categories_test.sql` มีตัวอักษรล่องหน 2 ตัว (ศูนย์ความกว้าง และตัวกลับทิศข้อความ) อยู่ในชื่อหมวดตรงๆ ซึ่งเห็นไม่ได้และพิมพ์ส่งต่อให้เครื่องมืออื่นแล้วหายง่าย เปลี่ยนเป็นรหัสหนี `​` และ `‮` แทน

**ทำไม:** ตอนรันเทสต์ SQL ครบ 28 ไฟล์ (23 พ.ย.) ต้องพิมพ์เนื้อไฟล์ส่งเข้าฐานข้อมูล ตัวอักษรล่องหนอาจหายระหว่างทาง ทำให้เทสต์ที่รันไม่ตรงกับไฟล์ใน repo การใช้รหัสหนีทำให้ไฟล์ในเครื่องกับไฟล์ที่รันเป็นข้อความเดียวกันเสมอ และไม่เปลี่ยนความหมายของเทสต์ (ค่าที่ได้เป็นตัวอักษรเดียวกันหลังตีความ JSON)

**ทดสอบอย่างไร:** เปลี่ยนเฉพาะ 2 บรรทัดในไฟล์เทสต์ ไม่แตะโค้ดแอปหรือฐานข้อมูล รันไฟล์นี้ในฐานข้อมูลจริงได้ `TESTS_PASSED` ตั้งแต่ตอนรันซ้ำวันที่ 23 พ.ย. ด้วยรหัสหนีชุดเดียวกัน
