# เรียนรู้: ปรับมือถือรอบ 1 + ชุดถ่ายภาพหน้าจอ 360px

**ทำอะไร:** (1) ปุ่ม/ตัวเลือกที่แตะบ่อยบนมือถือ (แก้ไข/ลบ, ปุ่มใน toast, เลือกประเภทรายการ, ช่องเลือกของการจดด่วน, ปุ่มแสดงรหัสผ่าน) สูงอย่างน้อย 44px และเว้นช่องระหว่างปุ่มแก้ไข/ลบกันกดผิด (2) dialog ใช้ความสูงที่เห็นจริง (`dvh`) ไม่ให้ปุ่มบันทึกถูกแป้นพิมพ์บัง (3) แถบข้างบนมือถือย่อช่องไฟและตัดคำโปรย (4) เพิ่มชุดถ่ายภาพหน้าจอ `harness.html` สำหรับนักพัฒนา

**ทำไม:** ผลสำรวจ design-critic ว่าผู้ใช้มือถือกดปุ่มเล็กพลาดง่าย และแถบข้างกินพื้นที่บนสุดก่อนถึงเนื้อหา

**ชุดถ่ายภาพ (dev เท่านั้น):** `npm run dev` แล้วเปิด `/harness.html?seed=1` (ข้อมูลสมมติ ข้ามล็อกอิน ใช้ข้อมูลในเครื่อง) เพิ่ม `&view=<ชื่อเมนู>` เปิดหน้านั้น · ไม่ถูกรวมใน build จริง (ตรวจแล้วไม่มีใน dist) · ไม่ใช้ข้อมูลการเงินจริง

**ทดสอบอย่างไร:** เทสต์ตรวจกฎ CSS ≤720px · ถ่ายภาพที่ 360px ดูด้วยตา (ไม่มีแถบเลื่อนแนวนอน scrollWidth = 360)
