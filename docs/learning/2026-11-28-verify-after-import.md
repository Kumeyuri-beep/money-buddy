# นำเข้าแล้วแต่ตรวจยอดไม่ได้ (28 พ.ย. 2569)

## ทำอะไร
- ถ้านำเข้าไฟล์สำรองสำเร็จแต่อ่านกลับมาตรวจยอดไม่ได้ หน้าจอบอกว่า "นำเข้าแล้ว" และมีปุ่มตรวจยอดอีกครั้ง (ไม่นำเข้าซ้ำ)
- ถ้าสลับบัญชีระหว่างนั้น หน้าจอบอกให้กลับเข้าบัญชีที่ใช้นำเข้า

## ทำไม
เดิมผู้ใช้เห็นแค่ข้อความผิดพลาด ไม่รู้ว่าข้อมูลเข้าไปแล้ว

## ทดสอบอย่างไร (บนคอม)
`npm run dev` เปิด `/harness.html?reset=1&importRetry=ok&online=empty&verify=firstfail` เลือกไฟล์ `tests/fixtures/import-retry-backup.json`
