# รหัส error ของฟอร์มลงทุน (งาน B)

**ทำอะไร:** ฟอร์มซื้อ-ขาย-ปันผล หุ้นสหรัฐ และแลกเงิน (`tradeForm.ts`, `usForms.ts`) เดิมสร้างข้อความไทยฝังในประโยคเลย ตอนนี้ทุกข้อความมี "รหัส" (เช่น `form.moneyPositive`) พร้อม "พารามิเตอร์" (เช่น ชื่อช่อง ค่าสูงสุด สกุลเงิน) แล้วแม่แบบใน `formMessages.ts` ประกอบเป็นไทยหรืออังกฤษตามต้องการ

**ทำไม:** หน้า /invest ต้องแสดงอังกฤษ ส่วนหน้าอื่นต้องยังเป็นไทยเหมือนเดิมทุกตัวอักษร จึงแยก "ความหมาย" (รหัส) ออกจาก "ภาษา"

**ปลอดภัยอย่างไร:** ไม่แตะสูตร เงื่อนไข หรือลำดับการตรวจ ข้อความไทยเดิมเก็บใน `message` เหมือนเดิม เพิ่มแค่ `code` และ `params` ถ้าตัวอ่านหน่วย/ราคาโยน error ที่มีรหัส ฟอร์มส่งรหัสนั้นต่อให้

**ทดสอบ:** เทสต์ golden เทียบข้อความไทยทุกรหัสกับค่าที่คัดลอกจากโค้ดก่อนแก้ · เทสต์อังกฤษต้องไม่มีตัวอักษรไทยและมีค่า params ครบ · เทสต์ส่งต่อรหัสจาก error ต้นทาง
