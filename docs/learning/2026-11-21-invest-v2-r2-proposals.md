# สรุปการเรียนรู้: ข้อเสนอ Invest v2 รอบที่ 2 ขั้นที่ 0 (21 พ.ย. 2569)

- **ทำอะไร:** เขียนข้อเสนอ 4 ไฟล์ใน `docs/proposals/` (Categories + RLS, กฎ R29 Rebalancing พร้อมตัวอย่างมือ, `replace_trade` + `delete_asset`, แผนและคำถาม) ยังไม่มีโค้ดหรือ migration
- **ทำไม:** เจ้าของสั่งให้สำรวจและร่างก่อนลงมือ (งานแตะฐานข้อมูลและกฎเงินใหม่)
- **ให้ผู้ตรวจ 3 ตัวอ่าน:** money-auditor เจอจุดร้ายแรงในร่าง `replace_trade` (อ่านก่อนล็อก ทำให้แก้ซ้ำแล้วซื้อซ้ำ 2 เท่า) · security-auditor เจอเรื่องล้างข้อมูลแล้วหมวดค้าง ชื่อซ้ำชั่วคราว อักขระมองไม่เห็น · investment-expert เจอว่า Rebalancing ชนกติกา "ห้ามคำแนะนำการลงทุน" ของโปรเจกต์ → แก้ร่างตามทั้งหมดแล้ว
- **บทเรียน:** ร่าง SQL ที่แตะเงินต้องให้ผู้ตรวจอ่านก่อนเสมอ (ผู้ตรวจจับบั๊กการแข่งกันเขียนที่ผมมองไม่เห็นได้) และตัวอย่างมือต้องรวมกรณีเศษไม่ลงตัว
