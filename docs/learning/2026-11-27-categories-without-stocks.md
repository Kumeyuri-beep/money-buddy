# หน้า Categories ลบหมวดได้แม้ยังไม่มีหุ้น (27 พ.ย. 2569)

## ทำอะไร
ถ้ามีหมวดค้างแต่ยังไม่มีหุ้น หน้า Categories แสดงหมวด และกด Change เพื่อแก้หรือลบได้ เดิมขึ้นแค่ "No stocks yet"
ข้อความกราฟบอกว่า "ไม่ได้ถือหุ้น" แทนการบอกว่าราคาขาด

## ทำไม
หลังนำเข้าไฟล์สำรองที่ล้มครึ่งทาง หมวดเก่าอาจค้างอยู่โดยไม่มีหุ้น ผู้ใช้ต้องลบได้

## ทดสอบอย่างไร (บนคอม)
`npm run dev` เปิด `/harness.html?seed=1&investDemo=cat&noStocks=1#/invest/portfolio/categories` กด Change ลบสองหมวด แล้วกด Save
