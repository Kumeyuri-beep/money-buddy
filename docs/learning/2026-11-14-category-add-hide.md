# เพิ่มหมวดใหม่ และซ่อนหมวดที่ไม่ใช้

## ทำอะไร
- หน้าโปรไฟล์ → "ชื่อหมวดรายรับ-รายจ่าย" → แสดงรายการหมวด: **เพิ่มหมวดใหม่** (รายจ่าย/รายรับ) ได้ · **ซ่อน** หมวดที่ไม่ใช้ได้ · ส่วน "หมวดที่ซ่อนอยู่" มี **เปิดกลับ**
- ซ่อนไม่ใช่ลบ: หมวดที่ซ่อนไม่แสดงในฟอร์มบันทึกรายการ แต่รายการเก่ายังเห็นชื่อหมวดเดิม ยอดเงินเดิมครบ ตัวกรองในหน้ารายรับ-รายจ่ายยังเลือกหมวดนั้นได้ (ติดป้าย "ซ่อนอยู่") และแก้รายการเก่าไม่ทำให้หมวดเปลี่ยนเอง
- ชื่อหมวดห้ามว่าง ห้ามซ้ำกับหมวดประเภทเดียวกัน (รวมหมวดที่ซ่อนอยู่ ให้เปิดกลับแทน) · ต้องเหลือหมวดที่ใช้งานอย่างน้อย 1 หมวดต่อประเภท (ไม่งั้นฟอร์มไม่มีหมวดให้เลือก)
- หมวดผลการลงทุนที่ระบบสร้าง (กำไร ขาดทุน ปันผล ภาษีหัก ณ ที่จ่าย) ไม่อยู่ในรายการนี้ ซ่อนหรือแก้ไม่ได้
- อยู่ในไฟล์สำรอง และนำเข้ากลับได้ครบ (รวมสถานะซ่อน)

## ทำไมต้องมีฟังก์ชันใหม่ในฐานข้อมูล
เดิมผู้ใช้แก้ตารางบัญชีได้เฉพาะคอลัมน์ชื่อ (ปิดช่องไว้เมื่อ #125 เพื่อความปลอดภัย) การซ่อนต้องแก้คอลัมน์ `archived` จึงเพิ่มฟังก์ชัน `set_category_archived` ที่ตรวจเองว่าเป็นหมวดของผู้ใช้คนนั้นจริง เขียนได้แค่สถานะซ่อน และไม่แตะข้อมูลอื่น (ไม่เปิดสิทธิ์ตารางเพิ่ม)

## ทดสอบอย่างไร
- เทสต์หน่วยโดเมน/ที่เก็บข้อมูล (สัญญาเดียวกันทั้ง Dexie และ Supabase จริง) · ไฟล์สำรองไปกลับ · เทสต์ SQL ใหม่ (ซ่อน/เปิด/ซ่อนตัวสุดท้าย/ไม่ใช่หมวด/ข้ามผู้ใช้/ยังไม่เปลี่ยนรหัสผ่าน/แก้ตรงๆยังถูกปฏิเสธ) ขึ้น TESTS_PASSED บนฐานข้อมูลจริง
- live-contract 60/60 · Playwright มืด/สว่าง × 360/1280 (เพิ่ม ซ่อน แก้รายการเก่า เปิดกลับ ซ่อนตัวสุดท้ายไม่ได้ + contrast)
- ตรวจโดย security-auditor, money-auditor, design-critic แก้ตามผลแล้ว
