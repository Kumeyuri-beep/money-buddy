# invest-v2: หน้า Portfolio → Holdings (ตารางถือครองใหม่)

## ทำอะไร
- หน้า Holdings ของโหมด /invest เปลี่ยนจากหน้าหุ้นสหรัฐเดิมเป็นตารางถือครองตามแบบร่าง 20
- มี 4 แท็บ ที่เปลี่ยนชุดคอลัมน์: My holdings / General / Dividends / Returns
- Returns แยกกำไรเป็น 6 แหล่งต่อหุ้น (กำไรราคาที่ยังไม่ขาย, ที่ขายแล้ว, ออปชั่น, ปันผล, ค่าเงิน, ค่าธรรมเนียมและภาษี) รวมกันได้เท่ากับกำไรรวมเป๊ะ (R24) · มุมมอง USD ไม่มีแหล่งค่าเงิน จึงแสดง "—"
- มีค้นหา เรียงลำดับ และ Show sold (หุ้นที่ขายหมดแล้วซ่อนไว้ก่อน)
- เมนู ⋯ ต่อแถว: Add a transaction, Open holding, Edit, Delete
  - Edit ตอนนี้เปิดฟอร์มแก้ราคา/อัตราแลกเปลี่ยนล่าสุด (ระบบยังไม่มีการแก้รายการซื้อขายที่บันทึกไปแล้ว)
  - Delete ลบทุกรายการของหุ้นตัวนั้น เรียงจากใหม่ไปเก่า ตามกติกา R17 (ห้ามลบรายการที่วันที่ ณ หรือก่อนรายการขายล่าสุด) ถ้าผิดกติกาจะไม่ลบอะไรเลย และต้องกดยืนยันก่อน
- แถวรวม "Total · N holdings" เป็นผลบวกของค่าที่แปลงสกุลแล้วของแต่ละแถว (R26) · ไม่มีราคาหรือเรต = ขึ้น "No price" / "Needs rate" และยอดรวมบอกว่าไม่ครบ (ไม่นับเป็น 0)
- คอลัมน์ Daily ยังซ่อนไว้ จนกว่าจะมีราคารายวัน (เฟส B)

## ทำไม
เจ้าของต้องการดูพอร์ตแบบตารางที่สลับสกุล USD/THB ได้ และเห็นว่ากำไรมาจากไหน โดยตัวเลขเงินทั้งหมดต้องมาจากฟังก์ชันใน `src/domain` ไม่ใช่สูตรใน component

## แกนของงาน
- `src/domain/invest/holdingsView.ts` สร้างแถว/ผลรวม/การค้นหา/การเรียง/แผนลบ โดยเรียกฟังก์ชันที่มีอยู่แล้ว (`replayWithFees`, `computeProfitSources`, `computeDividendMetrics`, `displayCurrency`) ไม่มีตัวปัดเศษใหม่
- ฟอร์มซื้อ/ขาย/ปันผล/แลกเงินเดิมยังใช้ของเดิม (ซ่อนเฉพาะตารางเก่าและหัวหน้าเก่า) ปุ่ม Add บนแถบบนยังเปิดฟอร์มเพิ่มหุ้น
