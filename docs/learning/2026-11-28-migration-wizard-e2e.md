# เทสต์หน้าจอตัวย้ายข้อมูล (28 พ.ย. 2569)

## ทำอะไร
เพิ่มเทสต์อัตโนมัติของหน้าย้ายข้อมูลจากเครื่องขึ้นออนไลน์: ต้องสำรองก่อน, ถามก่อนลบหมวด, นำเข้าล้ม, ยอดไม่ตรง
ใช้ปลายทางจำลองในหน้าทดสอบ (`src/dev/wizardDemo.ts`) ไม่แตะฐานข้อมูลจริง

## ทำไม
หน้านี้แตะข้อมูลทั้งสมุดและยังไม่เคยมีเทสต์หน้าจอ

## ที่พบ
ขั้นตรวจยอดล้นแนวนอนบนจอกว้าง 360px (ของเดิม จดรอปรับมือถือ)

## ทดสอบอย่างไร
`npx playwright test migration-wizard` · ดูเอง: `npm run dev` เปิด `/harness.html?reset=1&seed=1&wizard=ok`
