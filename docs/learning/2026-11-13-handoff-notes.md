# เรียนรู้: ใส่หมายเหตุในเอกสารเก่าแทนการแก้ประวัติ
- เอกสารเก่าที่เล่าถึง "กล่องเป้าเกษียณ" ในหน้าภาพรวม (ร่าง R18 และหัวข้อ 21 ใน HANDOFF) ยังเก็บเนื้อหาเดิมไว้เป็นประวัติ แต่มีหมายเหตุบรรทัดบนสุดว่า "ถูกแทนที่แล้ว ดู R18 ใน money-rules.md และ HANDOFF หัวข้อล่าสุด" คนมาอ่านทีหลังจะไม่เข้าใจผิดว่ากล่องนั้นยังมีอยู่
- HANDOFF หัวข้อ 34 สรุปผลการเปลี่ยนเพดานขนาด settings และจด backlog ที่ยอมรับไว้ รวมถึงสิ่งที่ยังรอเจ้าของลองบนอุปกรณ์จริง
- บันทึกความผิดพลาด: PR #96 merge ไปก่อนโดยมีเฉพาะไฟล์นี้ เพราะสคริปต์แก้เอกสารมี syntax error แล้วคำสั่งถัดมาในบรรทัดเดียวกันทำงานต่อ (ใช้ `;` แทน `&&`) จึงต้องมี PR นี้มาใส่หมายเหตุจริง · บทเรียน: คำสั่งที่ commit/push/merge ต้องต่อด้วย `&&` ทั้งสาย และตรวจผลการแก้ไฟล์ก่อนคอมมิต
