# เมนู dock บนคอม (15 พ.ย. 2569)

**ทำอะไร:** บนจอกว้าง (1024px ขึ้นไป) รายการเมนูย้ายจากแถบข้างไปอยู่ใน "dock" แถบกระจกลอยกลางล่างของจอ ไอคอนขยายตามเมาส์เหมือน dock ของ macOS ปุ่ม "เพิ่มรายการ" สีทองอยู่ซ้ายสุด มือถือและแท็บเล็ตไม่เปลี่ยน

**ทำไมทำแบบนี้**
- ขยายด้วย `transform: scale` อย่างเดียว ไม่เปลี่ยนความกว้าง/สูง ของจริงจึงไม่ดันของข้างๆ และเบามาก (ไม่ต้องคำนวณ layout ใหม่)
- เขียนสูตรเองในไฟล์ `src/ui/dockMagnify.ts` (ไม่เพิ่มไลบรารี): ยิ่งใกล้เมาส์ยิ่งใหญ่ ลดลงแบบโค้งนุ่มๆ แล้วเลื่อนไอคอนข้างๆ ออกเล็กน้อยไม่ให้ทับกัน
- ทุกไอคอนเป็นปุ่มจริง กด Tab ไปถึง Enter/Space ใช้ได้ ชื่อหน้าขึ้นเป็นป้ายตอนเมาส์ชี้และตอนโฟกัสด้วยคีย์บอร์ด (กด Esc ซ่อนได้)
- ถ้าตั้งค่า "ลดการเคลื่อนไหว" จะไม่ขยายเลย ตำแหน่งนิ่ง

**ทดสอบอย่างไร:** เทสต์หน่วยของสูตร (0, ขอบรัศมี, สมมาตร, ไม่ทับกัน) + Playwright 1280/1440 × มืด/สว่าง (คีย์บอร์ดล้วน, เมาส์ขยาย, ไม่บังเนื้อหาท้ายหน้า, ต่ำกว่า 1024px ไม่มี dock) + วัดขนาด bundle ก่อน/หลัง
