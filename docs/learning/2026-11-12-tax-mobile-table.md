# เรียนรู้: ตารางภาษีบนมือถือ
- ตารางค่าลดหย่อน 17 แถว มี 4 คอลัมน์ บนจอ 360px ต้องเลื่อนซ้ายขวาและชื่อรายการกินที่จนตัวเลขเหลือน้อย
- บนจอ ≤720px เปลี่ยนเป็น "การ์ดต่อรายการ": ชื่อรายการอยู่บนสุด ใต้ลงมาเป็นบรรทัดป้าย–ตัวเลข (ที่คุณกรอก / ใช้ได้ / สิทธิที่ยังใช้ได้) ไม่ต้องเลื่อนข้าง
- ป้ายหน้าตัวเลขมาจาก `data-label` ใน HTML ผ่าน CSS (ไม่ซ้ำข้อความสองที่) หัวตารางเดิมยังอยู่ ซ่อนแบบที่โปรแกรมอ่านจอยังอ่านได้
- เดสก์ท็อป (>720px) ไม่เปลี่ยน
- ทดสอบ: `npm test` (ตรวจ data-label ครบ, CSS ซ่อนหัวตารางแบบที่ยังอ่านได้) · ยังไม่ได้เปิดดูบนมือถือจริง ขอให้เจ้าของลองลดความกว้างเบราว์เซอร์เหลือ ~360px
- ผลตรวจ design-critic (ไม่ขัดดีไซน์ เดสก์ท็อปไม่กระทบ): ข้อสูง 1 ข้อ — `display:block` ทำให้โปรแกรมอ่านจอเสียความหมายตาราง แก้โดยใส่ role (table/rowgroup/row/columnheader/rowheader/cell) ตรงๆ ใน HTML · แก้ป้าย "เลื่อนซ้ายขวา" ที่ไม่จริงแล้ว · ตัวเลขห้ามตัดบรรทัด ป้ายยาวพับแทน · ตารางขั้นบันไดใช้แบบเรียงซ้อนเหมือนกัน
- ที่ยังควรลอง: โปรแกรมอ่านจอจริง (NVDA) 1 รอบ เพราะป้ายหน้าตัวเลขอาจถูกอ่านซ้ำกับหัวคอลัมน์
