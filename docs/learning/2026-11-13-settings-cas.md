# เรียนรู้: สองแท็บแก้ค่าตั้งค่าพร้อมกัน

**ทำอะไร:** เมื่อเปิดแอปสองแท็บแล้วเพิ่มแผน DCA / ติดป้ายภาษี / เลือกสินทรัพย์เกษียณ / บันทึกฟอร์มค่าตั้งค่าพร้อมกัน เดิมแท็บที่บันทึกทีหลังจะทับของแท็บแรก ตอนนี้ระบบ "เทียบก่อนเขียน" (compare-and-set): ถ้าค่าที่เคยอ่านมาเปลี่ยนไปแล้ว จะอ่านใหม่แล้วคำนวณใหม่ (กรณีเพิ่ม/เอาออกทีละรายการ) หรือแจ้งให้โหลดค่าล่าสุดก่อน (กรณีฟอร์ม)

**ทำไม:** กันข้อมูลหายเงียบๆ โดยผู้ใช้ไม่รู้ตัว

**ทดสอบอย่างไร:** เทสต์หน่วย (ตัวช่วยเทียบคีย์, ขอบเขตคีย์), เทสต์สัญญาที่ทั้งในเครื่องและออนไลน์ต้องผ่านเหมือนกัน, เทสต์ SQL ของฟังก์ชันใหม่, และเทสต์จริงที่ให้สองแท็บเพิ่มรหัสพร้อมกัน 6 รอบ ต้องได้ครบ 12 รหัส

**บทเรียน:** เทสต์จริงจับได้ว่าเวอร์ชันแรกของฟังก์ชันฐานข้อมูลค้างเมื่อสองคำขอมาพร้อมกัน พบว่ารหัส error 40001 ทำให้คำขอที่แพ้ค้างราว 60 วินาที จึงเปลี่ยนเป็นรหัส PT409 (และล็อกต่อผู้ใช้ก่อนอ่าน-เทียบ-เขียน)
