# เรียนรู้: Sankey เป็นกราฟแท่งบนมือถือ
เจ้าของตัดสิน (13 พ.ย. 2569): จอคอมคง Sankey ส่วนมือถือ (≤720px) เป็นกราฟแท่งแนวนอน "แหล่งเงิน" และ "เงินไปไหน" (ชื่อ · จำนวนเงิน · แท่ง · %) สีตามประเภทเดียวกับ Sankey · แทนที่รายการตัวหนังสือที่ทำไว้ใน #112 · กราฟแท่งเป็นภาพ (aria-hidden) ข้อมูลชุดเดียวกันอยู่ในตารางที่ซ่อนไว้ให้โปรแกรมอ่านจอทุกขนาดจอ · ความกว้างแท่งเป็นแค่การจัดวาง (ไม่ใช่ยอดเงิน) ใช้ % จากข้อมูลที่ domain คำนวณไว้แล้ว ไม่คำนวณเงินใหม่
