# แก้ถ้อยคำ R27: ค่ากึ่งกลางพอดีปัดสมมาตร

**ทำอะไร:** แก้สูตรใน R27 (ผลตอบแทนรวมหลายเดือน) จากปัดที่ "ผลคูณ" เป็นปัดที่ "ผลตอบแทน" ครึ่งออกจากศูนย์

**ทำไม:** แบบเดิมปัดไม่สมมาตรเมื่อค่าตกกึ่งกลางพอดี (+149.5 ได้ +150 แต่ −149.5 ได้ −149) เจ้าของสั่งเมื่อ 18 พ.ย. 2569 ให้ปัดเหมือน R24.5/R26 คือครึ่งออกจากศูนย์ ทั้งกำไรและขาดทุน

**ทดสอบอย่างไร:** เอกสารล้วน ตัวอย่างเดิมในกฎยังได้ค่าเดิม (+2,176, −1,450, +100, −6) และเพิ่มตัวอย่าง tie (+151, −150) โค้ดที่ทำตามกฎนี้อยู่ใน PR #221
