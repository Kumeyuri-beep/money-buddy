# invest-v2: หน้า My goal (R28)

**ทำอะไร:** หน้า Portfolio → My goal ตั้งเป้า "มูลค่าพอร์ต" หรือ "รายได้ปันผลต่อเดือน" พร้อมวันที่อยากถึง เงินเพิ่มต่อเดือน ผลตอบแทนคาดหวังต่อปี และเงินเฟ้อ (ไม่บังคับ) แล้วกด Save and calculate จะเห็นกราฟ เส้นเป้า ปีที่ถึงเป้า และสถานะ On track / Behind

**ทำไม:** ให้เห็นภาพว่าเป้าไกลแค่ไหน โดยต้องบอกชัดทุกจุดว่านี่คือ **ประมาณการ ไม่ใช่คำสัญญา** ("Projection, not a promise")

**ทำอย่างไร:**
- สูตรอยู่ใน `src/domain/invest/goalProjection.ts` ใช้จำนวนเต็ม BigInt ล้วน ปัดครึ่งออกจากศูนย์ ไม่มีทศนิยมลอยตัว ตามกฎ R28
- ถ้าไม่มีราคา/เรต หรือเป้ารายได้แต่ไม่มี yield จะขึ้น "Needs data" ไม่เดา
- เป้าที่ตั้งเก็บใน settings ฟิลด์ `investGoal` (ต่อผู้ใช้ ไม่ใช่ยอดเงินจริง ไม่ลงสมุด ไม่มี migration)
- เงินเพิ่มต่อเดือนเสนอค่าเฉลี่ยจากรายการซื้อจริง 12 เดือนล่าสุด แก้ได้

**ทดสอบ:** เทสต์หน่วยตัวอย่างมือ R28 (V1=111,000 V2=122,110 V3=133,331 ถึงเป้าเดือนที่ 3 · เป้ารายได้ถึงเดือนที่ 2) และขอบเขต (เป้า 0, ไม่ถึงใน 1,200 เดือน, i=r) · Playwright 1280/1440/360/390
