# สรุปการเรียนรู้: เมนูย่อยแถบบน /invest ปิดเองเมื่อหน้าเลื่อนใต้เมาส์ (20 พ.ย. 2569)

- **ปัญหา:** เทสต์เมนูย่อยที่ 390px ล้มเป็นพักๆ (คลิกลิงก์ในเมนูย่อยแล้ว "element was detached") ซ้ำได้ราว 3% เมื่อรันขนาน
- **สาเหตุที่พิสูจน์แล้ว (จาก log เหตุการณ์ pointer):** เมื่อเมนูย่อยยาวเกินขอบจอ ต้องเลื่อนหน้า พอหน้าเลื่อน เมาส์ที่ไม่ได้ขยับไปอยู่นอกเมนู (หรือไปอยู่เหนือเมนูอื่น) เบราว์เซอร์จึงส่ง pointerleave/pointerenter แบบสังเคราะห์ โค้ดเดิมปิดเมนูตาม (หรือสลับไปเมนูอื่น) ลิงก์ที่กำลังจะคลิกจึงหาย · เป็นบั๊กจริงของผู้ใช้เมาส์บนหน้าต่างแคบ/เตี้ย (ไม่ใช่การแตะบนมือถือ)
- **แก้อย่างไร:** จำตำแหน่งเมาส์ล่าสุดในแถบ ถ้า pointerleave/pointerenter ที่เกิดขึ้นตำแหน่งเดิม (เมาส์ไม่ได้ขยับ) ไม่ปิด/ไม่สลับเมนู · ผู้ใช้ขยับเมาส์ออกจริง เมนูปิดเหมือนเดิม · ไม่ใช้ retry หรือรอเวลาเพิ่ม
- **ทดสอบ:** `invest-nav-scroll.spec.ts` (เตี้ย 1280x420 ล้มก่อนแก้ ผ่านหลังแก้) + รันซ้ำ `invest-mode`/`invest-analysis` ทุกความกว้าง 272 ครั้งผ่านหมด (เดิมล้ม ~3%)
