# เรียนรู้: เฟส 0 ของภาษี (กฎ R19 + config ปี 2569)
- เจ้าของอนุมัติกฎ R19 แล้ว จึงเขียนลง `docs/money-rules.md` เป็น commit แยก (ย้อนดูง่าย)
- ตัวเลขกฎหมายทุกตัวอยู่ใน `src/domain/tax/config.ts` ไฟล์เดียว แต่ละตัวมีลิงก์ที่มาและระดับความมั่นใจ (verified/partial/unverified) ปีหน้าแก้ไฟล์เดียวพอ
- ประกันสังคมปี 2569 เพดานค่าจ้างเปลี่ยนแล้วแต่ยังไม่มีต้นฉบับทางการที่อ่านได้ จึงติดป้าย "ยังไม่ยืนยัน" และใช้ค่าเดิม 9,000 แบบปลอดภัย (ภาษีออกมาสูงกว่าจริงนิดหน่อย ไม่ต่ำกว่าจริง)
- เว็บ ก.ล.ต. ปฏิเสธการโหลดไฟล์จากเครื่องผม (403) ผมไม่พยายามอ้อมการบล็อก ใช้คำยืนยันของเจ้าของแทนและจดไว้
- ทดสอบ: `tests/unit/taxConfig.test.ts` ตรวจขั้นบันไดเรียงถูก ตัวเลขเป็นจำนวนเต็มสตางค์ ทุกค่ามีที่มา

## ปรับ 12 พ.ย. 2569 (รอบถัดมา)
- แก้ถ้อยคำ R19 4 ข้อตามที่เจ้าของอนุมัติ (commit แยก): ค่า unverified ต้องมีทั้งอนุมัติและป้าย · ช่วงสูงสุดข้อมูลเข้าอยู่ใน config · ขีดวิธีที่ 2 เข้า config ก่อนใช้ · เพดานกลุ่มตัดตามลำดับคงที่
- เพดานลดหย่อนประกันสังคมใน config เปลี่ยนเป็น 10,500 บาท/ปี (เพดานค่าจ้าง 17,500 × 5% × 12) เจ้าของอนุมัติตามข่าว ยังติดป้าย "ยังไม่ยืนยัน" จนกว่าจะมีแหล่งทางการ ผู้ใช้กรอกยอดที่จ่ายจริงตามสลิป
