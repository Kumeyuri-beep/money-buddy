# แถวสินทรัพย์ในหน้าพอร์ตบนมือถือ

**ทำอะไร:** เดิมตัวเลขของสินทรัพย์ (ถือกี่หน่วย ต้นทุน ราคา มูลค่า กำไร/ขาดทุน ฯลฯ) ถูกต่อเป็นข้อความบรรทัดยาวคั่นด้วย "·" บนมือถือ 360px ชื่อยาวหรือตัวเลขยาวจึงดันกันตกบรรทัดอ่านยาก ตอนนี้แต่ละค่าอยู่คนละบรรทัด: ป้ายอยู่ซ้าย ค่าอยู่ขวา ชื่อยาวขึ้นบรรทัดใหม่ในที่ของตัวเอง (บนจอใหญ่จัดเป็นหลายคอลัมน์)

**ไม่เปลี่ยนอะไร:** ค่าทุกตัวมาจากตัวคำนวณพอร์ตตัวเดิม (`buildPortfolio`) ไม่มีสูตรเงินใหม่ในหน้าจอ เป็นการจัดรูปแบบการแสดงผลอย่างเดียว เงื่อนไขการซ่อน/แสดงแต่ละแถวเหมือนเดิม (เช่น ไม่มีกำไรที่ขายแล้ว = ไม่แสดงแถว "ขายแล้ว")

**ทดสอบอย่างไร:** เทสต์ด้วยข้อมูลสมมติที่มีชื่อยาวมาก (ตัวเลขทุกอย่างอยู่ในแถวป้าย/ค่าของตัวเอง, ราคาเก่า, ไม่มีราคา, ข้อมูลผิดพลาด, ซ่อนแถวที่ไม่มีค่า) และเทสต์ CSS (ชื่อตัดบรรทัดได้, ตัวเลขไม่ถูกตัดกลาง, กริดไม่ล้นจอ 360px) หน้าพอร์ตเป็นแบบออนไลน์เท่านั้น จึงรอเจ้าของลองบนมือถือจริงด้วยข้อมูลสมมติ
