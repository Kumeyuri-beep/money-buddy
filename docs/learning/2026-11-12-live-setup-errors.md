# เรียนรู้: ทำให้ error ทุกแบบของชุดทดสอบจริงอ่านออก
- รอบก่อนแก้เฉพาะข้อความ "ลืมตั้งสวิตช์" รอบนี้ครอบคลุม error อื่นของขั้นเตรียม/เก็บกวาด (เช่น ไม่พบไฟล์ตั้งค่า, ลบผู้ใช้ทดสอบไม่สำเร็จ)
- พิมพ์เฉพาะข้อความ ไม่พิมพ์ stack กันข้อมูลหลุด
- ทดสอบ: ไม่ตั้งสวิตช์ต้องเห็นข้อความ · ตั้งสวิตช์ต้องผ่านครบ 45/45 (ไม่ได้จำลองกรณีไฟล์ตั้งค่าหาย เพราะห้ามแตะไฟล์นั้น)
