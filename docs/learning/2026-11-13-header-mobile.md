# เรียนรู้: Header บนมือถือ
เจ้าของมอบให้ design-critic ตัดสิน (13 พ.ย. 2569) ตราบที่ไม่ขัดเมนู pop up: บนมือถือ (≤720px) ซ่อนปุ่ม "+ เพิ่มรายการ" ใน Header (ซ้ำกับรายการแรกของเมนู pop up, ช่องจดด่วน และการ์ดเริ่มต้น 3 ขั้น) แล้วให้ "สแกนสลิป" เป็นปุ่มเต็มแถว (เหลือ 2 แถว: ช่องจดด่วน + สแกนสลิป) · ซ่อนด้วย CSS `display: none` ซึ่งถอดปุ่มออกจากลำดับ Tab และโปรแกรมอ่านจอพร้อมกัน · จอใหญ่ไม่เปลี่ยน
