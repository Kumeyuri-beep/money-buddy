# โครงรหัส error (17 พ.ย. 2569)

**ปัญหา:** ข้อความ error ใน domain/app/storage เป็นประโยคไทยที่ฝังตัวเลขไว้ โหมด /invest ต้องเป็นอังกฤษแต่หน้าอื่นต้องไทยเหมือนเดิม

**วิธี:** error แต่ละแบบมี "รหัส" และ "พารามิเตอร์" (เช่น จำนวนหน่วยที่ขายเกิน) แล้วมีแม่แบบข้อความไทยและอังกฤษที่ใช้พารามิเตอร์ชุดเดียวกัน ข้อความไทยที่ error ถือยังเหมือนเดิมทุกตัวอักษร (มีเทสต์เทียบ) ส่วน /invest ใช้ \`investError\` ดึงข้อความอังกฤษจากรหัส

**PR นี้:** วางโครงอย่างเดียว (\`src/domain/errors/coded.ts\`, \`src/ui/invest/investError.ts\`) ยังไม่เปลี่ยน error ตัวไหน PR ถัดไปจะย้ายทีละกลุ่ม: domain → ฟอร์ม app → storage → ภาพการ์ดแชร์
