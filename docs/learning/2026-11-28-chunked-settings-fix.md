# บั๊ก: นำเข้าไฟล์ใหญ่ที่มีค่าตั้งค่าไม่ได้ (28 พ.ย. 2569 · ยังไม่ได้ใส่ฐานข้อมูล)

## อาการ
ไฟล์สำรองเกิน 1,500 รายการ (หรือบรรทัดรวมเกินเพดานต่อคำสั่ง) ที่มีค่าตั้งค่า เช่น วันเงินเดือน จะถูกฐานข้อมูลปฏิเสธตั้งแต่ก้อนแรก ไม่มีข้อมูลเข้าเลย

## สาเหตุ
ระหว่างนำเข้าแบบแบ่งก้อน ฐานข้อมูลล็อกไม่ให้เขียนทางอื่น ฟังก์ชันปิด "กุญแจนำเข้า" เร็วไปหนึ่งขั้น จึงเขียนค่าตั้งค่าของตัวเองไม่ได้

## แก้อย่างไร
ย้ายการเขียนค่าตั้งค่าให้อยู่ก่อนปิดกุญแจ (migration `20261128000200_import_begin_settings.sql`)

## ทดสอบอย่างไร
รันเทสต์ SQL แบบย้อนกลับ: ก่อนแก้ `import_chunked_settings_test.sql` ล้มด้วย 42501 · เมื่อใส่ migration ชั่วคราวผ่าน
