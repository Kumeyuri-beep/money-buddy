# การ์ดเงินเข้า-ออกบนมือถือ: ปุ่มสลับ แผนภาพ / รายการ

## ทำอะไร
- มือถือ (จอกว้างไม่เกิน 720px) มีปุ่ม "แผนภาพ | รายการ" ค่าเริ่มต้นเป็นแผนภาพ (Sankey) · "รายการ" คือกราฟแท่งเดิม · จอใหญ่เป็น Sankey เดิมไม่มีปุ่ม
- แผนภาพมือถือวาดใหม่แบบกะทัดรัด กว้างพอดีการ์ดที่ 360px จึงไม่ต้องเลื่อนซ้ายขวา: ป้ายสั้น (ชื่อตัดที่ 8 ตัวอักษร + เปอร์เซ็นต์) ไม่แสดงยอดบนป้าย **แตะชื่อหรือแถบสี** แล้วเห็นชื่อเต็ม + ยอด + สัดส่วนในกล่องใต้แผนภาพ (ใช้คีย์บอร์ด Enter/Space ได้)
- จำมุมมองที่เลือกใน settings คีย์ `cashFlowView` ผ่าน merge_settings (เก็บเฉพาะ "รายการ" เลือก "แผนภาพ" = ลบคีย์ = ค่าเริ่มต้น) ตามผู้ใช้ไปทุกเครื่อง

## ทำไม
กราฟแท่งอย่างเดียว (ตัดสินใจ 13 พ.ย.) เสียภาพรวมการไหลของเงิน เจ้าของอยากได้ Sankey กลับมาแต่ต้องอ่านได้บนจอเล็ก

## ทดสอบอย่างไร
- เทสต์หน่วย: คีย์ settings ใหม่ (ตรวจ/ล้าง/patch/ที่เก็บทั้งสองแบบ) · ฟังก์ชันตัดชื่อ (ไม่ตัดสระ/วรรณยุคขาด) · ขนาดแผนภาพ
- Playwright (`tests/e2e/cashflow.spec.ts`) มืด/สว่าง × 360/390/1280: ไม่ล้นจอ ป้ายอยู่ในกรอบ จุดแตะ ≥ 30px แตะแล้วเห็นยอด จำค่าหลังโหลดใหม่ (รอให้บันทึกลง IndexedDB จริงก่อนโหลดใหม่ เพราะรอบแรกมีเทสต์ล้มจากการโหลดซ้ำเร็วกว่าการบันทึก) คีย์บอร์ด · จอใหญ่ไม่มีปุ่ม · เทสต์ contrast เดิมครอบคลุมป้ายใหม่
- design-critic ตรวจแล้วแก้: ฟอนต์จริง 12px (วาดขนาด 1:1), ระยะแท่ง, วงโฟกัสไม่ถูกตัด, ปุ่มที่เลือกมีเครื่องหมาย ✓ (ไม่พึ่งสีอย่างเดียว), ป้ายที่เลือกหนาขึ้น, ป้ายเสียงอ่านบอกฝั่ง (แหล่งเงิน/ปลายทาง)
