# แสดงวันที่ดาวน์โหลดสำรองล่าสุดในหน้าโปรไฟล์

**ทำอะไร:** ใต้ปุ่ม "ดาวน์โหลดข้อมูลของฉัน" มีบรรทัดบอกว่าสำรองไว้ล่าสุดเมื่อไหร่ เช่น "ดาวน์โหลดสำรองล่าสุด: 13 พฤศจิกายน 2569 (7 วันที่แล้ว)" หรือ "ยังไม่เคยดาวน์โหลดข้อมูลสำรอง" ถ้าอ่านค่าตั้งค่าไม่ได้ จะบอกว่า "อ่านวันที่… ไม่ได้" (ไม่บอกว่าไม่เคย เพื่อไม่ให้เข้าใจผิด)

**ข้อมูลมาจากไหน:** วันที่ที่จดไว้ตอนดาวน์โหลดสำเร็จ (`lastBackupAt` ในค่าตั้งค่า ตัวเดียวกับที่แถบเตือนบนหน้าภาพรวมใช้) หลังกดดาวน์โหลดสำเร็จ บรรทัดนี้อัปเดตทันที

**ทดสอบอย่างไร:** เทสต์ข้อความ (ไม่เคย/วันนี้/กี่วันที่แล้ว/ข้ามปี/วันที่ในอนาคต) และเทสต์ว่าหน้าโปรไฟล์ต่อสายถูก · ลองบนมือถือจริงด้วย
