# รหัส error ของชั้นเก็บข้อมูล (storage)

## ทำอะไร
error ที่ชั้น `src/storage/` โยนออกมา (เช่น "ไม่พบสินทรัพย์นี้", "ชื่อกระเป๋าต้องยาว 1-200 ตัวอักษร", ข้อมูลจากเซิร์ฟเวอร์ผิดรูป, เชื่อมต่อไม่ได้, ค่าตั้งค่าชนกัน) ตอนนี้มี "รหัส" (`store.xxx`) และ "ค่า" (params) ติดไปกับ error ด้วย
ข้อความไทยยังเหมือนเดิมทุกตัวอักษร (หน้าอื่นไม่เปลี่ยน) แต่โหมด /invest เอารหัสไปแสดงเป็นอังกฤษได้

## ทำไม
เดิมข้อความไทยฝังอยู่ในประโยค ฝั่งอังกฤษแปลไม่ได้โดยไม่เดา การแยกเป็นรหัส + ค่า ทำให้แปลได้ตรงและเลขไม่หาย

## ทดสอบอย่างไร
- `tests/unit/errorCodes-storage.test.ts` เขียนก่อนแก้โค้ด: เก็บข้อความไทยเดิมเป็น golden แล้วเรียกฟังก์ชันจริง ผ่านทั้งก่อนและหลังแก้
- ทุกรหัสมีเทสต์อังกฤษ (ไม่มีตัวอักษรไทย, ค่า params อยู่ครบ)
- ไม่เปลี่ยนเงื่อนไข ลำดับตรวจ หรือการเรียกฐานข้อมูล แค่เปลี่ยนวิธีสร้างข้อความ

## ที่ยังไม่มีรหัส
- ข้อความไทยที่ฐานข้อมูลส่งมาเอง และข้อความ "problem" ที่ domain คืนมาเป็น string (checkTradeAdd/checkTradeDelete, ค่าตั้งค่า) เป็นของงาน domain
- error ของหน้าอื่น (บิล รายการบัญชี นำเข้า/ล้างข้อมูล)
