# โหมดสว่าง เฟส 3: ปุ่มเลือกธีมในหน้าโปรไฟล์

## ทำอะไร
- หน้าโปรไฟล์มีการ์ด "สีหน้าจอ" เลือกได้ 3 แบบ: ตามเครื่อง (ค่าเริ่มต้น) / มืด / สว่าง
- เลือกแล้วเปลี่ยนทันที และจำไว้ 2 ที่: ในบัญชี (คีย์ `theme` ผ่าน updateSettings/merge_settings ตามผู้ใช้ไปทุกเครื่อง) และในเครื่อง (`mb.theme`)
- ไฟล์ `public/theme-init.js` ตั้งธีมก่อนวาดหน้า จอจึงไม่กะพริบมืดแล้วค่อยสว่าง (ต้องเป็นไฟล์แยกเพราะ CSP ห้ามสคริปต์ในหน้า)
- สีแถบบนมือถือ (`theme-color`) เปลี่ยนตามโหมด รวมถึงตอนเครื่องสลับมืด/สว่างเอง

## ทำไม
- ผู้ใช้บางคนอยากฝืนค่าเครื่อง และอยากให้ค่าที่เลือกตามไปทุกเครื่อง
- ไม่มี migration: ค่าตั้งค่าเก็บเป็น JSON ฐานข้อมูลไม่จำกัดชื่อคีย์ · ไม่แตะเงิน

## ทดสอบอย่างไร
- เทสต์หน่วย: ฟังก์ชันธีม, สคริปต์ตรงกับโค้ด, ค่าตั้งค่า theme (ตรวจ/ล้าง/patch), ที่เก็บข้อมูลทั้งสองแบบ
- Playwright (`tests/e2e/theme.spec.ts`): เลือกสว่าง/ตามเครื่อง/มืด, จำหลังโหลดใหม่ (ตรวจตั้งแต่ DOM พร้อม), สีแถบมือถือ, ใช้ลูกศรคีย์บอร์ด
- มืดเหมือนเดิม: เทียบภาพ 27 จาก 30 ตรงเดิม (อีก 3 ภาพคือหน้าโปรไฟล์ที่มีการ์ดใหม่)
