# เรียนรู้: ย้าย "สำรองข้อมูล" และ "ล้างข้อมูลและเริ่มใหม่" ไปหน้าโปรไฟล์
เจ้าของตัดสิน (13 พ.ย. 2569): ปุ่มแดง "ล้างข้อมูลและเริ่มใหม่" กับ "สำรองข้อมูล" เคยอยู่ท้ายแถบข้าง ซึ่งบนมือถือขึ้นบนสุดของทุกหน้า กดพลาดง่าย → ย้ายไปหน้าโปรไฟล์ทุกขนาดจอ · หน้าโปรไฟล์มีปุ่ม "ดาวน์โหลดข้อมูลของฉัน" (สำรองข้อมูล) อยู่แล้ว จึงลบปุ่มซ้ำออกจากแถบข้าง · เพิ่มส่วน "ล้างข้อมูลและเริ่มใหม่" (กรอบแดง ก่อนส่วนลบบัญชี) ที่เรียกขั้นตอนเดิม (ยืนยัน + ถามรหัสผ่าน ฝั่งฐานข้อมูลจำกัดการลอง) · ไม่เปลี่ยนพฤติกรรมการล้าง
