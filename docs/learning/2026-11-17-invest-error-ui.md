# ต่อรหัส error เข้าหน้าจอ /invest (17 พ.ย. 2569)

**ทำอะไร:** หน้า /invest (ซื้อขาย หุ้นสหรัฐ แผนซื้อประจำ โอนเข้าออกพอร์ต โหลดข้อมูล) แสดง error เป็นอังกฤษจากรหัส พร้อมตัวเลข (เช่น จำนวนที่ขายเกิน) ส่วนหน้าอื่นใช้ `friendlyError` ไทยเหมือนเดิม

**ตัวช่วย:** `investError(e)` สำหรับ error ที่โยน · `investProblem({message, code, params})` สำหรับข้อความรายช่อง/แถว · ไม่มีรหัส = ข้อความสำรองอังกฤษ (ไม่โชว์ไทยดิบ)

**ทดสอบ:** error จริงจากฟอร์ม domain และ storage แสดงอังกฤษไม่มีตัวอักษรไทย ส่วนข้อความไทยที่ error ถือยังเหมือนเดิม (เช่น SettingsConflictError)
