# นำเข้าไฟล์ใหญ่ไม่รู้ผล: ให้แอปตรวจยอดเอง (27 พ.ย. 2569)

## ทำอะไร
เมื่อคำตอบของการนำเข้าไฟล์ใหญ่หาย หน้านำเข้าไฟล์สำรองอ่านข้อมูลออนไลน์มาเทียบกับไฟล์ทันที
- ยอดตรง: มีปุ่มนำเข้าข้อมูลลงทุนต่อ (ถ้าไฟล์ไม่มี ก็ไปหน้าตรวจยอด)
- ยอดไม่ตรง: แสดงหน้าผลตรวจที่ยังไม่ให้ใช้งานต่อ
- อ่านไม่ได้: บอกว่ายืนยันผลไม่ได้ ให้โหลดหน้าใหม่

## ทำไม
เดิมผู้ใช้ไม่มีทางนำเข้าข้อมูลลงทุนต่อ และถ้ายอดไม่ตรง การโหลดหน้าใหม่จะเข้าแอปได้โดยไม่เห็นคำเตือน

## ทดสอบอย่างไร (บนคอม)
`npm run dev` เปิด `/harness.html?reset=1&importRetry=unconfirmed,ok&online=empty` เลือกไฟล์ `tests/fixtures/import-retry-backup.json`
เปลี่ยน `unconfirmed` เป็น `unconfirmed-wrong` เพื่อดูกรณียอดไม่ตรง
