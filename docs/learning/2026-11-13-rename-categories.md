# เปลี่ยนชื่อหมวดรายรับ-รายจ่าย

**ทำอะไร:** หน้าโปรไฟล์มีการ์ด "ชื่อหมวดรายรับ-รายจ่าย" เปลี่ยนชื่อที่แสดงของหมวดได้ แบบเดียวกับชื่อกระเป๋า

**กติกา:** เปลี่ยนแค่ชื่อที่แสดง ไม่แตะรหัสบัญชี ยอด หรือรายการ · ชื่อห้ามว่าง ห้ามยาวเกิน 200 ตัว ห้ามมีอักขระมองไม่เห็น · ห้ามซ้ำกับหมวดอื่น **ประเภทเดียวกัน** (รายรับกับรายจ่ายใช้ชื่อเดียวกันได้ เช่น "อื่นๆ") · ไม่เปลี่ยนชื่อให้ผู้ใช้เอง · หมวดผลการลงทุนที่ระบบสร้าง (กำไร ขาดทุน ปันผล ภาษีหัก ณ ที่จ่าย) กับยอดยกมา เปลี่ยนไม่ได้

**ทำไมปลอดภัย:** สิทธิ์ฐานข้อมูลของผู้ใช้แก้ได้เฉพาะคอลัมน์ `name` อยู่แล้ว (PR #125) และคำสั่งเขียนระบุชนิดบัญชีซ้ำที่ฝั่งฐานข้อมูลด้วย จึงแก้อย่างอื่นไม่ได้ต่อให้โค้ดผิด

**ทดสอบอย่างไร:** เทสต์ฟังก์ชันตรวจชื่อ, เทสต์สัญญาที่เก็บข้อมูล (เครื่องและออนไลน์ใช้ชุดเดียวกัน: ยอด/รายการ/รหัสไม่เปลี่ยน), เทสต์หน้าจอ และชุดทดสอบจริง `admin:live-contract`
