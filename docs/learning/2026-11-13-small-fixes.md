# เรียนรู้: จุดเล็กจากผลสำรวจผู้ใช้ใหม่

- ปุ่ม "สำรองข้อมูล" ที่แถบข้าง ถ้าดาวน์โหลดพลาดเดิมเงียบ ตอนนี้มีข้อความแจ้ง (สำเร็จ/ไม่สำเร็จ)
- คำอธิบายปุ่มสแกนสลิป (ที่โปรแกรมอ่านจออ่าน) ไม่เริ่มด้วย "กด Ctrl+V" ซึ่งมือถือไม่มี
- ลิงก์ในรายการล่าสุดเปลี่ยน "ดูสมุดบัญชี" เป็น "ดูรายรับ-รายจ่ายทั้งหมด" ให้ตรงชื่อเมนู
- ลบไฟล์ `src/sampleLedger.ts` ที่เหลือจากขั้นแรกและไม่มีที่ไหนเรียกใช้ (ค้นแล้วไม่มีการอ้างถึง)

ทดสอบ: เทสต์ซอร์ส · typecheck · build ผ่าน
