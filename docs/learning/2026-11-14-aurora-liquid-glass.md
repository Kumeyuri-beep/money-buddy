# พื้นหลังออโรรา + กระจกโปร่งแสงทั้งแอป

## ทำอะไร
- พื้นหลังทั้งแอปเป็นก้อนแสงโทนม่วงเข้มกับทอง (โหมดสว่างเป็นโทนอ่อน) วาดด้วย CSS gradient ล้วน ไม่มีรูปจากที่อื่น · ขยับช้ามาก (หลายนาทีต่อรอบ) เฉพาะคอม
- การ์ดหน้า แถบเมนู และหัวหน้า เป็นกระจกโปร่งแสงเห็นพื้นหลังเบลอทะลุ · รายการและตาราง (พื้นทึบ) ยังทึบเพื่ออ่านง่าย
- ผู้ที่ตั้ง "ลดความโปร่งใส" เห็นการ์ดทึบแบบเดิมและไม่มีพื้นหลังออโรรา · ผู้ที่ตั้ง "ลดการเคลื่อนไหว" เห็นพื้นหลังนิ่ง

## ทำไมออกแบบแบบนี้ (ประสิทธิภาพ)
- ก้อนแสงเดิมใช้ `filter: blur(90px)` (แพง) → เปลี่ยนเป็น radial-gradient ซึ่งนุ่มอยู่แล้ว ไม่ต้องใช้ filter
- วัดจริง (เบราว์เซอร์ headless ไม่มี GPU จึงเป็นกรณีเลวร้าย): พื้นหลังขยับเรียบๆ ทำให้ต้องเบลอใหม่ทุกเฟรม (นิ่งอยู่แล้วช้าลงถึง ~26ms) → เปลี่ยนเป็นขยับทีละขั้นช้ามาก (`steps()` ประมาณวินาทีละขั้น ไม่เห็นเป็นขั้น) ตอนนิ่งกลับมา 16.7ms (60fps)
- ตอนเลื่อนหน้า พื้นหลังหยุดชั่วคราว และมีตัวป้องกัน: ถ้าเครื่องช้า (เฟรมเฉลี่ย > 34ms ขณะเลื่อน) ระบบปิด blur ของการ์ดหน้าให้เอง (การ์ดยังโปร่งแสง ตัวหนังสือยังผ่านเกณฑ์เท่าเดิม)
- ห้าม blur ซ้อนกัน (เทสต์ตรวจทุกหน้า) · มือถือ: blur เบากว่า พื้นหลังนิ่ง แถบหัวหน้าไม่ blur
- **ข้อควรรู้:** ตอนเลื่อนหน้าบนคอมที่ไม่มี GPU การ์ดหน้าที่ blur เพิ่มทำให้เฟรมเฉลี่ย ~19ms → ~26ms ในเครื่องวัด (เครื่องจริงที่มี GPU น่าจะดีกว่า) ตัวป้องกันเครื่องช้าคือทางหนีไฟ

## ความอ่านออก (WCAG AA)
เทสต์ contrast คำนวณจากกรณีพื้นหลังเลวร้ายที่สุด (ก้อนแสงทุกก้อนซ้อนกันที่ความเข้มสูงสุด ทั้งแบบสว่างสุดและมืดสุด) จึงรับประกันตัวหนังสือผ่านแม้พื้นหลังขยับ · เทสต์วัดจากภาพจริงทุกหน้า × 2 โหมด × 360/390/1280 ผ่านด้วย
