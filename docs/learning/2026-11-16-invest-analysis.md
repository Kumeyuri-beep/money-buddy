# บันทึกการเรียนรู้: แท็บ "วิเคราะห์" ของโหมดการลงทุน (16 พ.ย. 2569)

## ทำอะไร
ทำหน้า "วิเคราะห์" ในโหมดพอร์ต (/invest) แนว Snowball บนคอมก่อน:
- **ตารางหุ้นที่ถือ** มี 3 มุมมอง (ทั่วไป / ปันผล / กำไร): ชื่อหุ้น + แถบสี, สัดส่วน, จำนวนหุ้น, ต้นทุนเฉลี่ย, ราคาล่าสุด, มูลค่า, กำไรยังไม่ขาย, "วันนี้" (รอราคาอัตโนมัติ จึงเป็น "—") และแถวรวม
- **ตารางผลตอบแทนรายเดือน**: แถวเป็นปี คอลัมน์ ม.ค.-ธ.ค. และ "ทั้งปี" เซลล์เขียว/แดงพร้อมเครื่องหมาย +/-
- **การ์ดสัดส่วนสกุลเงิน** และ **การ์ดปันผลเทียบเงินลงทุน** (yield และ yield on cost)
- ทุกการ์ดมีข้อความ "ยังไม่มีหุ้นสหรัฐ" เมื่อไม่มีข้อมูล และปุ่ม ฿/USD ที่หัวโหมดใช้กับตัวเลขเงิน

## ทำไมทำแบบนี้
- ตัวเลขทุกตัวมาจากฟังก์ชันที่มีอยู่แล้วใน `src/domain` และ `src/app/usPortfolio.ts` (กฎเหล็ก: ห้ามคิดเงินในหน้าจอ) ไฟล์ `analysis/analysisModel.ts` แค่ "ประกอบ" ผลของฟังก์ชันเหล่านั้นมาจัดเป็นตาราง
- ถ้าไม่มีราคาหรืออัตราแลกเปลี่ยน จะขึ้น "—" พร้อมเหตุผลสำหรับโปรแกรมอ่านหน้าจอ และมีป้าย "ไม่ครบ" ห้ามเอาต้นทุนมาแทนมูลค่าตลาด (R20.7)
- เซลล์ผลตอบแทนที่ติดลบมีเครื่องหมาย "-" ส่วนบวกมี "+" เพราะไม่ควรพึ่งสีอย่างเดียว (คนตาบอดสีอ่านได้)
- ป้ายแหล่งกำไรใช้คำว่า "ปันผล (ก่อนภาษี)" และ "ค่าธรรมเนียมและภาษีที่ถูกหัก" ตามกฎ R24
- ตารางกว้างเลื่อนซ้ายขวาในกรอบของตัวเองบนจอเล็ก หน้าเว็บไม่เลื่อนข้าง

## บทเรียนที่เจอ
- ข้อความซ่อน (`sr-only`) ในเซลล์ตารางตั้งตำแหน่งแบบ absolute ถ้ากรอบตารางไม่ใช่ `position: relative` มันจะหลุดออกไปดันให้ทั้งหน้าเลื่อนข้างบนจอเล็ก (เจอที่ 360px: หน้ากว้าง 843px) แก้โดยทำให้กรอบเลื่อนของตารางเป็น `position: relative`
- ลูกของ `display: grid` มี `min-width: auto` ตารางกว้างจะดันคอลัมน์ให้กว้างตาม ต้องใส่ `min-width: 0`
