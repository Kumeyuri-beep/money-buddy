# หน้า Tools → Rebalancing (R29)

**ทำอะไร:** เปิดหน้า "Portfolio rebalancing" ในเมนู Tools (เดิมเป็น Coming soon) ผู้ใช้เลือกฝาก/ถอน ใส่ยอด USD แล้วกด "See result" จะได้ตาราง "Result: Trades needed to reach your target" ว่าต้องซื้อ/ขายหุ้นตัวไหนกี่หุ้นเพื่อเข้าใกล้เป้าที่ตั้งไว้ในหน้า Categories พร้อมเงินเหลือ (Left over) หรือส่วนที่ขาด (Short by) และตารางหมวด Now / Target / After

**ทำไม:** กฎ R29 อนุมัติให้มีเครื่องมือนี้ โดยเป็น "ผลคำนวณจากเป้าที่ผู้ใช้ตั้งเอง" ไม่ใช่คำแนะนำการลงทุน จึงมีข้อความบังคับติดกับผลลัพธ์ทุกครั้ง (บนจอและท้ายไฟล์ CSV) และไม่มีปุ่มสร้างรายการซื้อขาย ไม่เขียนสมุดหรือฐานข้อมูล

**ทำอย่างไร:**
- สูตรเงินอยู่ใน `rebalance()` เดิม (BigInt ล้วน) หน้าจอแค่เรียกผ่านตัวแปลงใหม่ `src/domain/invest/rebalanceView.ts` (แปลงข้อความยอด→เซนต์ ปฏิเสธเลขลบ/ทศนิยมเกิน 2 ตำแหน่ง/ไม่ใช่ตัวเลข, ประกอบอินพุตจากข้อมูลลงทุน, สร้างแถวแสดงผลและ CSV)
- จำนวนหุ้นที่แสดง = ส่งออก = ที่คิด (แสดงจากหน่วยที่ปัดลงแล้ว 3 ทศนิยม)
- ค่าตั้ง Set up (Allow sales, เศษหุ้น, ยอดสั่งขั้นต่ำ) จำไว้ใน `localStorage` ของเบราว์เซอร์เท่านั้น
- มุมมอง THB: คำนวณเป็น USD เสมอ และมีข้อความบอก

**ทดสอบอย่างไร:** `npm test` (มีเทสต์ตัวแปลงที่ใช้ตัวอย่าง A/C ของ R29 จาก fixture), Playwright `tests/e2e/invest-rebalance.spec.ts` ที่ 360/390/1280/1440 (ตัวอย่าง A เปิด/ปิดเศษหุ้น, ถอน, อินพุตผิด, ส่งออก CSV, ข้อความบังคับ, ไม่มีคำต้องห้ามและไม่มีปุ่มสร้างรายการ) ลองเองได้ที่ `/harness.html?seed=1&investDemo=rebal#/invest/tools/rebalancing`
