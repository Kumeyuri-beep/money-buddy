# แก้เทสต์จริงของ P4 + สร้างกระเป๋าจากหน้าพอร์ต (สรุปแบบง่าย)

## เกิดอะไรขึ้น
หลัง merge P4 ผมรัน "ชุดทดสอบจริง" (ทดสอบกับฐานข้อมูลจริงด้วยผู้ใช้ทดสอบสองคน) แล้วล้ม 1 ข้อ
สาเหตุไม่ใช่ระบบพัง แต่เป็นเทสต์เก่าให้ผู้ใช้ B บันทึกซื้อกองทุนโดย **B ไม่มีกระเป๋าเงินสดเลย** ซึ่งตอนนี้ระบบไม่ยอมแล้ว (P4 ตั้งใจให้ทุกการซื้อขายผูกกับกระเป๋า)

## แก้อะไร
1. **เทสต์**: ให้ B มีกระเป๋าของตัวเองก่อนบันทึก และเพิ่มเช็กว่า B **ใช้กระเป๋าของ A หรือสินทรัพย์ของ A ไม่ได้** (ถูกปฏิเสธและไม่มีแถวค้าง ตรวจด้วยสิทธิ์ผู้ดูแล) ไม่แตะกติกา (policy/trigger) ในฐานข้อมูลเลย
2. **หน้าเว็บ**: ผู้ใช้ที่ยังไม่มีกระเป๋าเงินสดกดซื้อ/ขาย/ปันผล จะเห็นกล่องอธิบายเป็นภาษาคนว่า "ต้องสร้างกระเป๋าก่อน" พร้อมช่องใส่ชื่อและปุ่ม **สร้างกระเป๋า** ทำได้ในหน้าเดียว (เดิมหลังตั้งค่าเริ่มต้นไม่มีที่ไหนให้สร้างกระเป๋าเพิ่มได้เลย)
3. **กติกา**: PR ที่แตะฐานข้อมูลหรือ `tests/live/` ต้องรันชุดทดสอบจริงบน branch ให้ผ่านก่อน merge แล้วรันซ้ำบน main อีกครั้ง (จะได้เจอปัญหาแบบนี้ก่อน merge ไม่ใช่หลัง)

## ทำไมถึงควรเป็นแบบนี้
- เทสต์ที่ล้มเพราะ "ตั้งค่าเทสต์ไม่ครบ" ต้องแก้ที่เทสต์ ไม่ใช่ลดความเข้มของกติกาในฐานข้อมูล
- เทสต์ยังต้องพิสูจน์เรื่องความปลอดภัยเหมือนเดิม: ผู้ใช้คนหนึ่งใช้ของอีกคนไม่ได้
