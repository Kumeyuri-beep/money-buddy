# เรียนรู้: accessibility (การเข้าถึงสำหรับทุกคน)
- skip link = ลิงก์ซ่อนที่โผล่ตอนกด Tab ครั้งแรก ข้ามเมนูข้างทั้งก้อนไปที่เนื้อหา คนใช้คีย์บอร์ดไม่ต้อง Tab ผ่านเมนู 10 กว่าปุ่มทุกครั้ง
- เปลี่ยนหน้าแล้วต้องบอก: ชื่อแท็บเปลี่ยน และโฟกัสย้ายไปหัวข้อหน้า คนใช้โปรแกรมอ่านจอจะรู้ว่าอยู่หน้าไหน
- ปิดหน้าต่างย่อย (dialog) แล้วโฟกัสต้องกลับไปที่ปุ่มที่เปิด ถ้าปุ่มนั้นหายไปให้ไปที่เนื้อหาหลัก ไม่งั้นต้อง Tab จากบนสุดใหม่
- ขอบช่องกรอกต้องเห็นชัดพอ (อย่างน้อย 3 ต่อ 1 เทียบพื้น) ขอบเดิมจางเกินไป ผมคำนวณตัวเลขจริงด้วยสูตร WCAG ในเทสต์ ไม่ใช่เดา
- แถบแจ้งผลที่หายเอง ต้องอยู่นานพอและหยุดนับเมื่อเอาเมาส์หรือโฟกัสวางบนแถบ เพราะมีปุ่ม "เลิกทำ" ข้างใน
- ที่ยังต้องลองจริงกับโปรแกรมอ่านจอ (NVDA/VoiceOver) เพราะผมตรวจได้จากโค้ดเท่านั้น
- ทดสอบ: `npm test` (14+ เคสของ accessibility) · ลองเอง: กด Tab ครั้งแรกในหน้าใดก็ได้ ควรเห็นลิงก์ "ข้ามไปเนื้อหาหลัก" · เปลี่ยนหน้าจากเมนูแล้วชื่อแท็บต้องเปลี่ยน
