# หน้าล็อกอินโคมไฟ (PR 1 ของชุดลูกเล่น)

## ทำอะไร
- หน้าล็อกอินมีโคมไฟทองแบบกระจก กด/แตะ/Enter/Space เพื่อเปิดปิดไฟ · ไฟเปิด: ฉากสว่างขึ้น การ์ดฟอร์มมีขอบเรืองทอง · ไฟปิด: ฉากมืดลง
- **ฟอร์มใช้ได้เสมอ**: การ์ดเป็นพื้นทึบเหมือนเดิม โคมเป็นแค่ของตกแต่ง ไม่ซ่อนอะไร · ช่องเดิม (ชื่อผู้ใช้ รหัสผ่าน) ไม่เพิ่มปุ่ม Google หรือช่องยืนยัน
- วาดด้วย SVG + CSS ธรรมดา ไม่มีไลบรารี · อนิเมชันใช้เฉพาะ transform/opacity · ผู้ใช้ที่ตั้ง "ลดการเคลื่อนไหว" จะไม่เห็นอนิเมชันเลย (โคมยังกดได้)

## ทำไม
เจ้าของอยากให้หน้าล็อกอินมีเอกลักษณ์ในสไตล์ Aurora Glass โดยไม่แลกกับความช้าหรือความปลอดภัย
