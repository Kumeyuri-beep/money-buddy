# เกษียณ เฟส 2b: จำการเลือกสินทรัพย์ (สรุปแบบง่าย)

## ทำอะไร
หน้า "วางแผนเกษียณ" จำไว้ว่าคุณติ๊กสินทรัพย์ไหนนับเป็นเงินเกษียณ เปิดหน้าครั้งหน้าไม่ต้องติ๊กใหม่ · ปุ่ม "ล้างค่า" ล้างการเลือกที่จำไว้ด้วย

## ทำไมไม่ต้องแก้ฐานข้อมูล
ค่าตั้งค่าของคุณ (วันเงินเดือน แผน DCA ฯลฯ) เก็บเป็นก้อนเดียวอยู่แล้ว เราเพิ่มช่อง "รายชื่อสินทรัพย์ที่เลือก" เข้าไปในก้อนนั้น (เหมือนแผน DCA) ฐานข้อมูลไม่ได้ตรวจชื่อช่อง จึงไม่ต้อง migration

## สิ่งที่ระบบระวังให้
- เก็บแค่รหัสสินทรัพย์ที่เลือก ไม่เก็บยอดเงินหรือผลคำนวณ
- ไฟล์สำรองมีรายชื่อนี้ด้วย และนำเข้ากลับได้
- ถ้าสินทรัพย์ที่เคยเลือกถูกลบไปแล้ว ระบบข้ามไปเงียบๆ ไม่ขึ้น error
- บันทึกค่าอื่น (เช่นแก้วันเงินเดือนในหน้าบิล) จะไม่ลบรายชื่อที่เลือกไว้
- เลือกได้ไม่เกิน 30 รายการ (กันค่าตั้งค่าใหญ่เกินที่ฐานข้อมูลรับ)
- แก้บั๊กเล็กในไฟล์สำรอง: เดิมขึ้นคำเตือนว่า "แอปไม่รู้จัก dcaPlans" ทั้งที่ระบบเก็บไว้จริง

## ทดสอบอย่างไร
- `npm test` ผ่านทั้งหมด (เพิ่มเทสต์การเก็บ/ไฟล์สำรอง/สินทรัพย์ที่ถูกลบ)
- ลองเอง: ติ๊กสินทรัพย์ในหน้าเกษียณ → ออกไปหน้าอื่น → กลับมา ต้องยังติ๊กอยู่ · ลบสินทรัพย์ที่เลือกไว้แล้วกลับมา ต้องไม่ขึ้น error
- ชุดทดสอบจริง (`admin:live-contract`) ต้องรันและผ่านก่อน merge ดูหมายเหตุใน HANDOFF
