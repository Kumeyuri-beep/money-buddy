# การ์ดล่างของ Dashboard /invest (PR 2) — สรุปสำหรับมือใหม่

## ทำอะไร
เพิ่มการ์ดที่เหลือตามแบบร่าง: Top day gainers / losers · Recent and upcoming events · Future payments · My goal ข้อความเป็นอังกฤษ

## เรื่องข้อมูล
- ข้อมูลที่ยังไม่มี (ราคารายวัน, ปฏิทินงบ/ XD, ปันผลล่วงหน้า) การ์ดอยู่ที่เดิมแต่แสดง "Available after automatic data is enabled" ไม่ใส่เลขปลอม
- Future payments: แท่ง **Received** ใช้ปันผลที่บันทึกจริงของปีนี้ (ก่อนภาษี ใช้อัตราแลกเปลี่ยนวันปันผลตาม R20 · ฟังก์ชัน \`monthlyDividends\` ตัวเดิมที่เคยตรวจแล้ว) ส่วน Forecast รอข้อมูลอัตโนมัติ
- ปุ่ม sort (⇅ %) ในการ์ด gainers/losers สลับโหมดทันที (% ↔ ฿) คำอธิบายขึ้นเฉพาะตอนชี้หรือโฟกัส ตอนนี้ยังไม่มีรายการให้เรียง
- My goal: ปุ่ม Set a target พาไปหน้าแผนเกษียณ (ยังไม่เก็บเป้าหมายในฐานข้อมูล ไม่มี migration)

## ทดสอบอย่างไร
เทสต์หน้าจอ (เรนเดอร์) ตรวจข้อความที่เจ้าของกำหนดทุกข้อ · e2e ด้วยข้อมูลสมมติ: empty state, ปุ่ม sort สลับ, ⓘ ขึ้นข้อความ, แท่ง Received มี 1 แท่งตามปันผลสมมติ 1 ครั้ง, ปุ่ม Set a target ไปแผนเกษียณ · 360/390/1280/1440
