# ปรับยอดเงินสดในพอร์ต (record_cash_adjustment)

**ทำอะไร:** เพิ่มฟังก์ชันฐานข้อมูล `record_cash_adjustment` ให้หน้า Cash ฝาก/ถอนเงินสดของพอร์ต (บาทหรือ USD) หรือปรับยอดให้ตรงใบแจ้งยอดโบรกเกอร์ โดยบันทึกเป็นรายการ 2 บรรทัดในสมุดบัญชีคู่: เงินสดของพอร์ต กับ "บัญชีพักการปรับยอด" (equity) ฝั่งตรงข้ามเท่ากัน ไม่ใช่รายรับ/รายจ่าย (R16)

**ทำไม:** เงินเข้า/ออกจากภายนอกพอร์ตต้องลงสมุดให้ยอดเงินสดตรง และต้องไม่ถูกนับเป็นกำไรหรือขาดทุน ฟังก์ชันตรวจให้ตายตัว: ถอนเกินยอดคงเหลือไม่ได้, สกุลต้องตรงกัน, ผลรวมสองบรรทัดต้องเป็น 0, สร้างบัญชีพักได้เฉพาะชื่อที่กำหนด

**ทดสอบอย่างไร:** เทสต์หน่วย (`cashAdjustment.test.ts`, `errorCodes-invest.test.ts`) · เทสต์ SQL `supabase/tests/cash_adjustment_test.sql` ขึ้น TESTS_PASSED กับฐานข้อมูลจริง (rollback ไม่ทิ้งข้อมูล) และเทสต์ชุดจริง `tests/live/cashAdjustment.live.ts` ผ่าน `admin:live-contract`

**สถานะ migration:** ใส่ลงฐานข้อมูลจริงแล้วเมื่อ 17 พ.ย. 2569 (บันทึกเป็นเวอร์ชันเวลา 20261117203602 ชื่อ cash_adjustment) ไฟล์ใน repo ใช้ชื่อ 20261118000100_cash_adjustment.sql เนื้อหาเดียวกัน
