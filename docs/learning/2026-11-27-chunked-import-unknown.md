# นำเข้าไฟล์ใหญ่: เมื่อคำตอบก้อนสุดท้ายหาย (27 พ.ย. 2569)

## ทำอะไร
ไฟล์ใหญ่ถูกส่งเป็นหลายก้อน ถ้าก้อนสุดท้ายบันทึกแล้วแต่คำตอบมาไม่ถึง แอปเคยบอกว่า "ล้างส่วนค้างให้แล้ว" ซึ่งไม่จริง
ตอนนี้บอกว่ายืนยันผลไม่ได้ ข้อมูลอาจเข้าครบแล้ว ให้โหลดหน้าใหม่แล้วตรวจยอด

## รู้ได้อย่างไร
คำสั่งล้างตอบว่า `none` (ไม่มีอะไรให้ล้าง) แปลว่าฐานข้อมูลปิดรอบนำเข้าไปแล้ว

## ทดสอบอย่างไร
`npm test` (ชุด "นำเข้าแบบแบ่งก้อน") · จำลองเน็ตหลุดจังหวะนี้บนคอมทำได้ยาก จึงใช้เทสต์
