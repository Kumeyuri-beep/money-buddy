# เรียนรู้: เทสต์รอยต่อขั้นบันไดภาษี
- ขั้นบันไดภาษีมี 7 รอยต่อ (150,000 / 300,000 / 500,000 / 750,000 / 1,000,000 / 2,000,000 / 5,000,000) บั๊กมักซ่อนตรงขอบ จึงทดสอบ "พอดี" และ "ลบ/บวก 1 บาท" ทุกขอบ
- ค่าคาดหวังคำนวณมือจากตารางอัตราเอง ไม่เรียกโค้ดภาษีมาคำนวณซ้ำ เทสต์เลยจับความผิดของโค้ดได้จริง
- เพิ่มกรณีเงินได้ 0 (ทุกค่า 0 ไม่มี -0) และเงินได้ 0 ที่ขอค่าลดหย่อนที่ขึ้นกับเงินได้
- ผลรอบนี้: เทสต์ผ่านทั้งหมดตั้งแต่แรก แปลว่าสูตรเดิมถูกต้องที่ขอบ ไม่ได้แก้โค้ดภาษี
- ทดสอบ: `npm test` (ไฟล์ `tests/unit/taxBoundaries.test.ts` 27 เคส)
