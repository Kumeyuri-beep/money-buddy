# หน้า Cash ของโหมดลงทุน (invest-v2)

## ทำอะไร
เปลี่ยนหน้า Portfolio → Cash จาก "Coming soon" เป็นหน้าจริง
- การ์ดยอดเงินสดของพอร์ตสกุลบาทและ USD พร้อมยอดรวมและสัดส่วน (อ่านจากสมุดบัญชีทุกครั้ง ไม่เก็บยอดซ้ำ)
- ปุ่ม Change balance: ฝาก / ถอน / ตั้งยอดใหม่ (Set balance to) ระบบคำนวณส่วนต่างให้เองเป็นสตางค์/เซนต์จำนวนเต็ม ถ้าส่วนต่างเป็น 0 จะไม่บันทึกและบอกผู้ใช้
- รายการเงินเข้า/ออกพอร์ตล่าสุด (ปรับยอด, โอนบาทเข้า/ออก, แลกเงิน)
- กล่องอธิบายว่าเงินที่ลงทุนต่างจากเงินใช้จ่าย (R23) และข้อความว่าผลตอบแทนไม่รวมเงินสด (ข้อเสนอ R25.4 ยังรออนุมัติ จึงใช้ข้อความกลางๆ)
- ยอดติดลบ: แสดงคำเตือนบนหน้า (ฐานข้อมูลห้ามติดลบเฉพาะการถอนแบบปรับยอด)

## ทำไม
ผู้ใช้ต้องเห็นเงินสดที่พักในพอร์ตและแก้ยอดให้ตรงกับใบแจ้งยอดโบรกเกอร์ โดยไม่ปนกับรายรับ/รายจ่าย

## ออกแบบอย่างไร
- สูตรทั้งหมดอยู่ใน `src/domain/invest/cashView.ts` (BigInt) ส่วนหน้าจอแค่แสดงผล
- การลงสมุดใช้ `buildCashAdjustmentEntry` / `repo.recordCashAdjustment` ที่มีอยู่แล้ว ไม่เขียนสูตรใหม่
- การแปลงสกุลใช้ `displayCurrency.ts` ไม่มีเรต = แสดง "Needs rate" ไม่เดา (R26)
