# สรุปการเรียนรู้: ฟอร์มเพิ่มหุ้นเป็น dialog บนคอม (20 พ.ย. 2569)

- **ทำอะไร:** ฟอร์ม "Add US stock" เปิดเป็น dialog แบบ modal เมื่อจอ ≥1024px (Esc ปิด โฟกัสถูกกักในกรอบ พื้นหลังกดไม่ได้) · ต่ำกว่านั้นยังเป็นการ์ดในหน้าเหมือนเดิม
- **ทำไม:** เจ้าของเลือกจากตารางความต่างจากแบบร่าง 20 (ข้อ 4) และกติกา "มือถือห้ามเปลี่ยนหน้าตา" จึงแยกตามความกว้างจอ
- **ข้อควรรู้:** ใช้ `<dialog>` ของเบราว์เซอร์ (`showModal`) แบบเดียวกับ dialog อื่นของแอป ไม่แตะตรรกะบันทึกหุ้น · ไม่มีสูตรเงิน
- **ทดสอบ:** Playwright 360/390/1280/1440 (ที่คอมเป็น dialog ที่มือถือไม่ใช่) + เทสต์ us-stocks/invest-* เดิมผ่าน
