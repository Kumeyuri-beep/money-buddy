# เรียนรู้: การ์ด "เริ่มต้น 3 ขั้น"
เจ้าของตัดสิน (13 พ.ย. 2569): ผู้ใช้ใหม่ควรรู้ว่าต้องทำอะไรก่อน → การ์ดบนสุดของหน้าภาพรวมมี 3 ขั้น (บันทึกรายการแรก · ตั้งวันเงินเดือน · เพิ่มบิลประจำ) ติ๊กเองจากข้อมูลที่มีอยู่ (รายการที่ไม่ใช่ยอดยกมา, มี payDay, มีบิล) **ไม่เก็บข้อมูลใหม่** และหายเองเมื่อทำครบ · พื้นทึบ ไม่ใช่กระจกแท้ จึงไม่เกินโควตา 8 ใบ · ตรรกะเป็นฟังก์ชันล้วน `src/app/startGuide.ts` ทดสอบแยก
