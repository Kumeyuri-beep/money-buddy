# โหมดสว่าง เฟส 1: ย้ายสีเป็นตัวแปร (design tokens)

**ทำอะไร:** ค่าสีตรงๆ ราว 100 จุดใน `src/ui/styles.css` ถูกย้ายไปเป็นตัวแปร CSS 64 ตัว (บล็อก `:root` ใหม่) ชื่อบอก "บทบาท" ไม่บอกสี เช่น `--surface-solid` (พื้นทึบ), `--on-gold` (ตัวหนังสือบนปุ่มทอง), `--ov-10` (ฟิล์มสว่างโปร่ง 10% บนพื้นมืด), `--shade-25` (ฟิล์มมืดโปร่ง 25%), `--glow-violet-color` (ก้อนแสง) เพื่อให้เฟส 2 ทับค่าเป็นชุดสว่างได้ทีละตัว · สีของกราฟ Sankey ย้ายเป็น `--chart-*` อ่านผ่าน `src/ui/chartColors.ts` · สีของการ์ดแชร์รวมไว้ที่ `SHARE_CARD_PALETTE`

**โหมดมืดต้องเหมือนเดิมทุกจุด — พิสูจน์ 3 ทาง**
1. **ตัวอักษรต่อตัวอักษร:** กระจายตัวแปรกลับเป็นค่าเดิมแล้วเทียบกับ `styles.css` ก่อนแก้ → ตรงกันทุกตัวอักษร (ครอบคลุมทุกกฎ CSS รวมสถานะที่ภาพถ่ายไม่เห็น เช่น hover, dialog, ข้อความเตือน)
2. **เทียบภาพ Playwright 26 ภาพ** (8 หน้า × 360/390/1280 + เมนู pop up มือถือ, เวลาแช่แข็ง, ข้อมูลสมมติ): ต่างกัน 0 พิกเซล (`maxDiffPixels: 0`) · เครื่องมือ `VISUAL=1 npx playwright test visual` (ภาพฐานเก็บใน `.visual/` ไม่เข้า git เพราะภาพต่าง OS ไม่ตรงกัน)
3. **เทสต์ล็อกถาวร** (`tests/unit/themeTokens.test.ts`): ห้ามมีค่าสีตรงๆ นอกบล็อก token ทั้งใน CSS และซอร์ส TS (ยกเว้นพาเล็ตที่ตั้งใจ) · ทุก `var(--x)` ที่ใช้ต้องมีประกาศ · ค่า `--chart-*` ใน CSS ต้องตรงกับค่าสำรองในโค้ด

**ที่แก้เทสต์เดิม 1 ข้อ:** `balanceRange.test.ts` เดิมเช็กว่า `.solid` ใต้โหมดลดความโปร่งใสเป็น hex ตรงๆ ตอนนี้เช็กว่าเป็น `var(--surface-solid)` และ token นั้นเป็นสีทึบเต็ม (ความหมายเท่าเดิม)

**ไม่ทำในเฟสนี้:** ยังไม่มีโหมดสว่าง ไม่เปลี่ยนค่าสีใดๆ ไม่แตะสูตรเงินหรือฐานข้อมูล
