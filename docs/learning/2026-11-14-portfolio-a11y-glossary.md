# หน้าพอร์ต: โฟกัสหลังลบ · คำอธิบายศัพท์ · โครงสร้างที่ screen reader อ่านชัด

**1) โฟกัสหลังลบรายการลงทุน:** เดิมปุ่มลบหายไปพร้อมรายการ โฟกัสคีย์บอร์ดจึงหลุดไปต้นหน้า ตอนนี้หลังลบสำเร็จโฟกัสไปที่รายการถัดไป (ไม่มีก็รายการก่อนหน้า ไม่มีเลยก็หัว "ประวัติรายการ") ถ้าลบไม่สำเร็จจะไม่ย้ายโฟกัส

**2) คำอธิบายศัพท์:** ข้างคำว่า "ปันผลเป็นเงินสด", "ปันผลลงทุนต่อ", "ภาษีหัก ณ ที่จ่าย" มีปุ่ม "ความหมาย" แตะแล้วเห็นคำอธิบายสั้นภาษาคน (ไม่ต้องพึ่งการเอาเมาส์ชี้) ปุ่มสูง 44px กด Esc ปิดได้โดยไม่ปิดฟอร์ม ใช้ในฟอร์มบันทึกรายการและในรายการที่ขยาย คำอธิบายเป็นหลักการทั่วไป ไม่ใช่คำแนะนำด้านภาษี

**3) แก้ `<details>` ซ้อน `<details>`:** เหลือ `<details>` ชั้นเดียว ("ประวัติรายการ") ส่วนแต่ละรายการเปลี่ยนเป็นปุ่มที่บอกสถานะขยาย/ย่อ (`aria-expanded` + `aria-controls`) โปรแกรมอ่านจออ่านว่า "ปุ่ม ขยายอยู่/ย่ออยู่" ชัดกว่า

**ไม่เปลี่ยน:** ค่าและการคำนวณเงินทุกอย่าง (จัดรูปแบบ/การเข้าถึงอย่างเดียว)

**ทดสอบอย่างไร:** เทสต์ด้วยข้อมูลสมมติ (โครงสร้างปุ่ม, คำอธิบายศัพท์, ลำดับโฟกัสถัดไป/ก่อนหน้า, การล้างเป้าหมายเมื่อลบล้ม) + design-critic · ต้องลองบนมือถือ/screen reader จริง
