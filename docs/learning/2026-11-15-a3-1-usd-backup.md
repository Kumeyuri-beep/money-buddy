# A3-1: ไฟล์สำรองรองรับ USD และแยกเงินใช้จ่ายออกจากเงินลงทุน (15 พ.ย. 2569)

## ทำอะไร
- **ไฟล์สำรอง** ตอนนี้เก็บข้อมูลหุ้นสหรัฐ (เงิน USD เป็นเซนต์ อัตราแลกเปลี่ยน ประวัติการแลกเงิน) ได้ครบ ส่งออกแล้วนำเข้ากลับมาจะตรงทุกสตางค์ทุกเซนต์ ไฟล์เก่าที่มีแต่เงินบาทนำเข้าได้เหมือนเดิมทุกอย่าง
- **ตัวตรวจสุขภาพข้อมูล (Integrity)** เช็กต้นทุน USD และเตือนได้ถ้าเงินสด USD ติดลบ (ตอนนี้ยังไม่มีหน้าจอ ตัวนี้เตรียมไว้ให้หน้าจอรอบหน้า)
- **แยกเงินใช้จ่ายกับเงินลงทุน** ที่ตัวเลขและการแสดงผลเท่านั้น สมุดบัญชียังเป็นบัญชีคู่เหมือนเดิม "ใช้ได้วันนี้" ไม่นับบัญชีลงทุน และมีตัวเลข "ความมั่งคั่งรวม" ที่รวมสองกลุ่มด้วยราคาตลาด เปลี่ยนป้ายบัญชีได้แม้มีรายการแล้ว เพราะไม่กระทบสมุด

## ทำไม
เพื่อให้ข้อมูลของผู้ใช้ส่งออกได้เสมอ (กฎของโปรเจกต์) ก่อนที่จะเปิดหน้าจอที่สร้างข้อมูล USD ได้ และเพื่อไม่ให้เงินที่ใช้ลงทุนไปปนกับเงินที่ใช้จ่ายรายวัน

## ทดสอบอย่างไร
- เทสต์โค้ด 2,204+ ข้อผ่าน (รวมเทสต์ส่งออก→นำเข้ากลับ และเทสต์ว่า "ใช้ได้วันนี้" ของข้อมูลเดิมไม่เปลี่ยนแม้สตางค์เดียว)
- เทสต์ฐานข้อมูล 23 ไฟล์ผ่านครบหลังใส่ migration และเทียบจำนวนแถวก่อน/หลังตรงทุกตาราง
- ชุดทดสอบกับฐานข้อมูลจริง 60/60 ผ่าน
- ผู้ตรวจ 2 คนตรวจแล้ว เจอ 1 ข้อสำคัญ (เปลี่ยนป้ายกระเป๋าที่เคยใช้แลกเงินทำให้ไฟล์สำรองถูกปฏิเสธเอง) แก้แล้วพร้อมเทสต์

## ที่ยังรอ
ข้อแนะนำด้านความปลอดภัยระดับกลาง/ต่ำของฝั่งฐานข้อมูล 4 ข้อ ต้องใช้ migration ใหม่ จึงแยกไว้ให้เจ้าของตัดสินใจ (ดู HANDOFF หัวข้อ 78)
