# ให้ฐานข้อมูลตรวจบัญชีเองก่อนนำเข้าและล้าง (28 พ.ย. 2569 · ยังไม่ได้ใส่ฐานข้อมูล)

## ปัญหา
เว็บตรวจว่าเป็นบัญชีเดิมก่อนเขียนแล้ว แต่ยังมีช่องว่างสั้นมากที่แท็บอื่นอาจสลับบัญชีระหว่างตรวจกับเขียน

## ทางแก้
ฟังก์ชันตัวห่อชื่อลงท้าย `_as` รับ "ผู้ใช้ที่หน้าจอตั้งใจ" ถ้าไม่ตรงกับคนที่ล็อกอินอยู่ ปฏิเสธด้วยรหัส `PT412` ก่อนทำอะไร
ครอบการตั้งต้น นำเข้า ล้างข้อมูล และลบบัญชี (9 ฟังก์ชัน) ฟังก์ชันเดิมไม่ถูกแก้

## สิ่งที่ยังไม่ได้ทำ
- ยังไม่ได้ใส่ฐานข้อมูล
- เว็บยังไม่ได้เรียกฟังก์ชันใหม่ (ทำหลังใส่ migration)
- ยังไม่ครอบการบันทึกรายการทั่วไป
