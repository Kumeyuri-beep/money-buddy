# หน้า Dashboard ใหม่ของ /invest (PR 1) — สรุปสำหรับมือใหม่

## ทำอะไร
เปลี่ยนหน้าแรกของโหมดพอร์ตให้ตรงแบบร่างใหม่ของเจ้าของ: แถบบน (แท็บ + ปุ่ม) · 4 การ์ดตัวเลข (Value, Total profit, IRR, Passive income) · การ์ด Portfolio ที่มีโดนัทและตาราง ข้อความในโหมดนี้เป็นภาษาอังกฤษทั้งหมด

## ทำไมไม่ต้อง migration
ชื่อ/คำอธิบาย/สกุลเริ่มต้นของพอร์ตเก็บใน `settings` (ตารางเดิมที่เก็บค่าตั้งค่าเป็น JSON) เหมือนที่ธีมสว่าง/มืดเก็บอยู่ ฝั่งฐานข้อมูลไม่มีรายชื่อคีย์ที่อนุญาต จึงเพิ่มคีย์ใหม่ได้ด้วยโค้ดฝั่งเว็บอย่างเดียว (โค้ดตรวจความยาวชื่อ 1–40 ตัว, คำอธิบายไม่เกิน 120 ตัว, สกุลต้องเป็น THB หรือ USD)

## เรื่องเงิน (สำคัญ)
- ตัวเลขทุกตัวมาจากฟังก์ชันเดิม (R17/R20/R24/R25) ส่วนใหม่ที่เพิ่มมีแค่ "กำไรของหุ้นแต่ละตัว = มูลค่าตอนนี้ − ต้นทุนที่ยังถืออยู่" กับ % ของมัน (ใช้วิธีปัดเศษเดียวกับ R24.5)
- ถ้าหุ้นตัวไหนไม่มีราคาหรืออัตรา จะแสดง "—" ทั้งตารางแทนการเดา (R20.7)
- ปุ่ม Warning ขึ้นเมื่อหุ้นตัวเดียวเกิน 20.00% ของพอร์ต (ตรงๆ 20.00% ไม่เตือน) นับเฉพาะที่ถือตรง ยังไม่นับหุ้นในกองทุน
