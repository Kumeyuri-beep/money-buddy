# เรียนรู้: การ์ดสรุป 3 ใบบนมือถือ
เจ้าของตัดสิน (13 พ.ย. 2569): มือถือโชว์การ์ดสรุป 3 ใบสำคัญ (เงินทั้งหมดที่มี = ความมั่งคั่งสุทธิ, คงเหลือเดือนนี้, ใช้ได้ต่อวัน) + ปุ่ม "ดูทั้งหมด (อีก 5 ใบ)" ที่กดแล้วขยาย/ซ่อนได้ · จอใหญ่แสดงครบ 8 ใบเหมือนเดิม · ทำด้วย CSS (ตัวห่อ `display: contents` บนจอใหญ่) การ์ดทั้ง 8 ยังอยู่ใน DOM จึงไม่กระทบเทสต์/สูตร และกระจกแท้ยัง 8 ใบ ไม่เกินโควตา · หน้าภาพรวมที่ 360px สั้นลงจาก 4,024 เป็น 3,189px
