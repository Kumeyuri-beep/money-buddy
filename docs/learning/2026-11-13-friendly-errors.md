# เรียนรู้: ข้อความผิดพลาดต้องเป็นภาษาคน

**ทำอะไร:** เดิมบางจุด (แถบแจ้งเตือนทุกงาน, ฟอร์มเพิ่มรายการ, การจดด่วน, หน้าเริ่มต้น, หน้าเปิดข้อมูลไม่ได้) แสดงข้อความของระบบตรงๆ เช่น "TypeError: Failed to fetch" หรือ "Entry ต้องมีอย่างน้อย 2 Line" ตอนนี้ทุกจุดใช้ฟังก์ชัน `friendlyError` ตัวเดียว: ข้อความไทยที่แอปเขียนไว้เองแสดงตามนั้น · ข้อความที่ปนศัพท์โปรแกรมถูกแปลง (Entry→รายการ, Line→บรรทัด, ผลต่างสตางค์ดิบถูกตัด) · ข้อผิดพลาดของระบบใช้ข้อความสำรอง/ข้อความเครือข่าย

**ทำไม:** ผู้ใช้ใหม่ไม่ควรเห็นชื่อ error อังกฤษ และไม่รู้ว่าต้องทำอะไรต่อ

**ทดสอบอย่างไร:** เทสต์ตรวจทุกประเภท error + ตรวจว่าซอร์สหน้าจอไม่มี `e.message : String(e)` อีก · ผลภาษีและสูตรเงินไม่ถูกแตะ
