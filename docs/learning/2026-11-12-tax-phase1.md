# เรียนรู้: เครื่องคิดภาษีเงินเดือน (เฟส 1)
- ใส่เงินเดือนทั้งปี ภาษีที่ถูกหักแล้ว และค่าลดหย่อนที่จ่ายไป แอปประมาณภาษีและบอกว่าต้องจ่ายเพิ่มหรืออาจขอคืนเท่าไร (เป็นประมาณการเท่านั้น)
- ไม่บันทึกอะไรเลย ปิดหน้าก็หาย ไม่แตะสมุดบัญชีหรือยอดกระเป๋า
- ตัวเลขกฎหมายอยู่ที่เดียว (`src/domain/tax/config.ts`) แต่ละตัวมีป้ายความมั่นใจ ที่ยังไม่ยืนยัน (เพดานลดหย่อนประกันสังคม) แสดงป้ายบนจอ
- เพดานรวมกลุ่มเกษียณ 500,000: RMF ได้ก่อน ประกันบำนาญได้ส่วนที่เหลือ ส่วน Thai ESG แยกเพดานของตัวเอง
- "สิทธิที่ยังใช้ได้" บอกเพดานที่เหลือเป็นข้อเท็จจริง ไม่ชวนซื้อ
- ถ้ามีเงินได้อื่นนอกจากเงินเดือน เครื่องจะไม่คำนวณ (ดีกว่าให้ตัวเลขผิดแบบเงียบๆ)
- ทดสอบ: `npm test` (ขอบเขตทุกรอยต่อของขั้นบันได, เศษครึ่งสตางค์, เพดานกลุ่ม, ข้อมูลเข้าผิดทุกแบบ) · ลองเองบนหน้าเว็บ: เมนู "คำนวณภาษี" ใส่เงินเดือน 600,000 + ประกันสังคม 9,000 ควรได้เงินได้สุทธิ 431,000 ภาษี 20,600 (ตัวอย่างสมมติ)
