# แถบเตือนสำรองข้อมูล

**ทำอะไร:** หน้าภาพรวมมีแถบเล็กๆ เตือนให้ดาวน์โหลดข้อมูลสำรอง เมื่อไม่ได้ดาวน์โหลดเกิน 7 วัน หรือไม่เคยดาวน์โหลดเลยแต่มีรายการจริงแล้ว (ยอดยกมาตอนตั้งต้นไม่นับ) มีปุ่ม "ดาวน์โหลดข้อมูลของฉัน" และ "ปิดไว้ 3 วัน" และบอกตรงๆ ว่าระบบไม่มีสำรองบนเซิร์ฟเวอร์

**ทำไม:** ข้อมูลหายไปครั้งหนึ่งแล้ว (เหตุการณ์ลบผู้ใช้ทั้งหมด หัวข้อ 43) กู้ได้เพราะมีไฟล์สำรอง จึงควรเตือนให้ทำเป็นประจำ

**เก็บอย่างไร:** วันที่ดาวน์โหลดล่าสุด (`lastBackupAt`) และวันที่ปิดแถบชั่วคราว (`backupSnoozeUntil`) เก็บในค่าตั้งค่า เขียนผ่าน `updateSettings` แบบ compare-and-set เฉพาะสองคีย์นี้ ไม่ทับค่าอื่น (ฐานข้อมูลไม่ต้องแก้) ปุ่มดาวน์โหลดหน้าโปรไฟล์ก็จดวันที่ด้วย จะจดวันที่เมื่อดาวน์โหลดสำเร็จเท่านั้น

**ทดสอบอย่างไร:** เทสต์เกณฑ์ (7 วัน/8 วัน, ข้ามเดือน/ปีอธิกสุรทิน, วันในอนาคต, ปิดชั่วคราว) เทสต์ตัวแถบ เทสต์สัญญาของที่เก็บข้อมูล (ฟอร์มตั้งค่าหน้าบิลไม่ลบสองคีย์นี้) และชุดทดสอบจริง `admin:live-contract`
