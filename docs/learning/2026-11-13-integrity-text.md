# เรียนรู้: ข้อความตรวจความถูกต้องของสมุดบัญชี

แถบเตือน "พบ N ปัญหาในสมุดบัญชี" เดิมแสดงข้อความภายใน เช่น "Entry ซ้ำ", "Line ยอด 0", "ไม่สมดุล … ผลต่าง 100" (สตางค์ดิบ) ตอนนี้แสดงผ่านตัวแปลศัพท์ตอนแสดงผลเท่านั้น (รายการ/บรรทัด/ยอดฝั่งเข้าและออกไม่เท่ากัน) **ไม่แก้ข้อความหรือตรรกะใน `src/domain/ledger/integrity.ts`** จึงไม่กระทบเทสต์เดิมและไม่ต้องให้ money-auditor ตรวจสูตรเงิน (ไม่มีสูตรเงินเปลี่ยน)
ทดสอบ: เทสต์ตรวจข้อความที่แปลแล้วไม่มีศัพท์ดิบ
