# จำกัดให้ผู้ใช้แก้ accounts ได้เฉพาะชื่อ

**ทำอะไร:** ฐานข้อมูลเดิมยอมให้ผู้ใช้ที่ล็อกอินแก้ทุกคอลัมน์ของบัญชีตัวเอง (ชนิด, สกุลเงิน, ซ่อน ฯลฯ) ถ้ายิง API ตรงโดยไม่ผ่านหน้าเว็บ ตอนนี้เหลือสิทธิ์แก้แค่ `name`

**ทำไม:** หน้าเว็บมีกติกาว่าแก้ได้แต่ชื่อ แต่ฐานข้อมูลต้องบังคับเองด้วย ไม่ควรเชื่อแค่หน้าเว็บ (ไม่ได้ทำให้ข้ามผู้ใช้ได้ เพราะมี RLS กันอยู่แล้ว)

**ทดสอบอย่างไร:** เทสต์ SQL ใหม่ + เทสต์ live (แก้ชื่อผ่าน, แก้คอลัมน์อื่นได้ error 42501, เพิ่มกระเป๋า/เปลี่ยนชื่อ/บันทึกรายการยังทำงาน) และรันเทสต์ SQL เดิมครบ 17 ไฟล์

**ย้อนกลับ:** `grant update on public.accounts to authenticated;`
