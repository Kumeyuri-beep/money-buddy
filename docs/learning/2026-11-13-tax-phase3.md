# เรียนรู้: เติมยอดซื้อ RMF/Thai ESG จากพอร์ตเข้าเครื่องคิดภาษี
- ในเครื่องคิดภาษี (ส่วน "กองทุนเพื่อการเกษียณและ Thai ESG") ถ้ามีสินทรัพย์ในพอร์ต จะมีรายการให้เลือกป้าย "ไม่ติดป้าย / RMF / Thai ESG" เอง (ค่าเริ่มต้นไม่ติด แอปไม่เดาให้)
- แอปรวม "ยอดซื้อ" ของสินทรัพย์ที่ติดป้ายในปีภาษีนั้น แล้วมีปุ่มเติมลงช่อง ยอดที่เติมเป็นแค่ค่าตั้งต้น แก้เองได้ตามหนังสือจาก บลจ.
- นับเฉพาะ "ซื้อ" ไม่รวมค่าธรรมเนียม ไม่นับปันผลที่เอาไปซื้อต่อ ไม่นับการขาย ไม่นับแผนซื้อที่ยังไม่ซื้อจริง (ตามกฎ R19)
- ปุ่มเติมจะกดไม่ได้ถ้ายอดเป็น 0 และถ้าเติมทับค่าที่คุณพิมพ์ไว้ จะบอกค่าเดิม
- แอปตรวจไม่ได้ว่าถือครบเงื่อนไขหรือยัง ถ้ามีรายการขายในปีนั้นจะเตือนไว้ · วงเงินลดหย่อนที่ยังไม่ยืนยันยังมีป้ายเตือนเหมือนเดิม
- ป้ายเก็บเป็น "รหัสสินทรัพย์" ในค่าตั้งค่า (ไม่เก็บยอด) ติดได้ประเภทเดียวต่อสินทรัพย์ ไม่ต้องมีการเปลี่ยนฐานข้อมูล
- ทดสอบ: `npm test` · ลองเอง (ต้องล็อกอินออนไลน์และมีสินทรัพย์ในพอร์ต): หน้า "คำนวณภาษี" → ติดป้ายสินทรัพย์ → กดเติม → ตรวจยอดตรงกับรายการซื้อปี 2026 ในหน้าพอร์ต
