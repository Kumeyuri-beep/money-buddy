# R29 ฟังก์ชันคำนวณ Rebalancing (ชั้น domain)

## ทำอะไร
เขียนฟังก์ชัน `rebalance()` ใน `src/domain/invest/rebalance.ts` ที่รับเป้าของแต่ละหมวด หุ้นที่ถือ และยอดฝาก/ถอน แล้วคืน "Result": หุ้นตัวไหนซื้อ/ขายกี่หน่วย เงินเหลือ (Left over) หรือขาดไป (Short by) และตารางหมวด Now / Target / After
ยังไม่มีหน้าจอ ไม่แตะฐานข้อมูล ไม่สร้างรายการซื้อขายให้เอง (ตามกฎ R29)

## ทำไมต้องปัดลง
ถ้าปัดครึ่งขึ้นเหมือนที่อื่น อาจซื้อเกินเงินที่ฝากหรือขายเกินที่ถือ จึงเพิ่ม `floorDivBig` (ปัดลง รับเฉพาะตัวตั้งไม่ติดลบ ตัวหารบวก) เป็นข้อยกเว้นของ R29 เท่านั้น แล้วเติมเศษที่ปัดทิ้งทีละ 1 เซนต์ให้ตัวที่เศษมากสุด (largest remainder) ให้ผลรวมตรงยอดพอดี ส่วน "หน่วย x ราคา เป็นเซนต์" ยังใช้ `valueInSatang` เดิม

## ทดสอบอย่างไร
- ตัวอย่าง A-E อ่านจาก `tests/fixtures/r29-examples.json` ไฟล์เดียว ทุกค่าตรง (A และ B ทั้งเปิดและปิดเศษหุ้น)
- invariant: ซื้อ + Left over = เงินซื้อ, ขายไม่เกินที่ถือ, เงินที่ได้จัดสรรรวมตรงเงินซื้อ, เงินซื้อไม่เกินส่วนขาด/10,000 เมื่อเปิด Allow sales, ผลไม่ขึ้นกับลำดับอินพุต, ไม่มี `Math.floor` ในไฟล์
- สุ่มพอร์ต 400 ชุด (เมล็ดคงที่) ผ่าน invariant ทั้งหมด
- กรณีขอบ: ยอด 1 เซนต์, พอร์ตตรงเป้า, หมวดไม่มีหุ้น, Min order, ปิดเศษหุ้นแล้วหน่วย 0, ถอนเต็มพอร์ต, เป้า 0%, ราคาเก่า, ยอดใหญ่เกินช่วงปลอดภัย (RangeError)
