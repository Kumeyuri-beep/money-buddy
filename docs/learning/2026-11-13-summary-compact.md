# เรียนรู้: การ์ดสรุปบนมือถือ
การ์ดสรุป 8 ใบสูงขั้นต่ำ 168px ทั้งที่เนื้อหาน้อย บนมือถือให้สูงตามเนื้อหาและช่องไฟกระชับ (ยังเป็นกระจกแท้ 8 ใบ ไม่เกินโควตา) หน้าภาพรวมสั้นลงราว 6% (4,289 → 4,024px ที่ 360px) · การลดจำนวนการ์ดบนมือถือ (เช่น โชว์ 3 ใบ + "ดูเพิ่ม") เป็นการตัดสินใจเรื่องดีไซน์ ใส่ในรายการคำถามเจ้าของ
