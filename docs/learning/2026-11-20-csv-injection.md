# สรุปการเรียนรู้: กัน CSV injection กรณีมีช่องว่างนำหน้า (20 พ.ย. 2569)

- **ทำอะไร:** `csvText` ใส่ ' นำหน้าข้อความที่ขึ้นต้นด้วย = + - @ แม้มีช่องว่าง/tab/ขึ้นบรรทัดนำหน้า (เดิมกันเฉพาะที่ขึ้นต้นตรงๆ) ใช้ทั้ง Report และ Holdings
- **ทำไม:** Excel ตัดช่องว่างนำหน้าก่อนตีความเป็นสูตร ข้อความอย่าง " =HYPERLINK(...)" จึงรันเป็นสูตรได้
- **ทดสอบ:** vitest `investReportRows` และ `investHoldingsCsv` (ช่องว่าง tab NBSP ขึ้นบรรทัด · ข้อความปกติไม่เปลี่ยน)
