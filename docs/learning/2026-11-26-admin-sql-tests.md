# คำสั่ง admin:sql-tests รันเทสต์ SQL ครบทุกไฟล์

## ทำอะไร
`MONEY_BUDDY_SQL_TESTS=yes npm run admin:sql-tests` อ่านไฟล์ใน `supabase/tests/` แล้วรันกับฐานข้อมูลจริงทีละไฟล์ แต่ละไฟล์อยู่ในธุรกรรมของตัวเองและ **ยกเลิก (ROLLBACK) ทุกครั้ง** สรุปว่าไฟล์ไหน TESTS_PASSED หรือล้ม และนับจำนวนแถวก่อน/หลังเพื่อยืนยันว่าไม่มีอะไรค้าง

## ทำไม
เดิมต้องคัดลอกไฟล์ไปรันทีละไฟล์ (ราว 540 KB) ช้าและคัดลอกพลาดได้

## ความปลอดภัย
- ต้องตั้ง `MONEY_BUDDY_SQL_TESTS=yes` · ไฟล์ที่มี COMMIT หรือคำสั่งควบคุมธุรกรรม = ไม่รันเลยทั้งชุด
- ค่าเชื่อมต่ออยู่นอกโปรเจกต์ (`admin.env`) ต้องเป็นโปรเจกต์เดียวกับ `SUPABASE_URL` · ไม่พิมพ์ค่าเชื่อมต่อ/รหัสผ่าน · ตรวจใบรับรอง SSL เสมอ

## ตั้งค่าครั้งเดียว (เจ้าของทำเอง)
1. Supabase Dashboard → ปุ่ม **Connect** → **Session pooler** → คัดลอก URI (ขึ้นต้น `postgresql://postgres.<รหัสโปรเจกต์>:[YOUR-PASSWORD]@...pooler.supabase.com:5432/postgres`)
2. แทน `[YOUR-PASSWORD]` ด้วยรหัสผ่านฐานข้อมูล (อักขระพิเศษต้องเข้ารหัส: `@` = `%40`, `#` = `%23`, `/` = `%2F`, `:` = `%3A`, `?` = `%3F`, `%` = `%25`)
3. เปิดไฟล์ `admin.env` ในโฟลเดอร์ `.money-buddy-admin` ใต้โฟลเดอร์ผู้ใช้ แล้วเพิ่มบรรทัด `SUPABASE_DB_URL=...`
4. Database Settings → **SSL Configuration** → ดาวน์โหลดใบรับรอง บันทึกชื่อ `supabase-ca.crt` ไว้ในโฟลเดอร์เดียวกัน

## ทดสอบอย่างไร
unit `tests/unit/sqlTests.test.ts` (ด่านปฏิเสธไฟล์ · ROLLBACK ทุกกรณี · ตรวจ URL · ปิดบังความลับ) ยังไม่ได้รันกับฐานข้อมูลจริงจนกว่าเจ้าของจะใส่ค่า
