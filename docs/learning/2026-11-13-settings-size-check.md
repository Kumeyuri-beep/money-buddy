# เรียนรู้: เปลี่ยนวิธีวัดเพดาน 16 KB ของค่าตั้งค่า
- เดิมฐานข้อมูลวัดขนาดค่าตั้งค่าด้วยตัววัดภายในของ Postgres (ขึ้นกับรูปแบบเก็บ) ตอนนี้วัดจากความยาวข้อความ JSON จริง ซึ่งตรงกับที่ผู้ใช้ใส่ และไม่เปลี่ยนตามการบีบอัด
- การเปลี่ยน constraint เสี่ยงกว่าเพิ่มฟังก์ชัน จึงทำเป็นขั้น: ตรวจทุกแถวก่อน → dry-run แบบย้อนกลับ → เพิ่มตัวใหม่ก่อน แล้วค่อยถอดตัวเก่าในธุรกรรมเดียว (ถ้าตัวใหม่ไม่ผ่าน ตัวเก่ายังอยู่)
- ผู้ใช้ไม่รู้สึกอะไร: เว็บจำกัดค่าตั้งค่า 12,000 ไบต์อยู่แล้ว ต่ำกว่าขีดใหม่
- ทดสอบ: เทสต์ SQL เพิ่มขอบพอดี 16,383/16,384 ไบต์ และข้อความซ้ำๆ ขนาดใหญ่ต้องถูกปฏิเสธ + เทสต์ SQL ครบทุกไฟล์ + live-contract
