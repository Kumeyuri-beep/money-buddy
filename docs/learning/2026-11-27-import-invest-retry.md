# ปุ่มลองนำเข้าข้อมูลลงทุนอีกครั้ง (27 พ.ย. 2569)

## ทำอะไร
การนำเข้าไฟล์สำรองมีสองขั้น: สมุดบัญชีก่อน แล้วข้อมูลลงทุน เดิมถ้าขั้นที่สองล้ม ผู้ใช้ทำต่อเองไม่ได้
ตอนนี้หน้าข้อผิดพลาดมีปุ่มลองเฉพาะขั้นที่สอง โดยไม่ต้องล้างข้อมูล

## ปุ่มทำงานอย่างไร
1. อ่านข้อมูลลงทุนออนไลน์มาเทียบกับไฟล์ก่อน
2. ยังไม่เข้า = ลองนำเข้า (ถ้ามีหมวดเดิม ถามยืนยันก่อน)
3. ตรงกับไฟล์ = ไปหน้าตรวจยอด
4. มีแต่ไม่ตรง = หยุด ไม่ลบหรือทับ
5. อ่านไม่ได้ = ไม่ทำอะไร กดใหม่ได้

## ทำไมต้องอ่านก่อน
ถ้าเน็ตหลุด ฐานข้อมูลอาจบันทึกสำเร็จแล้วแต่คำตอบมาไม่ถึงเรา การเดาว่า "ล้ม" จะบอกผู้ใช้ผิด

## ข้อจำกัด
- ปิดหรือโหลดหน้าใหม่แล้วปุ่มหาย เพราะไฟล์อยู่ในหน่วยความจำเท่านั้น (หน้าจอเตือนไว้)
- ตัวย้ายข้อมูลจากเครื่องไม่มีปุ่มนี้ (ข้อมูลในเครื่องไม่มีข้อมูลลงทุน)
