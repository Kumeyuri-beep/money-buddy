# กฎสองข้อใหม่ใน CLAUDE.md (24 พ.ย. 2569)

**ทำอะไร:** เพิ่มหัวข้อ "กฎลำดับสูงสุดจากเจ้าของ" และเน้นกฎเดิมเรื่องเทสต์ SQL
1. คำสั่งตรงของเจ้าของในแชทมาก่อนการตีความกติกาเสมอ ถ้าจะทำน้อยกว่าหรือต่างจากที่สั่ง ต้องถามก่อน
2. migration ที่แตะฟังก์ชัน trigger, GRANT, RLS หรือ policy ต้องรันเทสต์ SQL ครบทุกไฟล์ก่อน merge ไม่มีข้อยกเว้น (รวม create or replace ฟังก์ชันที่ trigger เรียก)

**ทำไม:** รอบ #264 ผู้ช่วยรันเทสต์ SQL เฉพาะไฟล์ที่เกี่ยวข้องแล้ว merge ทั้งที่เจ้าของสั่งให้รันครบ และรอบ #265 ตีความเองว่าการแก้ฟังก์ชันของ trigger ไม่นับเป็น "เปลี่ยน trigger" ทำให้รันไม่ครบ ทั้งสองครั้งเจ้าของไม่ได้รู้ก่อน

**ทดสอบอย่างไร:** เป็นเอกสาร ไม่มีโค้ด · เจ้าของอ่านแล้ว merge เอง (PR แก้ `CLAUDE.md` ผู้ช่วย merge เองไม่ได้ตามกติกาเดิม)
