# กำไรรวมเป็น % และการ์ดเป้าหมาย (16 พ.ย. 2569)

**ทำอะไร:** การ์ด "กำไรรวม" ในแดชบอร์ดพอร์ตแสดง % ใต้ยอดเงิน (เช่น +36.83%) พร้อมข้อความ "เทียบกับต้นทุนที่ยังถืออยู่" · การ์ดเป้าหมายมีปุ่ม "ตั้งเป้าในแผนเกษียณ" พาไปหน้าแผนเกษียณ (ยังไม่มีตัวเลขเป้า เพราะยังไม่มีที่เก็บเป้า)
**กติกา (R24.5):** % = กำไรรวม ÷ ต้นทุนของหุ้นที่ยังถืออยู่ (ตัวเลขเดียวกับการ์ด "เงินลงทุน") ปัดครึ่งออกจากศูนย์ ถ้าต้นทุนเป็น 0 (เช่น ขายหมดแล้ว) หรือไม่มีราคา จะแสดง "—" ไม่เดา
**ทำไมต้องระวัง:** กำไรรวมนับกำไรที่ขายไปแล้วกับปันผลด้วย แต่ตัวหารเป็นต้นทุนของที่ยังถืออยู่ ถ้าเหลือถือนิดเดียว % จะดูสูงมาก จึงมีข้อความอธิบายกำกับ
**ทดสอบอย่างไร:** ตัวอย่างหลัก (ซื้อ 10/ขาย 4/ปันผล $50) ได้ 3,683 bps (36.83%) ฝั่งบาท และ 4,504 bps (45.04%) ฝั่ง USD · เทสต์เศษ .4/.5/.6 ทั้งบวกและลบ เพื่อให้แน่ใจว่าปัดครึ่งออกจากศูนย์จริง ไม่ได้ตัดเศษทิ้ง · ต้นทุน 0 · ไม่มีราคา
