สถานะ: **เจ้าของอนุมัติแนวทางแล้ว 21 พ.ย. 2569 (ปรับตามข้อ A–D ของคำสั่ง) · ตัวอย่างมือนี้รอเจ้าของดูก่อน merge** · ข้อความของกฎอยู่ใน `docs/money-rules.md` R29 (commit แยก)
แบบร่าง: `docs/design/invest-v2/30-tools-rebalancing.png` · ตัวเลขในแบบร่างเป็นข้อมูลตัวอย่าง · ต้องมี Categories ก่อน (`R2-categories.md`)
**ผลลัพธ์เป็น "Result" เท่านั้น ไม่สร้างรายการซื้อขายให้เอง** (ไม่ลงสมุด R16 · ไม่เขียนฐานข้อมูล) · ข้อยกเว้นของกติกา `docs/plans/investment-design.md` ข้อ 3 บันทึกแล้วในไฟล์นั้น (commit แยก)

## 1. ค่าที่เจ้าของตัดสิน (21 พ.ย. 2569)
- A: ใช้คำว่า **"Result"** ทั้งหน้า ไม่ใช้ "Recommendation/Recommended" · ป้ายเตือนว่าไม่ใช่คำแนะนำการลงทุน · ไม่สร้างรายการซื้อขาย
- B: **แบ่งเงินของหมวดตามสัดส่วนมูลค่าปัจจุบันของหุ้นในหมวด** (ตัดแบบ "หุ้นมูลค่าน้อยสุดตัวเดียว" ออก)
- C: เศษหุ้น **เปิดเป็นค่าเริ่มต้น** (ทศนิยม 3 ตำแหน่ง) ผู้ใช้ปิดได้ใน Set up
- D: ถอนเงินยอมขาดเล็กน้อย ("Short by") · หมวดที่มีสินทรัพย์บาทหยุดคำนวณ · R29 ใช้ปัดลง (floor) เป็นข้อยกเว้นเฉพาะ R29 ไม่แก้ R8
- คำถาม 1–7 ของแผน: ใช้ค่าที่แนะนำทุกข้อ (sector ผู้ใช้เลือกเอง · THB view คำนวณเป็น USD เท่านั้น · หุ้นไม่มีหมวด = หยุด · แถวต่ำกว่าขั้นต่ำ = เงินเหลือ · รายการเก่าไม่ผูกสมุดแก้ไม่ได้ · แก้ได้ทั้ง THB/USD · Import/Export = หมวดและเป้าเป็นไฟล์)

## 2. หลักการ
- อินพุต: ยอดฝาก D ≥ 0 หรือยอดถอน W > 0 (เซนต์ จำนวนเต็ม) · หมวดและเป้า (bps รวม 10,000) · หุ้นสหรัฐที่ถืออยู่ในแต่ละหมวดพร้อมหน่วยและราคาล่าสุดที่ผู้ใช้กรอก (R20.7)
- เอาต์พุต: รายการซื้อ/ขายต่อหุ้น (หน่วย × 10^8, ราคา + วันที่ราคา, จำนวนเงินเซนต์) · เงินเหลือ · ตาราง "Now / Target / After" ต่อหมวด
- **ขอบเขต:** หุ้นสหรัฐ คำนวณเป็น **USD เซนต์** · มุมมอง THB ขึ้นป้าย "Rebalancing works in USD" และช่องจำนวนเงินเป็น USD
- จำนวนเต็มล้วน BigInt ห้าม float · "หน่วย × ราคา → เซนต์" ใช้ `valueInSatang` (R17 · ปัดครึ่งออกจากศูนย์) · **การแบ่งเงินและหน่วยใช้ปัดลง (floor) + largest remainder** (ข้อยกเว้นของ R29 เพื่อไม่ซื้อเกินเงิน/ขายเกินที่ถือ) ผ่านตัวช่วย `floorDivBig` ตัวเดียว ห้าม `Math.floor` หรือ `/` ของ BigInt กระจายในโค้ด
- **ป้ายบังคับ** (หน้าจอและไฟล์ส่งออก): "Result calculated from the targets and prices you entered. Not investment advice: the app does not buy or sell for you. Taxes, fees and price or currency changes are not included. Thai tax on foreign income may arise when money is brought into Thailand. Check with the Revenue Department or a tax adviser, and decide for yourself before trading. Targets are set by you; the app does not assess what suits you." · หัวตาราง "Trades needed to reach your target" · **ห้าม** "Recommended / Recommendation / ควร / ดีที่สุด / เหมาะสม" และคำสื่อรับประกัน · ไม่ใส่ตัวเลขภาษีในหน้านี้ (R13)

## 3. ตัวแปรและเงื่อนไขก่อนคำนวณ
- หมวด c = 1..k, เป้า tc (bps, Σ tc = 10,000), มูลค่าปัจจุบัน Vc (เซนต์) = Σ หน่วย × ราคาล่าสุดของหุ้นในหมวด · V = Σ Vc · เปรียบเทียบในหน่วย "เซนต์ × 10,000" (คูณ bps ก่อน ไม่หารก่อน)
- **ไม่คำนวณ (แจ้งเหตุผล ไม่เดา · R20.7):** ไม่มีเป้า/เป้ารวมไม่ครบ 100% · มีหุ้นที่ถืออยู่แต่ไม่มีหมวด · **หมวดใดมีสินทรัพย์สกุลบาท** ("Category <ชื่อ> contains a baht asset; rebalancing works with US stocks only") · หุ้นที่ถืออยู่ตัวใดไม่มีราคา ("Needs price: <ticker>") · ฝาก/ถอนเป็น 0 และไม่เปิด Allow sales · W > V · ติดลบ/ไม่ใช่จำนวนเต็ม
- หุ้นที่ยังไม่เคยถือ/ขายหมด: ไม่เป็นตัวรับเงินซื้อ เพราะการแบ่งตามมูลค่าปัจจุบัน (น้ำหนัก 0) · **หมวดที่ไม่มีหุ้นที่ถืออยู่เลย (Vc = 0)** แต่มีเป้า → เงินของหมวดนั้นเป็นเงินเหลือ + ข้อความ "No holding to buy in <หมวด>" (ผู้ใช้ซื้อหุ้นตัวแรกเอง)
- แสดงวันที่ราคาล่าสุดต่อหุ้น (เกิน 30 วันขึ้นเตือนเหมือน R26) · หน่วย/ราคาต้องเป็นของปัจจุบัน (ยังไม่รองรับเหตุการณ์บริษัทเช่นแตกพาร์)

## 4. ฝากเงิน (Deposit / Rebalance)
1. T = V + D · Gc = T × tc / 10,000 (เก็บเป็น T × tc)
2. ส่วนขาด sc = max(0, T×tc − Vc×10,000) · ส่วนเกิน ec = max(0, Vc×10,000 − T×tc) · Σ sc − Σ ec = D × 10,000 จึง **Σ sc = D×10,000 + Σ ec**
3. **ไม่เปิด Allow sales:** เงินซื้อ F = D · ac = ⌊F × sc / Σ sc⌋ แล้วเติมเศษทีละ 1 เซนต์ให้หมวดที่เศษมากที่สุด (largest remainder · เศษเท่ากัน → ลำดับหมวด) จนผลรวม = F เซนต์พอดี · หมวดที่เกินเป้าไม่ถูกซื้อ/ขาย
4. **เปิด Allow sales:** ขายส่วนเกิน (ข้อ 6) ได้เงิน P แล้ว F = D + P แบ่งซื้อตามข้อ 3 (ใช้ sc เดิม) · ใช้ได้ทั้ง D = 0 และ D > 0 (ตรงกับ `docs/money-rules.md` R29)
5. **แบ่งเงินในหมวด (ข้อ B):** เงิน ac ของหมวด แบ่งให้หุ้นที่ถืออยู่ในหมวดตาม **สัดส่วนมูลค่าปัจจุบัน** vi / Vc: bi = ⌊ac × vi / Vc⌋ + largest remainder (เศษเท่ากัน → ชื่อย่อก่อน แล้ว id) · หุ้นที่มีมูลค่าเป็นศูนย์ไม่ได้เงิน
6. **หน่วยที่ซื้อ:** เปิดเศษหุ้น (ค่าเริ่มต้น · 3 ตำแหน่ง) หน่วย = ⌊bi × 10^12 / (priceMicro × 10^5)⌋ × 10^5 · ปิด = เต็มหน่วย ⌊bi × 10^12 / (priceMicro × 10^8)⌋ × 10^8 · จำนวนเงินแถว = `valueInSatang(หน่วย, priceMicro)` (ไม่เกิน bi เสมอ) · เงินเหลือแถว = bi − จำนวนเงิน ≥ 0
7. **ยอดสั่งขั้นต่ำ (Min order):** ผู้ใช้ตั้ง ค่าเริ่มต้น 0 · แถวที่จำนวนเงิน < ขั้นต่ำหรือหน่วย = 0 ถูกตัด เงินกลับเป็นเงินเหลือ (ไม่ย้ายหมวด)
8. **เงินเหลือรวม** = F − Σ จำนวนเงินซื้อ ≥ 0 (บรรทัด "Left over") · ไม่ซื้อซ้ำรอบสอง
9. **ผล "After" อาจไม่ตรงเป้า:** ไม่เปิด Allow sales หมวดที่เกินเป้าไม่ถูกแตะ (หัวตารางบอก "closest without selling") · ปัดหน่วยลง/ตัดแถว · ขายปัดลงได้ P น้อยกว่าที่ตั้งใจ (F ≤ Σ sc / 10,000 เสมอ) · ตาราง After คิดจากหน่วยที่ปัดจริง ไม่ใช่จากเป้า

## 5. ถอนเงิน (Withdrawal)
1. T = V − W · ec ต่อหมวดตามข้อ 4.2 · Σ ec ≥ W × 10,000
2. **ขายจากหมวดที่เกินเป้ามากที่สุดก่อน:** เรียง ec มาก→น้อย (เท่ากัน → ลำดับหมวด) ขายหมวดละไม่เกิน ⌊ec / 10,000⌋ เซนต์ จนครบ W
3. ในหมวด: แบ่งยอดขายตามสัดส่วนมูลค่าปัจจุบันของหุ้น (วิธีเดียวกับ 4.5 · ไม่เกินมูลค่าที่ถืออยู่ของตัวนั้นโดยปริยาย เพราะ ec ≤ Vc) · หน่วยที่ขายปัดลง ไม่เกินหน่วยที่ถือ
4. เงินที่ได้จริงน้อยกว่า W (ปัดลง) → แสดง **"Short by"** (ผู้ใช้ปรับเอง · ไม่ขายเพิ่มเอง) · ไม่ซื้ออะไรในโหมดถอน
5. ขายหมดทั้งตำแหน่งของหุ้นตัวใด → เตือน "This sells your whole position in <ticker>" · เป้า 0% + Allow sales → "This sells the whole category"

## 6. ขายเมื่อ Allow sales (ข้อ 4.4)
ขายหมวดที่ ec > 0 หมวดละ ⌊ec / 10,000⌋ เซนต์ แบ่งในหมวดตามสัดส่วนมูลค่า (ข้อ 5.3) ปัดหน่วยลง · P = Σ เงินที่ได้จริง · เมื่อผู้ใช้บันทึกจริง R17 ให้ลงวันที่หลังรายการขายล่าสุด (ระบบไม่บันทึกให้ จึงเตือนบนหน้าจอ)

## 7. กรณีขอบ
| กรณี | ผล |
|---|---|
| ไม่มีเป้า / เป้าไม่ครบ 100% | ไม่คำนวณ ลิงก์ไป Categories (empty state ตามแบบร่าง) |
| มีหุ้นไม่มีราคา | ไม่คำนวณทั้งหมด "Needs price: <ticker>" |
| มีสินทรัพย์บาทในหมวด | ไม่คำนวณ ระบุชื่อหมวด |
| D = 0 และไม่เปิด Allow sales | ไม่คำนวณ บอกให้ใส่ยอดหรือเปิด Allow sales |
| หมวดมีเป้าแต่ไม่มีหุ้นที่ถืออยู่ | เงินของหมวดเป็นเงินเหลือ + ข้อความ |
| ราคาสูงกว่าเงินของแถวและปิดเศษหุ้น | หน่วย = 0 แถวถูกตัด เงินเป็นเงินเหลือ |
| ยอดใหญ่ใกล้ 2^53 | BigInt ไม่ล้ม · ผลเกินช่วงปลอดภัยของเซนต์โยน `RangeError` |
| ถอนเท่ามูลค่าทั้งพอร์ต | ขายทุกตัวทั้งหมด (เตือนขายหมดตำแหน่ง) |
| เป้า 0% ของหมวดที่ถืออยู่ + Allow sales | ขายหมวดนั้นหมด + เตือน |

## 8. ตัวอย่างคำนวณมือ (ต้องตรงกับฟังก์ชัน · ตรวจซ้ำด้วยโปรแกรมอ้างอิง BigInt แล้วทุกค่า)
ข้อมูลตั้งต้น (สมมติ · ราคา USD): Tech เป้า 5,000 bps · Health 3,000 · Funds 2,000

- invariant: ซื้อ ≤ F · ซื้อ + เงินเหลือ = F · F ≤ Σ sc / 10,000 เมื่อเปิด Allow sales · ac ≤ ⌈sc / 10,000⌉ ต่อหมวด (ไม่ใช่ ac ≤ sc/10,000 เพราะ largest remainder เติม 1 เซนต์ได้) · ขาย ≤ หน่วยที่ถืออยู่ (รวมกรณีมูลค่าแถวปัดขึ้นแล้วขายทั้งตำแหน่ง → ใช้ min(คำนวณ, ที่ถือ)) · Σ sc = 0 ไม่หารด้วยศูนย์ · ผลรวมแบ่งในหมวด = เงินของหมวด · ปัดลงด้วย `floorDivBig` ตัวเดียว (ไม่มี `Math.floor`)
- ขอบ: ไม่มีเป้า · เป้า 99.99% · หุ้นไม่มีราคา · มีสินทรัพย์บาทในหมวด · D = 0 ไม่เปิดขาย · หมวดไม่มีหุ้นที่ถือ · ยอดสั่งขั้นต่ำตัดแถว · ปิดเศษหุ้นแล้วหน่วย 0 · เศษเท่ากันตัดสินด้วยชื่อย่อ/ลำดับหมวด · ยอดใกล้ 2^53 · ถอนเท่ามูลค่าทั้งพอร์ต (เตือนขายหมด) · เป้า 0% + Allow sales (เตือน) · ถอนแล้ว Short by · มุมมอง THB
- e2e: ตั้งหมวดและเป้า → หน้า Rebalancing แสดง Result ตรงตัวอย่าง A · ไม่มีคำ "Recommend" ในหน้า (ตรวจข้อความทั้งหน้า) · ไม่มีปุ่มสร้างรายการ
