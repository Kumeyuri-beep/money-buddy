เลข R21/R22 สงวนไว้ตามเดิม · ตัวเลือกที่เจ้าของต้องตัดสินอยู่ท้ายไฟล์

## R26 Display Currency (สกุลที่แสดงผลใน /invest)

**หลักการ:** สกุลที่แสดงเป็นเรื่องของหน้าจอเท่านั้น ไม่เปลี่ยนข้อมูลที่บันทึก ไม่ลงสมุด (R16) · ไม่มีการคำนวณสะสมต่อจากตัวเลขที่แปลงแล้ว (แปลงจากต้นทางครั้งเดียว)

1. **ค่าเริ่มต้นและการจำค่า:** ค่าเริ่มต้น USD · ผู้ใช้สลับ USD/THB ได้ที่แถบบน · เก็บต่อผู้ใช้ในค่า `portfolioCurrency` ของตาราง settings เดิม (ไม่ต้อง migration) · ผู้ที่เคยตั้งค่าไว้แล้วคงค่าเดิม · ไม่ตั้ง = USD (เดิมคือ THB)
2. **ต้นทางของตัวเลข:** หุ้น/เงินสด USD ต้นทางเป็นเซนต์ · มุมมอง USD = ใช้เซนต์ต้นทางตรงๆ ไม่แปลง · มุมมอง THB = แปลงด้วยเรตตามชนิดตัวเลข (ข้อ 3)
3. **เรตที่ใช้ตามชนิดตัวเลข (มุมมอง THB):**
   | ชนิดตัวเลข | ใช้เรต | ที่มา |
   |---|---|---|
   | มูลค่าปัจจุบันของหุ้น, เงินสด USD คงเหลือ | เรตล่าสุดที่กรอก ณ วันที่ดู | R20.7 |
   | ต้นทุนของที่ถืออยู่ | ต้นทุนบาทต่อสินทรัพย์ `Cthb` (เรตวันที่ซื้อแต่ละรายการ) | R20.3 |
   | กำไรที่ขายแล้ว, เงินขาย | เรตวันขาย | R24 |
   | ปันผล ภาษีหัก | เรตวันปันผล | R20.5 |
   | ค่าธรรมเนียม | เรตวันรายการ | R24 |
   | มูลค่าสิ้นเดือนในรายงาน | เรตล่าสุดที่กรอกก่อนหรือเท่าวันสิ้นเดือน | R25.4 |
   | ส่วน "ค่าเงิน" (FX) | ส่วนที่เหลือ R24 แหล่ง (5) | R24 |
   มุมมอง USD: แหล่ง (5) ค่าเงิน แสดง "—" (R24 มุมมอง USD)
4. **เงินบาทในพอร์ต แสดงเป็น USD:** `cents = roundHalfUp(satang × 10^6 / rateMicro)` ด้วยเรตล่าสุดที่กรอก (rateMicro = บาทต่อ 1 USD × 10^6, R20.2) · ปัดครั้งเดียว
5. **ปัดเศษ:** ปัดครึ่งออกจากศูนย์ (R8) ด้วย `roundHalfUpBig` ตัวกลาง สมมาตรกับค่าติดลบ · แปลงจากหน่วยต้นทางครั้งเดียวต่อค่า ห้ามปัดผ่านค่ากลางที่เป็นหน่วยแสดงผลแล้ว · BigInt ล้วน ห้าม float · เกินช่วงปลอดภัยโยน `RangeError`
6. **ผลรวมในมุมมอง THB:** ผลรวมของตาราง = ผลบวกของค่าที่แปลงแล้วของแต่ละแถว (ตารางต้องบวกเลขกันได้ตรง) · อาจต่างจากการแปลงยอดรวมก้อนเดียวไม่เกิน ½ สตางค์ต่อแถว (ดูตัวเลือก ก.)
7. **ไม่มีเรต:** ค่าที่ต้องใช้เรตแต่ไม่มีเรต = ไม่คำนวณ แสดง "Needs rate" ห้ามใช้ 1 หรือเรตเก่าแทนเงียบๆ (ย้ำ R20.7) · เรตเก่ากว่า 30 วันต้องเตือน (WEALTH_STALE_DAYS) · มุมมอง USD ไม่ต้องใช้เรตจึงใช้งานได้เสมอ
8. **แหล่งเรต:** เรตรายวันที่ผู้ใช้กรอกไว้ (ตาราง `fx_rates` ผูกบัญชีเงินสด USD) และเรตจากรายการแลกเงิน (R20.2) เท่านั้น · ยังไม่มีเรตตลาดอัตโนมัติ (เฟส B)
9. **ภาษี/ป.161:** ตัวเลขภาษีเป็นบาทเสมอ คิดจากเรตวันที่ทำรายการตาม R20/R13 · **ไม่เปลี่ยนตามปุ่มสลับสกุล** และต้องติดป้าย "ประมาณการ" ตามเดิม
10. **ขอบเขตรอบที่ 1:** หุ้นและเงินสดสกุล USD (ตามที่หน้าวิเคราะห์ใช้อยู่) · สินทรัพย์บาทเดิมไม่มีถังต้นทุน USD จึงไม่แสดงเป็น USD ในหน้าเหล่านี้ (ไม่เดา)

### เทสต์ที่ต้องมี (ตัวอย่างมือ)

- **แปลงบาทเป็น USD:** 5,000.00 บาท = 500,000 สตางค์ เรต 32.400000 (32,400,000 micro) → `500,000 × 10^6 / 32,400,000 = 15,432.098…` → **15,432 เซนต์ ($154.32)**
- **ปัดครึ่ง:** 1 เซนต์ที่เรต 32.500000 → `1 × 32,500,000 / 10^6 = 32.5` → **33 สตางค์** · −1 เซนต์ → **−33 สตางค์** (สมมาตร) · 1 เซนต์ที่เรต 32.499999 → 32.499999 → **32 สตางค์**
- **มูลค่าหุ้น THB:** 0.31 หุ้น (31,000,000 หน่วย×10^8) ราคา $235.96 (235,960,000 micro) → เซนต์ `roundHalfUp(31,000,000 × 235,960,000 / 10^12)` = 7,314.76 → **7,315 เซนต์** → ที่เรต 32.40 = `7,315 × 32,400,000 / 10^6` = 237,006 สตางค์ (ปัดครั้งเดียวจากเซนต์ ตาม R20.2)
- ขอบเขต: 0 · ติดลบ · เรตไม่มี (ผลต้อง null) · เรต 0/ติดลบ (ปฏิเสธ) · ตัวเลขใหญ่ใกล้ 2^53 (RangeError) · ผลรวมแถว = ผลรวมของค่าที่แปลงแล้ว

## R27 ผลตอบแทนรวมหลายเดือน (คอลัมน์ Total ของ "Total profit, %" ในรายงาน)

**นิยาม:** ผลตอบแทนรวมของช่วงเวลาที่เลือก = **ต่อผลตอบแทนรายเดือน (Modified Dietz ตาม R25.4) แบบทบกัน (time-weighted)** ไม่ใช่กำไรรวมหารเงินลงทุน

1. **อินพุต:** ผลตอบแทนรายเดือนที่ปัดเป็น bps แล้วของ R25.4 ทุกเดือนที่ "มีหุ้นหรือมีรายการ" ในช่วงที่เลือก (เดือนที่ไม่มีหุ้นและไม่มีรายการข้ามตาม R25.4)
2. **สูตร:** `total_bps = roundHalfUp( ∏(10,000 + bᵢ) / 10,000^(n−1) ) − 10,000` · BigInt ล้วน · **ปัดครึ่งออกจากศูนย์ครั้งเดียวตอนท้าย** (ตรงกับการเชื่อมทั้งปีของ R25.4 `years`) · n = จำนวนเดือน
3. **null:** ถ้าเดือนใดในช่วงเป็น null (ไม่มีราคา/เรต, ตัวหาร ≤ 0) ผลรวม = null พร้อมเหตุผล "ข้อมูลบางเดือนไม่ครบ" ห้ามข้ามเดือนนั้นแล้วคิดต่อ · ไม่มีเดือนที่คำนวณได้เลย = null (แสดง "–")
4. **มุมมอง USD และ THB:** แต่ละสกุลคิดผลตอบแทนรายเดือนแยกกันด้วยกระแสเงินและมูลค่าของสกุลนั้น (R26.3) แล้วต่อทบแยกกัน ผลต่างกันได้เพราะค่าเงิน (เหมือน R24.5) · **มุมมอง USD ต้องมีฟังก์ชัน Dietz เวอร์ชันเซนต์ใหม่** (ของเดิมเป็นสตางค์ล้วน)
5. **ช่วง "ทั้งหมด" ที่ยาวกว่า 1 ปี:** ใช้สูตรเดียวกัน ไม่ทำให้เป็นรายปี (ไม่ annualize) · ช่วงที่เลือกต้องไม่ตัดเดือนกลางๆ (หน่วยเป็นเดือนเต็มตาม Time grouping)
6. **จัดกลุ่มรายไตรมาส/ปี:** ผลตอบแทนของไตรมาส/ปี = ต่อทบของรายเดือนในกลุ่มนั้นด้วยสูตรข้อ 2 · ผลรวมทั้งช่วง = ต่อทบของรายเดือนทั้งหมด (ไม่ใช่ต่อทบของค่ากลุ่มที่ปัดแล้ว เพื่อไม่ปัดซ้ำ) · แถวอื่นของ Total (เงินบาท/เซนต์ เช่น Dividends, Fees) = ผลบวกของเดือน ไม่ใช่ TWR

### เทสต์ที่ต้องมี (ตัวอย่างมือ 2 ตัวอย่างตรงกับฟังก์ชัน)

1. **ตัวอย่าง R25 (บวกทั้งคู่):** ม.ค. +1,069 bps · ก.พ. +1,000 bps → `11,069 × 11,000 = 121,759,000` ÷ 10,000 = 12,175.9 → ปัด **12,176** → **+2,176 bps (+21.76%)** (ตรงกับตัวเลข "เชื่อมทั้งปี 2,176" ใน R25)
2. **ตัวอย่างติดลบ:** เดือนที่ 1 −500 bps · เดือนที่ 2 −1,000 bps → `9,500 × 9,000 = 85,500,000` ÷ 10,000 = 8,550 → **−1,450 bps (−14.50%)** (ไม่ใช่ −1,500 ที่ได้จากการบวกกันตรงๆ)
- ตัวอย่างเสริม (ปัดครึ่ง): +50 และ +50 bps → `10,050 × 10,050 = 101,002,500` ÷ 10,000 = 10,100.25 → **+100 bps** · −3 และ −3 bps → `9,997 × 9,997 = 99,940,009` ÷ 10,000 = 9,994.0009 → **−6 bps**
- ขอบเขต: เดือนเดียว (= ค่าเดือนนั้นตรงๆ) · มีเดือน null → null · ไม่มีเดือน → null · 12+ เดือน · ค่าติดลบมากถึง −10,000 bps (ผลคูณ 0 → −10,000) · ค่าต่ำกว่า −10,000 ปฏิเสธ (ผลตอบแทนรายเดือนต่ำกว่า −100% เป็นไปไม่ได้)

## ตัวเลือกที่เจ้าของต้องตัดสิน

- **ก. ผลรวมมุมมอง THB (R26.6):** (1) บวกค่าที่แปลงแล้วของแต่ละแถว ตารางบวกกันตรง แต่อาจต่างจากยอดรวมแปลงก้อนเดียว ≤ ½ สตางค์ต่อแถว **(แนะนำ)** หรือ (2) แปลงยอดรวมก้อนเดียว ตารางอาจบวกกันไม่ตรงในหลักสตางค์
- **ข. สินทรัพย์บาท (R26.10):** แนะนำให้หน้า /invest v2 รอบนี้แสดงเฉพาะหุ้น/เงินสด USD ตามที่ใช้อยู่ ถ้ามีกองทุนบาทอยู่ในพอร์ตต้องเพิ่มกฎต้นทุน USD ของสินทรัพย์บาท (ยังไม่มี)
- **ค. ประมาณการเป้าหมาย (หน้า My goal):** การทบดอกเบี้ยของเป้า "Passive income/Value" เป็นประมาณการ แนะนำให้เป็นกฎ R28 สั้นๆ (ประมาณการ จำนวนเต็ม bps ปัดตาม R8 ติดป้าย "ไม่ใช่คำสัญญา") หรือใช้โครงเดียวกับ R18 · ถ้าไม่เพิ่มกฎ ผมจะทำตามโครง R18 และไม่ถือเป็นกฎเงินใหม่
