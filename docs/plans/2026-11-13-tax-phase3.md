# แผนสั้น: ภาษี เฟส 3 ผูกยอดซื้อ RMF/Thai ESG จากพอร์ต
ตามคำสั่งเจ้าของ 12 พ.ย. 2569 · กฎ R19 ข้อ "เฟสผูกพอร์ต" (อนุมัติแล้ว) · ไม่มี migration (เก็บใน `settings` แบบ `retirementAssetIds`)
- **ป้าย**: ผู้ใช้เลือกเองว่าสินทรัพย์ไหนเป็น RMF หรือ Thai ESG (ค่าเริ่มต้นไม่ติด) เก็บเป็นรหัสใน `settings.taxRmfAssetIds` / `settings.taxThaiEsgAssetIds` (ติดได้ประเภทเดียว ≤30 ต่อประเภท) · เขียนผ่าน `patchSettings` เท่านั้น · อยู่ในไฟล์สำรอง
- **ยอด**: `summarizeTaxPurchases` (โดเมน) รวมเฉพาะ **ซื้อ (buy)** ในปีภาษี (พ.ศ.−543 = ค.ศ. 1 ม.ค.–31 ธ.ค. ตามวันที่ที่บันทึก) ใช้ `amount` **ไม่รวมค่าธรรมเนียม** · ไม่นับ reinvest/dividend/sell · ไม่นับแผน DCA ที่ยังไม่ซื้อจริง · ผลสตางค์ bigint · เกินเพดานเครื่องคิด = `RangeError` · ข้อมูลผิดปกติ (ยอด ≤0/ไม่ใช่จำนวนเต็ม/วันที่เป็นไปไม่ได้) ข้ามและนับ
- **หน้าจอ**: ส่วน "ดึงยอดซื้อจากพอร์ต" ในกลุ่มช่อง RMF/Thai ESG ของเครื่องคิดภาษี: select ติดป้าย → สรุปยอดตามสินทรัพย์ → ปุ่มเติมช่อง (ปิดเมื่อยอด 0 · บอกค่าเดิมเมื่อเติมทับ) · ผู้ใช้แก้ยอดเองได้ตามหนังสือจาก บลจ. · แจ้งเตือน: วงเงินยังไม่ยืนยัน (ป้ายเดิม), มีรายการขาย (แอปไม่ตรวจเงื่อนไขถือครอง), ข้อมูลผิดปกติที่ข้าม
- ไม่ทำ: ติดป้ายอัตโนมัติจากชื่อสินทรัพย์, เขียนยอดลง ledger, ตรวจเงื่อนไขถือครอง
- เทสต์ก่อนโค้ด: `taxPortfolioLink` (ป้าย/ settings / สรุปยอด / ตัวช่วย), `taxPortfolioUi` (ขอบเขตโค้ด/slot), สัญญา repository (ในเครื่อง+ออนไลน์/live) สำหรับป้าย
