# แผน: หน้าล็อกอินโคมไฟ + เอฟเฟกต์ liquid glass (14 พ.ย. 2569)

เจ้าของสั่ง: หน้าล็อกอินมีอนิเมชัน/ลูกเล่น (แรงบันดาลใจ: โคมไฟกดเปิดปิดได้ แต่ต้องเป็นดีไซน์ของเราเองในสไตล์ Aurora Glass ห้ามลอก) · แสงสะท้อนบนกระจกขยับตามเมาส์ (คอม) · เคารพ reduced-motion · ห้ามไลบรารีหนัก ห้ามผ่อน CSP ห้ามขอสิทธิ์เซ็นเซอร์ · ทั้งมืด/สว่าง · design-critic · Playwright 360/390/1280 + ล็อกอินด้วยคีย์บอร์ดอย่างเดียว

## แบ่ง PR
1. **PR 1 หน้าล็อกอิน (โคมไฟ)**
   - โคมทองแบบกระจก SVG+CSS (ปุ่ม `aria-pressed` กด/แตะ/Enter/Space) · ไฟเปิด: แสงฉาก (radial) + ขอบเรืองของการ์ด · ไฟปิด: ฉากมืดลง การ์ดหรี่เล็กน้อย **ฟอร์มเป็นพื้นทึบมองเห็นและใช้ได้เสมอ** (เทสต์ contrast ทั้งสองสถานะ)
   - อนิเมชันเฉพาะ `transform`/`opacity` (โคมแกว่งเบาๆ, ดึงเมื่อกด, แสงเฟด) · `prefers-reduced-motion` = หยุดทั้งหมด (โคมยังกดได้)
   - โคมอยู่หลังฟอร์มในลำดับโฟกัส (Tab แรก = ชื่อผู้ใช้) แสดงเหนือการ์ดด้วย CSS order · ช่องเดิมเท่านั้น (ห้าม Google/ช่องยืนยัน)
   - สี: โทเคน `--lamp-*` `--scene-*` `--card-halo` `--card-unlit` ทั้งมืด/สว่าง · ไม่แตะ CSP · ไม่เพิ่มไลบรารี
   - ทดสอบ: ชุดหน้าล็อกอินจำลอง `/login-harness.html` (ตัวล็อกอินจำลอง ไม่ต่อเครือข่าย ไม่รวมใน build จริง) + Playwright `login.spec.ts` + contrast ล็อกอิน · วัดขนาด bundle ก่อน/หลัง
2. **PR 2 เอฟเฟกต์ liquid glass ทั้งแอป** (หลัง PR 1 merge): แสงสะท้อนบน `.glass` ตามเมาส์บนคอม (ตัวฟังเมาส์เดียวระดับเอกสาร + ตัวแปร CSS · วาดด้วย transform/opacity ของ pseudo-element) · มือถือ: ขยับเบาๆ เอง/ตอบสนองตอนแตะ · ไม่ขอสิทธิ์เซ็นเซอร์ · reduced-motion = หยุด · ไม่กระทบ contrast/โควตากระจก 8 ใบ
