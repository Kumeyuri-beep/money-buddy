# แผนสั้น: เมนู dock บนคอม (เจ้าของสั่ง 15 พ.ย. 2569)

## ขอบเขต
- จอ ≥1024px: dock กระจกลอยกลางล่างแทนรายการเมนูในแถบข้าง · <1024px (มือถือ/แท็บเล็ต) ไม่เปลี่ยน (≤720 = เมนู pop up เดิม · 721-1023 = แถบข้างเดิม)
- ไม่ใช้ framer-motion/lucide/tailwind/ไลบรารีใหม่ · ใช้ path ไอคอนชุดเดียวกับแถบข้าง (`NAV_MAIN`/`NAV_TOOLS` ใน Shell.tsx)
- ไม่แตะเงิน/ฐานข้อมูล/migration/settings → ไม่ต้อง money-auditor/security-auditor/live-contract

## ออกแบบ
- `src/ui/dockMagnify.ts` (ฟังก์ชันล้วน): `magnifyScale(dx)` ไอคอนใกล้เมาส์ใหญ่สุด ลดตามระยะแบบโคไซน์จนเป็น 1 ที่รัศมี · `layoutOffsets(scales, base)` เลื่อนแนวนอนให้ไอคอนที่ขยายไม่ทับกัน (ศูนย์กลาง dock คงที่ ตำแหน่งไม่กระโดด)
- `src/ui/Dock.tsx`: `<nav aria-label="เมนูหลัก">` ปุ่มจริงทุกตัว (`<button>`) · เมาส์เท่านั้น (pointerType mouse) ตั้ง CSS variable `--s`/`--dx` ผ่าน ref + rAF (ไม่ re-render ต่อการขยับ) · ขยายด้วย `transform: scale` เท่านั้น (ไม่เปลี่ยน width/height) · tooltip ชื่อหน้าตอนเมาส์ชี้และตอนโฟกัสคีย์บอร์ด (ข้อความ aria-hidden ชื่อจริงอยู่ที่ aria-label ภาษาไทย) · หน้าปัจจุบัน `aria-current="page"` + จุดใต้ไอคอน · ปุ่ม "เพิ่มรายการ" ทองเป็นรายการแรก
- `prefers-reduced-motion: reduce` = ไม่ขยาย ไม่ตั้ง `--s` · ลดความโปร่งใส = พื้นทึบ
- CSS: ซ่อนเมนูในแถบข้างและปุ่ม "เพิ่มรายการ" ของ Header ที่ ≥1024 (ไม่ซ้ำกับ dock) · เว้นพื้นที่ล่างของหน้า · toast ยกขึ้นเหนือ dock
- ตัดสินใจ (ใช้ตัวแนะนำ): แถบข้างยังอยู่ที่ ≥1024 เฉพาะโลโก้/โปรไฟล์/ออกจากระบบ/สถานะ (ฟังก์ชันเหล่านี้ไม่มีที่ไปอื่น) แต่รายการเมนูย้ายไป dock · ถ้าเจ้าของอยากให้ตัดแถบข้างทั้งแถบ ย้ายสิ่งเหล่านี้ไปหัวหน้าเป็นงานถัดไป

## ทดสอบ
เทสต์หน่วย dockMagnify (0, ขอบรัศมี, สมมาตร, ไม่ทับกัน, ค่าแปลก) → Playwright 1280/1440 × มืด/สว่าง: เห็นเฉพาะที่ ≥1024 · คีย์บอร์ดล้วน (Tab ถึงทุกปุ่ม Enter/Space เปลี่ยนหน้า tooltip ตอนโฟกัส) · เมาส์ขยายด้วย transform ไม่เปลี่ยนขนาดกล่อง · reduced-motion ไม่ขยาย · ไม่บังเนื้อหาท้ายหน้า · contrast tooltip/ป้าย · ที่ 1023 ไม่มี dock · วัด bundle ก่อน/หลัง · design-critic
