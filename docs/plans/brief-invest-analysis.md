## ขอบเขต
**ทำ**
- ตารางหุ้นที่ถือ: หุ้น (+แถบสี) / สัดส่วน / จำนวนหุ้น / ต้นทุนเฉลี่ย / ราคาล่าสุด / มูลค่า / กำไรยังไม่ขาย / วันนี้ (รอราคาอัตโนมัติ = "—") · แถวรวม · แท็บย่อย ทั่วไป / ปันผล / กำไร · คลิกแถว → หน้ารายละเอียดหุ้นเดิมที่มีอยู่
- ตารางผลตอบแทนรายเดือน: แถว = ปี, คอลัมน์ ม.ค.–ธ.ค. + ทั้งปี, เซลล์เขียว/แดง, เซลล์ null แสดง "—" พร้อมเหตุผล (เช่น ไม่มีราคา)
- การ์ดสัดส่วนสกุลเงิน · การ์ดปันผลเทียบเงินลงทุน (yield, yield on cost, ค่าเฉลี่ยต่อเดือน)
- ทุกการ์ด/ตารางมี empty state เมื่อยังไม่มีหุ้น · ปุ่ม ฿/USD ใช้กับตัวเลขเงิน

**ไม่ทำ**: migration/SQL · ราคาอัตโนมัติ · แก้โครงหน้า/เส้นทาง · คำนวณเงินใน component

## ฟังก์ชันที่ใช้ (ห้ามคำนวณเงินเองใน component)
- `src/domain/invest/metrics.ts`: `computeMonthlyReturns(data, asOf)` (`months[{month,bps|null,na?}]`, `years{ปี: bps|null}`) · `computeDividendMetrics(data, asOf)` · `computeProfitSources` (คอลัมน์กำไร)
- `src/domain/invest/usPortfolio.ts` (`buildUsPortfolio`) สำหรับตารางถือครอง ต้นทุนเฉลี่ย มูลค่า · `portfolioMoney.ts` (`latestFxRate`) · ถ้าต้องการสัดส่วน ใช้ `allocateBps` เดิม

- ป้าย: "ปันผล (ก่อนภาษี)" และ "ค่าธรรมเนียมและภาษีที่ถูกหัก" เมื่อแสดงแหล่งกำไร
