# แผน: การ์ดเงินเข้า-ออกบนมือถือ สลับ "แผนภาพ / รายการ" (14 พ.ย. 2569)

เจ้าของสั่ง: เพิ่มปุ่มสลับบนมือถือ ค่าเริ่มต้นเป็นแผนภาพ (Sankey) จำค่าใน settings ผ่าน merge_settings · ให้ design-critic ทำให้ Sankey อ่านได้ที่ 360px ไม่ต้องเลื่อนซ้ายขวา (ย่อชื่อ ลดป้าย แตะเพื่อดูยอด) · Playwright ทั้งมืด/สว่างที่ 360/390/1280
(ทับการตัดสินใจ 13 พ.ย. 2569 ที่ให้มือถือเป็นกราฟแท่งอย่างเดียว: กราฟแท่งกลายเป็นมุมมอง "รายการ")

## ขอบเขต
- ไม่มี migration · ไม่แตะสูตรเงิน (ยอด/สัดส่วนมาจาก `buildCashFlow` เดิม) · เพิ่มคีย์ `cashFlowView` ใน settings (JSON เดิม ไม่จำกัดชื่อคีย์)
- มือถือ (≤720px): ปุ่มสลับ "แผนภาพ | รายการ" (ค่าเริ่มต้น แผนภาพ) · จอใหญ่: Sankey เดิม ไม่มีปุ่ม

## ดีไซน์ Sankey แบบกะทัดรัด (มือถือ)
- วาดใหม่ใน viewBox แคบ (กว้าง 300) ไม่มี min-width จึงไม่ต้องเลื่อนแนวนอน
- ป้ายสั้น: ชื่อตัดที่ ~9 ตัวอักษร (ตัดตามกลุ่มอักษร ไม่ตัดวรรณยุคขาด) + เปอร์เซ็นต์ · ไม่แสดงยอดเงินบนป้าย
- แตะแท่ง/ป้ายเพื่อดูชื่อเต็ม + ยอด + สัดส่วน ในบรรทัดรายละเอียดใต้แผนภาพ (aria-live) · ปุ่มแตะสูง ≥ 28px · ใช้คีย์บอร์ดได้ (Enter/Space)
- ตารางข้อมูล sr-only เดิมคงไว้

## เก็บค่า
- `FinanceSettings.cashFlowView?: 'diagram' | 'list'` · UI เขียนเฉพาะ 'list' (เลือกแผนภาพ = ลบคีย์ = ค่าเริ่มต้น) ผ่าน `updateSettings(['cashFlowView'], …)` → merge_settings
- แสดงผลทันที (optimistic) แล้วบันทึก · บันทึกไม่สำเร็จ = ใช้ในหน้านี้ต่อและแจ้งสั้นๆ

## ทดสอบ
- เทสต์หน่วย: คีย์ settings (ตรวจ/ล้าง/patch/ที่เก็บทั้งสองแบบ) · ตัดชื่อ
- Playwright (มืด/สว่าง × 360/390/1280): ไม่ล้นจอ/ไม่เลื่อนแนวนอน · ปุ่มสลับ (มือถือมี จอใหญ่ไม่มี) · แตะแท่งแสดงยอด · จำค่าหลังโหลดใหม่ · contrast ครอบคลุมป้ายใหม่
- ผู้ช่วย: design-critic (หน้าจอ) · `live-contract` (แตะ settings ผ่าน repository contract)
