# แผน A3-1b: เสริมความปลอดภัยการนำเข้าไฟล์สำรอง USD (15 พ.ย. 2569)

ที่มา: ผลตรวจ security-auditor ของ A3-1 · เจ้าของสั่งให้ทำก่อน A3-2 (เป็นเรื่องความปลอดภัย ควรเสร็จก่อนมีหน้าจอสร้างข้อมูล USD)

## ขอบเขต
| ข้อ | ระดับ | ทำอะไร |
|---|---|---|
| ก1 | กลาง | `import_ledger_investments` ตรวจรายการแลกเงินกับบรรทัดของ Entry ที่ผูกฝั่งเซิร์ฟเวอร์ ไม่ตรง = ปฏิเสธทั้งก้อน 23514 |
| ต1 | ต่ำ | `set_account_kind` ปฏิเสธเมื่อมีการนำเข้าสมุดค้างอยู่ (55000) |
| ต2 | ต่ำ | เจ้าของรับความเสี่ยงไว้ จดใน `docs/decisions/2026-11-15-a3-1b-accepted-risks.md` |
| ต3 | ต่ำ | เพิ่มเทสต์นำเข้าที่ชี้บัญชี/Entry ของผู้ใช้อื่น |

## ไม่อยู่ในขอบเขต

- ไม่แก้ `docs/money-rules.md`
