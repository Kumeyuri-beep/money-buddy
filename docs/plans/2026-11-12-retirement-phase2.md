# แผน: เกษียณ เฟส 2 (ผูกพอร์ตจริง + ความคืบหน้า + เทียบแผน DCA)

branch `auto/retirement-phase2` · กฎ R16, R17, R18 (ข้อ 18.8) · **ไม่แตะฐานข้อมูล/schema/`tests/live`** (ไม่ต้อง migration ไม่ต้อง live-contract)

## ขอบเขต PR นี้ (เฟส 2a: อ่านอย่างเดียว)
- เครื่องคิดเลขเกษียณมีส่วน "นับพอร์ตลงทุนเป็นเงินเกษียณ" ผู้ใช้ติ๊กเลือกเองว่าสินทรัพย์ไหนนับ (ค่าเริ่มต้นไม่เลือก)
- มูลค่า = ตามราคาที่ผู้ใช้ป้อน (ตัวอ่าน R17 `buildPortfolio`) · ไม่มีราคา = "ยังไม่มีราคา" + เตือนมูลค่าไม่ครบ · ราคาเก่ากว่า 30 วันเตือน
- เมื่อเลือก ใช้มูลค่านี้แทนช่อง "เงินที่เก็บไว้แล้ว" (ไม่บวกซ้ำ) และบอกที่มา ("จากพอร์ต ณ วันที่ราคาเก่าสุด …" / "กรอกเอง")
- ความคืบหน้า (bps แสดงผลอย่างเดียว) และเทียบแผน DCA ต่อเดือนของสินทรัพย์ที่เลือกกับเงินที่ต้องเก็บ (ป้าย "แผนที่ตั้งไว้ ไม่ใช่เงินที่ผูกพันว่าจะทำตามจริง")

## ตัดสินใจเอง (เหตุผลใน `docs/decisions/2026-11-12-retirement-phase2.md`)
- **ไม่บันทึกการเลือกสินทรัพย์** ใน PR นี้ เพราะการบันทึกต้องเก็บใน `settings` หรือตารางใหม่ (เปลี่ยน schema/migration ต้อง draft รอเจ้าของ) · ผู้ใช้เลือกใหม่ทุกครั้งที่เปิดหน้า
- ไม่ทำปุ่ม "ใช้ราคาทุนเป็นค่าประมาณ" (กฎอนุญาตเป็นตัวเลือกเสริม ไม่บังคับ) ลดความเสี่ยงที่ผู้ใช้เข้าใจผิดว่าเป็นมูลค่าตลาด
