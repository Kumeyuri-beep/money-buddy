# แผนสั้น: นำเข้าจากไฟล์สำรองที่ผู้ใช้เลือกเอง (9 พ.ย. 2569)

เป้าหมาย: ผู้ใช้ใหม่ที่มีไฟล์สำรอง (.json จากแอปนี้) นำเข้าแทนตั้งต้นใหม่ได้เอง · กฎที่แตะ: R1, R15, R16 (ผ่านตัวตรวจเดิม `parseBackup`) และ PDPA (ข้อมูลของผู้ใช้เอง)

ขอบเขต
- `src/app/importFile.ts`: อ่านไฟล์ (ตรวจขนาดก่อนอ่านเนื้อ) -> `parseBackup` ปฏิเสธทั้งไฟล์ถ้าผิดข้อใดข้อหนึ่ง
- `src/ui/ImportBackupPanel.tsx` ในหน้าตั้งต้น (สมุดออนไลน์ว่าง): เลือกไฟล์ -> ตรวจ -> นำเข้า (`importAndVerify` ธุรกรรมเดียว) -> ตารางเทียบยอด -> ติ๊กยืนยัน
- ย้าย `BalanceTable` เป็น `ImportReportTable.tsx` ใช้ร่วมกับหน้าย้ายข้อมูล (ตรรกะเดิมไม่เปลี่ยน)
- ไม่ทำ: นำเข้าแบบแบ่งชุด (>1,500 รายการ), นำเข้าลงสมุดที่มีข้อมูลแล้ว (ฐานข้อมูลปฏิเสธ ไม่ทับ)

เทสต์ก่อนโค้ด: `tests/unit/importFile.test.ts` (ไฟล์ส่งออกเอง/ใหญ่เกิน/ไม่ใช่ JSON/อ่านไม่ได้/ไม่สมดุล R16/-0 เศษสตางค์/ชื่อไฟล์/นำเข้าซ้ำไม่ทับ) + `importBoundary.test.ts` (หน้านำเข้าไม่แตะ Dexie/localStorage)
ผู้ช่วยตรวจ: security-auditor (ไฟล์ภายนอก), money-auditor (นำเข้าเงิน), design-critic (หน้าจอ)
