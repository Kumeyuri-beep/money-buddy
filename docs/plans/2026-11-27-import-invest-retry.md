# แผน: ปุ่มลองนำเข้าข้อมูลลงทุนอีกครั้ง (ทาง ก)

branch `auto/import-invest-retry` · เจ้าของอนุมัติ 27 พ.ย. 2569 (1ก 2ก) · **ไม่แก้ฐานข้อมูล**

## คำตัดสิน
- **1ก:** ก่อนลองใหม่ทุกครั้ง อ่านข้อมูลลงทุนออนไลน์มาเทียบกับไฟล์
  - ยังไม่เข้า (ไม่มีสินทรัพย์ รายการ ราคา อัตรา การแลกเงิน) = ลองใหม่ · ถ้ามีหมวดค้างต้องยืนยันก่อน (เงื่อนไขเดิม §115)
  - ตรงกับไฟล์ = ถือว่าสำเร็จ ไปหน้าตรวจยอด
  - มีแต่ไม่ตรง = หยุด ไม่ลบหรือทับ (อ่านซ้ำหนึ่งครั้งก่อนสรุป กันอ่านคร่อมช่วงที่ฐานข้อมูลกำลังบันทึก แบบเดียวกับ `exportSnapshot`)
  - อ่านไม่ได้ = ไม่ทำอะไร ให้กดใหม่
- **2ก:** `MigrationWizard` ไม่มีปุ่ม (ข้อมูลในเครื่องไม่มีข้อมูลลงทุน) แก้แค่ข้อความเมื่อไฟล์ไม่มีข้อมูลลงทุน

## ทำอะไร
1. `src/storage/ledgerRepository.ts`: `InvestmentImportError` (สมุดเข้าแล้ว ขั้นลงทุนล้ม · `outcome`: `not_saved` | `unknown`) และเมธอด `retryImportInvestments`
2. `src/storage/supabaseRepository.ts`: โยน error ชนิดใหม่ทั้งสองทาง · ไม่ได้คำตอบ = `unknown` ห้ามอ้างว่าไม่เข้า (§115 ข้อ 5ก) · ไฟล์ไม่มีข้อมูลลงทุน = ข้อความเรื่องลบหมวด
3. `src/app/investImport.ts`: `investImportState` (เทียบ) และ `checkInvestImport` (อ่านแล้วเทียบ)
4. `src/ui/ImportBackupPanel.tsx`: ปุ่มลองใหม่ (หลัก) · โหลดหน้าใหม่ (รอง) · คำเตือนว่าปิด/โหลดใหม่แล้วปุ่มหาย · สำเร็จ = หน้าตรวจยอด
5. `useCategoryGuard`: ข้อความ "กดยกเลิก" ในรอบลองใหม่ต้องไม่บอกว่า "จะไม่นำเข้าอะไรเลย" (สมุดเข้าแล้ว)
