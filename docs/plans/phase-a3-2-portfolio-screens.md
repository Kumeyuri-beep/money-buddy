# แผน A3-2: หน้าจอพอร์ตหุ้นสหรัฐบนคอม (15 พ.ย. 2569)

ที่มา: เจ้าของสั่ง 15 พ.ย. 2569 · ตามแผน `docs/plans/phase-a-us-stocks.md` และ `investment-design.md` · ทำหลัง A3-1 (#189) และ A3-1b (#190) merge แล้ว · คำตัดสินเจ้าของ: **ซ่อนกระเป๋าที่ติดป้ายเงินลงทุนจากตัวเลือกแลกเงินไปก่อน ไม่แก้ `record_fx_exchange` ไม่มี migration ใน A3-2** (จดไว้ใน backlog)

## ขอบเขต (บนคอมก่อน · มือถือ/แท็บเล็ตห้ามพัง ไม่ปรับปรุงใหม่)
1. **ชั้นเขียนข้อมูล (ฝั่งเว็บ ไม่แตะฐานข้อมูล):** ตัวสร้าง Entry ซื้อ/ขาย/ปันผล USD และแลกเงิน (R20.5/R20.2) · repository ใหม่ (`addUsdCash`, `addUsdStock`, `recordTradeFx`, `recordFxExchange`, `deleteFxExchange`, `saveFxRate`) เรียก RPC ที่มีอยู่แล้ว (`record_trade_fx`, `record_fx_exchange`)
2. **มุมมองพอร์ตและฟอร์ม (ฟังก์ชันล้วน):** `usPortfolio` (มูลค่า USD/บาท ต้นทุนเฉลี่ยต่อหุ้น กำไรยังไม่ขายแยกราคาหุ้น/ค่าเงิน ปันผลสะสมสุทธิ สัดส่วน เงินสด USD ติดลบ) · `usForms` · `usdFormat`
3. **หน้าจอ:** หน้า "พอร์ตการลงทุน" เป็นแท็บ **ภาพรวมพอร์ต** (ของเดิมครบ + ส่วนหุ้นสหรัฐเมื่อมีข้อมูล + โอนเข้า/ออกพอร์ต) และ **หุ้นสหรัฐ** (ตาราง ปุ่มซื้อ/ขาย/ปันผล/ราคา ฟอร์มแลกเงิน ปันผลล่าสุด ประวัติแลกเงิน คำเตือนเงินสด USD ติดลบ)
4. **แยกเงินใช้จ่าย/เงินลงทุน (R23):** ความมั่งคั่งรวม (ราคาตลาด) ในหน้าภาพรวม · การ์ดเดิมเปลี่ยนชื่อเป็น "มูลค่าสุทธิ (ราคาทุน)" · หน้าโปรไฟล์: กลุ่มบัญชีเงินสด "เงินใช้จ่าย / เงินลงทุน" พร้อมหน้าต่างยืนยันตอนย้ายกลุ่ม (บอกว่า "ใช้ได้วันนี้" เปลี่ยนทันที และรายงานเดือนก่อนๆ คำนวณใหม่ตามป้ายใหม่)

## ตัดสินใจระหว่างทำ (ต่างจากแผนเดิมเล็กน้อย)
- แท็บ "หุ้นสหรัฐ" **แสดงเสมอ** (แผน A เดิมเขียนว่าซ่อนเมื่อไม่มีสินทรัพย์) เพราะต้องใช้แท็บนี้สร้างบัญชีเงินสด USD และหุ้นตัวแรก
- ฟอร์มแลกเงินแสดงเฉพาะกระเป๋าเงินใช้จ่าย (`walletOptions` อยู่แล้ว) · backlog: "เปิดให้แลกเงินจากกระเป๋าบาทที่ติดป้ายลงทุน (ทำเมื่อเจ้าของมีบัญชีโบรกเกอร์เงินบาท)"
- การ์ดความมั่งคั่งรวมแสดงเมื่อมีข้อมูลลงทุนเท่านั้น (ผู้ใช้ที่ยังไม่มีเงินลงทุนไม่เห็นการ์ดเพิ่ม ภาพรวมเดิมไม่เปลี่ยน) และเป็น glass-lite (ไม่นับโควตากระจกแท้ 6-8 ใบ)
- ราคา/อัตราแลกเปลี่ยนกรอกเอง (ดึงอัตโนมัติคือเฟส B) · ใช้คำว่า "หุ้นเศษส่วน"
