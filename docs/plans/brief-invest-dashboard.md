# บรีฟลูกน้อง 1: แท็บ "แดชบอร์ด" ของโหมด /invest

เขียนโดย GM 16 พ.ย. 2569 · ใช้คู่กับ CLAUDE.md หัวข้อ "กติกา GM/ลูกน้อง" · branch: `auto/invest-dashboard` (git worktree ของตัวเอง แตกจาก `origin/main` หลังขั้น 1 merge)

## เป้าหมาย
ทำแท็บ "แดชบอร์ด" ให้เต็ม ตามแบบ A (แนว Snowball) บนคอมก่อน (≥1024px; Playwright 1280 และ 1440) มือถือ (360/390) ห้ามพัง

## ขอบเขต
**ทำ**
- แถวบน 5 การ์ด: มูลค่าพอร์ต (ใหญ่สุด สีทอง + มูลค่าเป็น USD) · เงินลงทุน · กำไรรวม (+%) · IRR ผลตอบแทนต่อปี · รายได้ปันผลต่อปี (yield + หลังภาษี)
- แถวกลาง: การ์ดกราฟมูลค่าพอร์ต (แสดง `CardUnavailable` "ใช้ได้เมื่อเปิดราคาอัตโนมัติ") · โดนัทสัดส่วนพอร์ต (สลับ หุ้น/สกุลเงิน) · การ์ด "วันนี้ขึ้น/ลง" (รอเฟส B แสดง CardUnavailable)
- แถวล่าง: ปันผลรายเดือนปีนี้ (แท่ง) · "กำไรมาจากไหน" 6 แหล่งเป็นแท่งแนวนอน · ความคืบหน้าเป้าหมาย (เป้าจากแผนเกษียณที่มีอยู่แล้ว)
- ทุกการ์ดมี empty state เมื่อยังไม่มีหุ้น
- ปุ่ม ฿/USD (`useInvest().currency`) ต้องมีผลกับทุกการ์ดที่แสดงเงิน

**ไม่ทำ**: migration/SQL · ราคาอัตโนมัติ · กราฟมูลค่าย้อนหลังจริง · แก้โครงหน้า/เส้นทาง · คำนวณเงินใน component

## ฟังก์ชันที่ใช้ (ห้ามคำนวณเงินเองใน component)
- `src/domain/invest/metrics.ts`: `computeProfitSources(data, asOf)` (ผลคือ `thb`/`usd`/`parts`/`complete`/`missing`) · `computeDividendMetrics(data, asOf)` (รายได้ปันผล 12 เดือน, yield, yield on cost) · `computeIrr(data, asOf)` (`{kind:'ok',bps}` หรือ `{kind:'na',reason}` — `short` แสดง "ใช้ได้เมื่อถือครบ 30 วัน") · `computeMonthlyReturns` (ไม่ใช้ในแท็บนี้)
- `src/domain/invest/usPortfolio.ts` (`buildUsPortfolio`) สำหรับมูลค่า/เงินลงทุน/ถือครอง · `portfolioMoney.ts` (`latestFxRate`)
- ข้อมูล/อัตรา/วันนี้ จาก `useInvest()` (`data`, `today`, `currency`) · `CardUnavailable` สำหรับการ์ดที่ยังไม่มีข้อมูล
- ป้ายในหน้าจอ: แหล่งที่ 4 = **"ปันผล (ก่อนภาษี)"** · แหล่งที่ 6 = **"ค่าธรรมเนียมและภาษีที่ถูกหัก"** · แหล่งที่ 5 ในมุมมอง USD แสดง "—" · แหล่ง 3 ออปชั่น แสดง 0 (หรือซ่อนเมื่อ 0 ถ้าแบบร่างระบุ)
- ฟอร์แมตตัวเลข/เปอร์เซ็นต์ใช้ตัวช่วยเดิมของโปรเจกต์ (bps → % ด้วยการจัดรูปแบบข้อความจากจำนวนเต็ม ไม่ใช้ float คำนวณเงิน)

## ดีไซน์
Aurora Glass มืด · การ์ด glass-lite รัศมี 20px · `font-variant-numeric: tabular-nums` · บวกเขียวอ่อน ลบแดงอ่อน · ตัวหนังสือผ่าน WCAG AA (เทสต์ contrast ใน Playwright) · ไม่ blur ซ้อน · ทึบเมื่อผู้ใช้ตั้งลดความโปร่งใส · ข้อมูลไม่ครบ = การ์ด `CardUnavailable` ห้ามแสดงเลขปลอม/0 แทน
สไตล์เฉพาะคอมครอบด้วย `@media (min-width: 1024px)` และตรวจว่า <1024px ไม่เปลี่ยนหน้าตาเดิมจนพัง (เรียงเป็นคอลัมน์เดียวได้)
