# แผนสั้น: ตรวจและแก้ accessibility ทั้งแอป (13 พ.ย. 2569)
design-critic ตรวจทั้งแอปอ่านอย่างเดียว (ฐานดี: `<dialog>`+`showModal` ได้ focus trap/Esc, label ครบ, ตารางภาษี/เมนูมือถือมีโครงถูก, contrast ข้อความผ่าน AA ทุกสี) แก้ข้อสูงและกลางทั้งหมด:
- **skip link + main landmark** (WCAG 2.4.1): "ข้ามไปเนื้อหาหลัก" เป็นลูกแรกของหน้า, `<main id="main" tabIndex={-1}>`
- **เปลี่ยนหน้า**: ตั้ง `document.title` ตามหน้า และย้ายโฟกัสไป `main h2.page-title` (หน้าภาพรวมเพิ่ม h2 สำหรับโปรแกรมอ่านจอ) หลังหน่วง 60 ms (รอเมนูมือถือคืนโฟกัสก่อน) · ไม่ย้ายตอนโหลดครั้งแรก · `preventScroll`
- **dialog คืนโฟกัส** ทุกตัว (เพิ่ม AddEntryDialog) ผ่าน `restoreFocus`: ถ้าปุ่มเปิดหายหรือไม่มี ไปที่ `#main`
- **ขอบช่องกรอก ≥3:1** (WCAG 1.4.11): `--control-border` (ขาว .5) ใช้กับ input/select/search/seg เดิมขอบ .18 วัดได้ต่ำกว่า 3:1 จริง
- **Toast** (WCAG 2.2.1): ข้อผิดพลาดเป็น `role=alert`, อยู่ 20 วินาที (ผิดพลาด 30), หยุดนับเมื่อเมาส์/โฟกัสอยู่บนแถบ, ติดตั้งใหม่ทุก toast (กัน held ค้าง)
- ไม่ทำ (ระดับต่ำ/ต้องลองจริง): `window.confirm` (ยังใช้ได้), อ่านซ้ำของ Sankey/ScanStatus, ขนาดปุ่ม 40px (ผ่าน WCAG 2.2 AA), toast ใต้ dialog
- เทสต์: `tests/unit/accessibility.test.ts` รวมการ **คำนวณ contrast จริงจากค่าสีใน CSS** (ข้อความทุก token ≥4.5:1 บน 3 พื้น, ขอบช่อง ≥3:1, ขอบเดิมไม่ผ่าน)
