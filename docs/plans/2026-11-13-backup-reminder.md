# แผน: แถบเตือนสำรองข้อมูล (13 พ.ย. 2569)

เป้า: ผู้ใช้ไม่ได้กด "ดาวน์โหลดข้อมูลของฉัน" เกิน 7 วัน (หรือไม่เคยเลยแต่มีรายการแล้ว) → แถบเตือนบนหน้าภาพรวม มีปุ่มดาวน์โหลดทันที + ปิดชั่วคราว 3 วัน บอกตรง ๆ ว่าระบบไม่มีสำรองบนเซิร์ฟเวอร์

- เก็บใน settings 2 คีย์ใหม่ `lastBackupAt` และ `backupSnoozeUntil` (YYYY-MM-DD ปฏิทินไทย) เขียนผ่าน `updateSettings` (compare-and-set → `merge_settings_if`) · ฐานข้อมูลไม่มีรายชื่อคีย์ตายตัว จึง **ไม่ต้องมี migration**
- `src/app/backupReminder.ts` (ฟังก์ชันล้วน): `backupReminder`, `snoozeUntilFor`, `markBackupDone`
- `CARRIED_KEYS` ต้องมีสองคีย์นี้ ไม่งั้นฟอร์มตั้งค่าหน้าบิล (replace) จะลบทิ้งเงียบ ๆ
- UI: `src/ui/overview/BackupReminder.tsx` ใต้การ์ดเริ่มต้น · ปุ่มดาวน์โหลดหน้าโปรไฟล์ก็บันทึกวันที่ด้วย
- กฎ: ไม่แตะเงิน/สมุดบัญชี · "รายการ" = รายการที่ไม่ใช่ยอดยกมา (source ≠ system) เหมือนการ์ดเริ่มต้น
- ข้อจำกัด: ปุ่มดาวน์โหลดตอนแอปล้ม (ErrorBoundary) ไม่บันทึกวันที่ (ไม่มี repo ในขณะนั้น)
