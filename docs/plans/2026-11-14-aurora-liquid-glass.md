# แผนสั้น: พื้นหลังออโรรา + กระจกโปร่งแสงทั้งแอป (14 พ.ย. 2569)

รายละเอียดการตัดสินใจและเงื่อนไข: `docs/decisions/2026-11-14-aurora-liquid-glass.md`

1. **เทสต์ contrast ก่อน** (TDD): `themeContrast.test.ts` คำนวณกรณีพื้นหลังที่แย่สุดจาก `--glow-*-op` (ก้อนแสงซ้อนกันทั้งหมด ทั้งแบบสว่างสุดและมืดสุด) แทนค่าเดิม (ที่มีแต่ด้านมืดสุด)
2. **โทเคน**: ชุดออโรรา (ม่วงเข้ม/ม่วงน้ำเงิน/ทอง/พลัม ทั้งมืดและสว่าง) ใช้ `--glow-*` เดิม · `--glass-under` โปร่งขึ้น (มืด .55→.34 · สว่าง .28→.5)
3. **พื้นหลัง**: `.aurora` (fixed, z-index -1) 4 ก้อน + ริบบิ้น radial/linear-gradient ล้วน แทนก้อน `filter: blur(90px)` เดิม · ขยับช้ามากแบบ `steps()` เฉพาะคอมที่ไม่ลดการเคลื่อนไหว · หยุดระหว่างเลื่อน · มือถือนิ่ง
4. **กระจก**: `.glass-lite` ได้ backdrop-filter ร่วมกับ `.glass` (blur 18px คอม / 14px มือถือ) · รายการ/ตาราง/dialog ยังทึบ · แถบหัวหน้ามือถือไม่ blur · ตัวป้องกันเครื่องช้า (`data-lite`) · reduced-transparency = ทึบ + ซ่อนออโรรา
5. **ทดสอบ**: `aurora.spec.ts` (ไม่ blur ซ้อนทุกหน้า, gradient ล้วนไม่มีรูป, ขยับช้า/หยุดเมื่อเลื่อน/ลดการเคลื่อนไหว/มือถือนิ่ง, เครื่องช้า) + contrast จากภาพจริงเดิมทุกหน้า/โหมด/ความกว้าง + เทียบภาพ
6. ผู้ช่วย: design-critic · ไม่แตะเงิน/ฐานข้อมูล/CSP (ไม่ต้อง money/security-auditor, ไม่ต้อง live-contract)
