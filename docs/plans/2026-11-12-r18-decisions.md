# แผน: ปรับเครื่องคิดเลขเกษียณตามมติ R18 ของเจ้าของ (12 พ.ย. 2569)

branch `auto/r18-decisions` · กฎที่แตะ R2, R8, R16, R18 · ไม่แตะฐานข้อมูล (ไม่ต้อง live-contract)

## มติเจ้าของ
1. `ceilDivBig` เป็นข้อยกเว้นของ R8 เฉพาะ "เงินเก็บต่อเดือน" · ค่าอื่นปัดครึ่งขึ้น (เงินที่ต้องมี N เปลี่ยนจากปัดขึ้นเป็นปัดครึ่งขึ้น)
2. ผลตอบแทนไม่มีค่าเริ่มต้น · ช่วงค่า: เงินเฟ้อ 0-10%, ผลตอบแทน -5..15%, อายุเกษียณ ≤ 80, อายุคาดการณ์ ≤ 110 (money-auditor ปรับได้ถ้ามีเหตุผล)
3. ยอมรับความคลาดเคลื่อนเดิม · หน้าจอแสดงปัดเป็นหลักร้อยบาท + คำเตือนว่าประมาณ
4. เพิ่ม "วางแผนเกษียณ" เป็นรายการที่ 7 ในเมนู pop up มือถือ
5. เขียน R18 ลง `docs/money-rules.md` เป็น commit แยก · แล้วเริ่มเฟส 2

## ตัดสินใจเอง (เหตุผลใน `docs/decisions/2026-11-12-r18-display-rounding.md`)
- เงินเก็บต่อเดือนที่แสดงปัด **ขึ้น** เป็นหลักร้อยบาท (ไม่ปัดใกล้สุด) เพราะเจตนาของมติข้อ 1 คือไม่ให้เก็บขาด
