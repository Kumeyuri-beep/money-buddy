# Invest mode v2 — design reference (sample data)

Mockups for the /invest redesign (Snowball-style, dark Aurora Glass, English UI).
Each page has a full-page PNG and a standalone HTML file (open in a browser; hovers, tabs and toggles work with pure CSS).

All numbers are SAMPLE data. Do not copy numbers into code or tests as real values.

Global decisions shown in every page:
- Display currency: USD first, toggle $ USD / ฿ THB in the top bar (sample rate 32.40 ฿/$; the real app uses the stored daily rate).
- Navigation: top bar Dashboard / Analytics ▾ / Portfolio ▾ / Tools ▾. Portfolio pages have NO sub-tab bar; pick a page from the Portfolio menu.
- Tools menu: Portfolio rebalancing, Top dividend stocks, Dividend payout calendar (opens https://snowball-analytics.com/calendars/dividend-calendar in a new tab), Find the Dip. Portfolio Lab removed.
- No "Sample data / Main portfolio" header text under the top bar.
