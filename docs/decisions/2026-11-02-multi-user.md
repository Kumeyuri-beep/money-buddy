# 2026-11-02 เปลี่ยนเป็นเว็บหลายผู้ใช้สำหรับเพื่อนและครอบครัว

## ตัดสินใจ
- ผู้ใช้: เพื่อนและครอบครัว ไม่เกิน 20 คน เข้าได้เฉพาะคนที่ได้รับเชิญ (ปิดสมัครเอง)
- ไม่เก็บเงิน ไม่ใช้เชิงพาณิชย์
- งบ 0 บาท: Supabase แพ็กเกจฟรี (Auth + Postgres) + Vercel Hobby
- ข้อมูลแต่ละคนแยกกันเด็ดขาดด้วย RLS (`auth.uid() = user_id`) ไม่มีกระปุกร่วม ไม่มีการแชร์
- แทรก milestone ใหม่ M2 "บัญชีผู้ใช้และฐานข้อมูลออนไลน์" หลัง M1 ก่อนงานบิลและหนี้

## Ticket
M2-A ฐานข้อมูล + RLS + ตรวจ R16 ฝั่งเซิร์ฟเวอร์ · M2-B ล็อกอิน · M2-C repository interface (Supabase/Dexie)
M2-D นำเข้าไฟล์สำรอง JSON · M2-E PDPA (นโยบาย, ยินยอม, ส่งออก, ลบบัญชี) · M2-F ทดสอบแยกข้อมูล 2 ผู้ใช้

## ความเสี่ยงที่ยอมรับ
- โปรเจกต์ฟรีถูกพักถ้าไม่มีใครใช้ 7 วัน → กดเปิดคืนได้ ข้อมูลไม่หาย
- สำรองข้อมูลเองเป็นประจำ ไม่พึ่งระบบสำรองของแพ็กเกจฟรี
- เจ้าของโปรเจกต์มองเห็นข้อมูลได้จากหน้าแอดมิน → แจ้งในนโยบายความเป็นส่วนตัว
- ถ้าวันหนึ่งเก็บเงิน ต้องย้ายเป็นแพ็กเกจเสียเงินทั้ง Vercel และ Supabase
