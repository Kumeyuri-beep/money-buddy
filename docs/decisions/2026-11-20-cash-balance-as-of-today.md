# หน้า Cash นับยอดถึงวันนี้ (วันที่ <= วันนี้) ตรงกับ Holdings

วันที่: 20 พ.ย. 2569 · กฎที่เกี่ยว: R16 (ยอดคำนวณจากสมุด) R20 R23 R26 · ที่มา: ผลตรวจ money-auditor ของ PR #231

## ปัญหา
หน้า Cash รวมทุก Entry ในสมุดทุกวัน แต่ Holdings (`src/app/usPortfolio.ts`) กรอง `date <= today` ก่อนคิดเงินสด USD
ถ้ามีรายการลงวันอนาคต ยอดเงินสด USD สองหน้าจะไม่ตรงกัน

## ตัดสิน
`cashAccountBalances` / `buildCashView` รับวันนี้ (`today` ที่ InvestMode ส่งมา ตัวเดียวกับที่ Holdings ใช้) และนับเฉพาะ Entry วันที่ไม่เกินวันนี้
- รายการเงินเข้า/ออกล่าสุด (recentCashMovements) ยังแสดงทุกวัน เพื่อให้ผู้ใช้เห็นรายการที่ลงล่วงหน้า
- Dialog Change balance: ถ้าเลือกวันที่เป็นอนาคต แสดงข้อความว่ารายการจะนับในยอดเมื่อถึงวันนั้น (ไม่บล็อก)
- Set balance to คำนวณส่วนต่างจากยอด ณ วันนี้ ตัวเดียวกับที่แสดงบนหน้า

## ข้อควรรู้
ยอดที่ฐานข้อมูลใช้ตรวจ "ถอนเกินยอด" อาจนับรายการอนาคตต่างจากหน้าจอ (ฐานข้อมูลเป็นผู้ตัดสินสุดท้าย ไม่แก้ฝั่ง DB ใน PR นี้)
