# ตัดสินใจ: พื้นหลังออโรรา + กระจกโปร่งแสงทั้งแอป (14 พ.ย. 2569)

เจ้าของสั่ง: ทำทั้งแอปเป็นกระจกโปร่งแสงแบบ liquid glass มากขึ้น (โทน Aurora Glass ของเราเอง) · พื้นหลังก้อนแสงออโรราโทนทอง/ม่วงเข้มมีมิติ ขยับช้ามาก ด้วย CSS gradient · การ์ดทุกใบโปร่งแสงเห็นพื้นหลังเบลอทะลุ (backdrop-filter) · ตัวหนังสือผ่าน WCAG AA ทุกจุดทั้ง 2 โหมด (ถ้าใสแล้วไม่ผ่านให้ลดความใสเฉพาะจุด ห้ามลดเกณฑ์) · blur เฉพาะการ์ดระดับบนสุด ห้ามซ้อน · มือถือต้องลื่น · reduced-transparency = การ์ดทึบเดิม · reduced-motion = พื้นหลังนิ่ง

## ผลต่อกฎเดิมใน CLAUDE.md (การตีความดีไซน์ 2 พ.ย. 2569)
เดิม: กระจกแท้ (blur) เฉพาะการ์ดสรุป ไม่เกิน 8 ใบ · glass-lite ไม่มี blur · พื้นทึบกับรายการ/ตาราง
**คำสั่งใหม่ของเจ้าของ (14 พ.ย.) ทับข้อ "glass-lite ไม่มี blur"**: การ์ดหน้า (`.glass-lite`: การ์ดทั่วไป แถบเมนู หัวหน้า) ได้ backdrop-filter ด้วย โดยมีเงื่อนไขกันกระตุก/ช้า:
1. **ห้าม blur ซ้อน** (ไม่มีองค์ประกอบ backdrop-filter อยู่ใต้องค์ประกอบ backdrop-filter อีกตัว) · เทสต์ Playwright ตรวจจากหน้าจริงทุกหน้า
2. **รายการและตาราง (`.solid`) ยังเป็นพื้นทึบ** (ข้อมูลหนาแน่น ต้องอ่านง่ายที่สุด) และ dialog เป็นพื้นทึบ
3. มือถือ (≤720px): blur เบาลง (รัศมีเล็ก ไม่ saturate) และแถบหัวหน้าไม่ blur · พื้นหลังออโรรานิ่ง (ไม่ขยับ) บนอุปกรณ์ที่ไม่มีเมาส์ เพื่อไม่ให้ต้องคำนวณ blur ใหม่ทุกเฟรมขณะเลื่อน
4. `prefers-reduced-transparency` = การ์ดทึบเดิมทุกแบบ และซ่อนพื้นหลังออโรรา · `prefers-reduced-motion` = พื้นหลังนิ่ง
5. ความใสของการ์ดกำหนดจากเทสต์ contrast ที่คำนวณกรณีพื้นหลังที่แย่สุด (ก้อนแสงทุกก้อนซ้อนกันที่ความเข้มสูงสุด ทั้งแบบสว่างสุดและมืดสุด) · ถ้าจุดใดไม่ผ่านให้เพิ่มความทึบของจุดนั้น ไม่ลดเกณฑ์

ตัวเลือกที่พิจารณาแล้วไม่เลือก: blur ทุกชั้นรวม `.solid` (ตารางอ่านยาก ช้า) · ก้อนแสงแบบ filter: blur(90px) เดิม (แพงกว่า gradient มาก จึงเปลี่ยนเป็น radial-gradient ล้วน)
