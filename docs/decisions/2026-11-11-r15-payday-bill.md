# R15: บิลที่ครบกำหนดตรงวันเงินเดือนถัดไปถูกหักด้วย (11 พ.ย. 2569)

เจ้าของตัดสินใจและอนุมัติแก้ `docs/money-rules.md` R15 เฉพาะข้อนี้ (commit แยก) · ปิดข้อ 3 ของ backlog ใน HANDOFF

| # | เรื่อง | ตัดสินใจ |
|---|---|---|
| 1 | ช่วงนับบิล | เดิม [วันนี้, วันเงินเดือนถัดไป) → ใหม่ [วันนี้, วันเงินเดือนถัดไป] บิลที่ครบกำหนดตรงวันเงินเดือนถัดไปถูกหักจาก SAFE-TO-SPEND ของรอบปัจจุบัน (ทางปลอดภัย: ยอดที่โชว์ไม่สูงเกินจริง) |
| 2 | จำนวนวันหาร | ไม่เปลี่ยน ยังเป็น [วันนี้, วันเงินเดือนถัดไป) (`daysBetween`) |
| 3 | แผง "บิลที่จะถึง" | `until` = วันเงินเดือนถัดไป (รวม) เพื่อให้ยอดรวมในแผงเท่ากับที่การ์ดหัก (มีเทสต์เทียบ) |
| 4 | ผลข้างเคียงที่ยอมรับ | วันนี้คือวันเงินเดือนและบิลครบกำหนดวันนั้นยังไม่จ่าย: หักบิล 2 งวดคนละงวด ไม่ใช่นับซ้ำ (งวดวันนี้ที่ค้าง + งวดวันเงินเดือนเดือนหน้า เช่น 1,500 → 3,000 บาท) เพราะบิลเดือนหน้าที่ครบกำหนดตรงวันเงินเดือนก็ตกในช่วงตามข้อ 1 · เป็นแบบระวังไว้ก่อน เมื่อจ่ายรอบนี้แล้วยอดคืนเอง |
| 5 | โค้ด | `outstandingBeforePayday` (schedule.ts), `buildSafeToSpend`, `buildUpcomingPanel` (billsOverview.ts) ส่ง `next` แทน `addDays(next, -1)` ไม่มี migration |
