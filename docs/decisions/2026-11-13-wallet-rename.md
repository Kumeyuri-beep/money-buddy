# เปลี่ยนชื่อกระเป๋าเงิน + ชื่อเริ่มต้นเป็นไทย (13 พ.ย. 2569)

กฎที่แตะ: R16 (ข้อมูลบัญชีคู่) — ไม่แตะยอด/รายการ · เจ้าของตัดสิน: เปลี่ยนแค่ "ชื่อที่แสดง" ห้ามเปลี่ยนรหัสบัญชีหรือยอด · ผู้ใช้เดิมที่ใช้ชื่ออังกฤษ (CashFlow/Mainframe/Vault Zero) **ห้ามเปลี่ยนชื่อให้เอง** ให้เปลี่ยนเองได้

## ที่ทำ
- ชื่อเริ่มต้นตอนตั้งต้นใหม่: เงินสด / บัญชีธนาคาร / เงินออม (ผู้ใช้เดิมไม่ถูกแตะ ค่านี้ใช้เฉพาะตอน Setup)
- `renameWallet(id, name)` ใน `LedgerRepository` (ทั้งในเครื่องและออนไลน์ ผ่านชุดเทสต์สัญญาเดียวกัน): เขียนเฉพาะคอลัมน์ `name` · ตัดช่องว่างหัวท้ายและยุบช่องว่างซ้อน · ปฏิเสธ: ว่าง, ยาวเกิน 200, ซ้ำกับกระเป๋าอื่น (ไม่สนตัวพิมพ์/ช่องว่าง), ไม่ใช่กระเป๋าเงิน (บัญชีลงทุน หมวด ยอดยกมา), ไม่มีอยู่
- หน้าโปรไฟล์: ส่วน "ชื่อกระเป๋าเงิน" (ช่องกรอก + ปุ่มบันทึกชื่อ ต่อกระเป๋า) กดบันทึกได้เมื่อผู้ใช้แก้เองเท่านั้น

## ทำไมไม่มี migration
ตาราง `accounts` ให้ authenticated แก้ได้อยู่แล้ว (RLS ตามเจ้าของ) และ `accounts_guard` กันเปลี่ยนชนิด/สกุลเงิน/ประเภทของบัญชีที่มีรายการ · ฝั่งเว็บเขียนเฉพาะ `name` และกรอง `type='asset' and kind='normal'` · การเปลี่ยนรหัสบัญชีที่มีรายการผูกอยู่ถูก FK ในฐานข้อมูลกันอยู่แล้ว (รหัสเป็นกุญแจของแถวบรรทัดรายการ) · ถ้าอยากกันระดับฐานข้อมูลเพิ่ม (trigger ห้ามเปลี่ยน id ทุกกรณี) เป็น migration add-only แยก (backlog)

## ผลทดสอบ
เทสต์สัญญา renameWallet ผ่านทั้ง Dexie และ live-contract ออนไลน์ (54/54) ตรวจ: รหัสบัญชีทุกตัวเหมือนเดิม, จำนวนรายการเท่าเดิม, ยอดกระเป๋าเท่าเดิม, Integrity ผ่าน, บัญชีอื่นไม่เปลี่ยนแม้แต่ฟิลด์เดียว, ทุกกรณีปฏิเสธไม่เปลี่ยนอะไร
