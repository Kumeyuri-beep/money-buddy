# นำเข้าจากไฟล์สำรองที่ผู้ใช้เลือกเอง (9 พ.ย. 2569)

กฎที่แตะ: R1, R15, R16 (ผ่าน `parseBackup` เดิม) · PDPA · แผน `docs/plans/2026-11-09-import-file.md`

## สิ่งที่ทำ
- การ์ด "มีไฟล์สำรองอยู่แล้ว?" ใต้ฟอร์มหน้าตั้งต้น (แสดงเมื่อสมุดออนไลน์ว่างเท่านั้น): เลือกไฟล์ -> ตรวจทั้งไฟล์ -> นำเข้าธุรกรรมเดียว -> ตารางเทียบยอดต่อบัญชี -> ติ๊กยืนยัน -> เริ่มใช้งาน
- `readBackupFile` (src/app/importFile.ts): ตรวจขนาดจาก `file.size` ก่อนอ่านเนื้อ, ชื่อไฟล์ตัดอักขระควบคุม/จัดรูป (`\p{Cc}\p{Cf}`) และจำกัดความยาว, อ่านไม่ได้ = ข้อความไทย ไม่โยน error
- ผิดข้อใดข้อหนึ่ง = ปฏิเสธทั้งไฟล์ ไม่นำเข้าบางส่วน · นำเข้าลงสมุดที่มีข้อมูลแล้วถูกฐานข้อมูลปฏิเสธ ไม่ทับ (มีเทสต์)
- ยอดไม่ตรงหลังนำเข้า: ไม่ให้ไปต่อ มีปุ่มล้างข้อมูลออนไลน์ (ผ่าน `reset_my_ledger` ต้องใส่รหัสผ่าน)
- ย้าย `BalanceTable` ไป `ImportReportTable.tsx` ใช้ร่วมกับหน้าย้ายข้อมูล (ตรรกะเดิมไม่เปลี่ยน)
- ไม่ต้องมี migration (ใช้ `import_ledger` เดิม)

## ผลตรวจ
- **money-auditor:** ผ่าน · ยอดมาจาก domain, ไม่มีสูตรเงินใน UI · ข้อสังเกต: caption ตารางพูดถึง "ในเครื่อง" (แก้แล้ว), ขอเทสต์ -0 (เพิ่มแล้ว พร้อม 0.5 และ 1e300)
- **security-auditor:** ผ่าน ไม่มีทางข้ามผู้ใช้ (`import_ledger` เป็น invoker ใต้ RLS ใช้ `auth.uid()` ไม่อ่าน user_id จากไฟล์, คีย์ (user_id, id), advisory lock, เพดานฝั่งเซิร์ฟเวอร์ 20 MB/2000/1500/20,000) · แก้: ชื่อไฟล์ตัด `\p{Cf}` (LRM/RLM/ZW) ด้วย · ข้อความเตือนปุ่มล้างบอกว่าตัวเลขนับตอนตรวจยอด
- **design-critic:** ไม่มีตัวบล็อก · แก้: `choose()` ครอบ try/catch, เหตุผลปุ่มปิดอยู่เหนือปุ่ม, ภาษาคนแทนศัพท์เทคนิค, ตัดรายการปัญหาที่ 20, คำเตือนผูกกับปุ่มล้าง (`aria-describedby`), ปุ่มยกเลิกในขั้นไฟล์ผิด, CSS ช่องเลือกไฟล์ (ธีมมืด)

## ความเสี่ยงที่ยอมรับ / ยังไม่ทำ
- ปุ่มล้างพึ่งว่า Setup ถูก render ใต้ `DataSourceGate` (repository ออนไลน์ที่ถามรหัสผ่าน) · ค่าเริ่มต้นของ `RepositoryContext` เป็น Dexie ซึ่ง `resetAll` ไม่ถามรหัส · ตอนนี้ไม่มีทางอื่น render Setup · **ถ้าจะ render Setup นอก Gate ต้องซ่อนปุ่มล้างก่อน**
- ล้างได้ทั้งบัญชีออนไลน์ ไม่ใช่เฉพาะที่เพิ่งนำเข้า (บอกในข้อความเตือนแล้ว)
- ข้อความ error ดิบของ Postgres ผ่าน `friendly(e)`: ตอนนี้เป็นข้อความไทยที่เราเขียน ยังไม่ได้ตรวจทุกเส้นทางของ `rpc()`
- `parseBackup` เทียบ `text.length` กับ `MAX_IMPORT_BYTES` (หน่วยต่างกัน แต่ปลอดภัย)
- หลังนำเข้าสำเร็จแล้วปิดแท็บก่อนกด "เริ่มใช้งาน" สมุดจะเปิดได้เลย (ไม่มีธง pending เหมือนหน้าย้ายข้อมูล) เพราะผู้ใช้เห็นตารางเทียบยอดแล้ว
- ทดสอบหน้าจอด้วยเบราว์เซอร์จริง: **เจ้าของต้องลองเอง** (ผมไม่มีเบราว์เซอร์) · ยังไม่ทำ: นำเข้าแบบแบ่งชุด >1,500 รายการ
