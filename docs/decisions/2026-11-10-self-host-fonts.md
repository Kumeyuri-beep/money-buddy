# ฟอนต์ self-host แทน Google Fonts (10 พ.ย. 2569)

กฎที่แตะ: PDPA (ลดผู้ประมวลผลภายนอก) · CSP (docs/decisions/2026-11-09-csp.md) · ไม่แตะ money-rules

## ปัญหา
หน้าเว็บโหลดฟอนต์ IBM Plex Sans Thai จาก Google Fonts ทำให้ Google เห็น IP ของผู้ใช้ทุกครั้งที่เปิดหน้า (ระบุไว้ในนโยบายความเป็นส่วนตัวแล้ว แต่เป็นทางออกนอกระบบที่ไม่จำเป็น) และ CSP ต้องเปิดโดเมน Google 2 ตัว

## ที่ทำ
- เพิ่มแพ็กเกจ `@fontsource/ibm-plex-sans-thai` (ล็อกเวอร์ชันตรง 5.3.0, ลิขสิทธิ์ OFL) นำเข้าใน `src/main.tsx` เป็นไฟล์รวมต่อน้ำหนัก `400.css` `500.css` `600.css` `700.css` (เท่าที่ดีไซน์ใช้) ซึ่งมี `unicode-range` ของ 4 ชุดอักษร (ไทย, ละติน, ละตินขยาย, ซีริลลิกขยาย) เบราว์เซอร์ดาวน์โหลดเฉพาะชุดที่หน้าใช้จริง · ตัวอักษรนอกฟอนต์ (เช่นลูกศร ✓) ใช้ฟอนต์ระบบสำรองเหมือนเดิม
- **ข้อควรระวัง (ผู้ตรวจพบ):** ไฟล์แยกชุด `thai-400.css` / `latin-400.css` **ไม่มี** `unicode-range` ถ้านำเข้าทั้งคู่ @font-face จะทับกัน (ชุดหลังชนะทั้งหมด) อักษรไทยจะตกไปฟอนต์ระบบ จึงมีเทสต์ห้ามนำเข้าไฟล์แยกชุด
- ลบ `<link>` ของ Google ออกจาก `index.html`
- CSP: `style-src 'self'` และ `font-src 'self'` (ไม่มีโดเมนภายนอกแล้ว นอกจาก Supabase ใน `connect-src`)
- `vite.config.ts`: `build.assetsInlineLimit: 0` เพื่อให้ไฟล์ฟอนต์เป็นไฟล์จริงในโดเมนเอง (ไม่ฝังเป็น `data:` ซึ่ง CSP ไม่อนุญาต)
- นโยบายความเป็นส่วนตัว: ลบประโยค Google Fonts ออก (ต้องตรงพฤติกรรมจริง) + เทสต์ว่าไม่มีคำว่า Google

## ตัดสินใจ
1. **ไม่ขึ้นเวอร์ชันนโยบายใหม่ (ไม่มี migration):** เป็นการ "ลด" การส่งข้อมูลออกนอกระบบ ไม่ใช่เพิ่มการประมวลผลใหม่ จึงไม่ถือเป็นการแก้ในสาระสำคัญที่ต้องขอยินยอมซ้ำ (สอดคล้องที่เจ้าของเลือกไม่ขึ้นเวอร์ชันใหม่ใน decisions 2026-11-09-consent-current-only) · **ถ้าเจ้าของต้องการให้ขึ้นเวอร์ชัน:** เพิ่มแถวใน `private.policy_versions` ด้วย migration และเปลี่ยน `PRIVACY_POLICY_VERSION` (มีเทสต์กันลืม)
2. **ใช้ไฟล์รวมที่มี unicode-range ไม่ใช่ไฟล์แยกชุด:** ผู้ใช้ดาวน์โหลดเฉพาะชุดที่หน้าใช้จริง (ปกติ ไทย + ละติน) · `dist/assets` มี woff2 16 ไฟล์ (รวม ~1.2MB ทั้งโฟลเดอร์ assets แต่ส่งให้ผู้ใช้เฉพาะที่ใช้) · ยังไม่ทำ `preload` และฟอนต์สำรองปรับขนาด (ตัวเลขใหญ่อาจกระโดดเล็กน้อยตอน swap) เป็นงานปรับแต่งภายหลัง
3. **เพิ่มแพ็กเกจ npm 1 ตัว** (supply chain): ใช้เวอร์ชันที่เผยแพร่มานานกว่า 2 สัปดาห์ ล็อกตรงใน `package.json` และ `package-lock.json` · แพ็กเกจมีแต่ไฟล์ CSS/ฟอนต์ ไม่มีสคริปต์ติดตั้ง

## ผลตรวจ
ดูในคำอธิบาย PR · `npm run build` สร้างไฟล์ woff2 16 ไฟล์ (4 ชุดอักษร × 4 น้ำหนัก) ใน `dist/assets` ทุกชุดมี `unicode-range` และไม่พบ `googleapis`/`gstatic`/`data:` ฟอนต์ใน dist · security-auditor: supply chain ผ่าน (แพ็กเกจเดียว ไม่มี dependency ลูก ไม่มีสคริปต์ติดตั้ง ลิขสิทธิ์ OFL-1.1) CSP ยังรัด

## บันทึกประวัตินโยบาย
`PRIVACY_POLICY_VERSION` ยังเป็น `2026-11-09` แต่ข้อความเปลี่ยนวันที่ 10 พ.ย. 2569: ตัดประโยค "ฟอนต์โหลดจาก Google Fonts ทำให้ Google เห็น IP" (ลดผู้ประมวลผล) · ต้องพิสูจน์ว่าผู้ใช้เห็นข้อความไหนตอนยอมรับ ให้ดูประวัติ git ของ `src/domain/privacy/policy.ts`
