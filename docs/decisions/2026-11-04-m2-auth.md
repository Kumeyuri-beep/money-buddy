# M2: ล็อกอินด้วย username + password และโมเดลออนไลน์เป็นหลัก (4 พ.ย. 2569)

เจ้าของสั่งเมื่อ 4 พ.ย. 2569 · แผนเต็ม `docs/plans/2026-11-04-m2-multi-user.md` · ผลตรวจแผนโดย `security-auditor` รวมอยู่ในข้อ 4.6 ของแผน

| # | เรื่อง | ตัดสินใจ | เหตุผล / ที่ทำต่อ |
|---|---|---|---|
| 1 | โมเดลข้อมูล | **ออนไลน์เป็นหลัก** Supabase คือแหล่งข้อมูลจริง · คง Dexie ไว้จน M2-D (นำเข้า) เสร็จและเจ้าของยืนยัน | ซิงก์สองทางกับสมุดบัญชีคู่ (R16) เสี่ยงข้อมูลเพี้ยน · ผู้ใช้ใช้เว็บเดสก์ท็อปที่ออนไลน์อยู่แล้ว · ข้อเสีย: ใช้ตอนไม่มีเน็ตไม่ได้ |
| 2 | ข้อความ "local-first" ใน CLAUDE.md | เปลี่ยนเป็น "ข้อมูลเป็นของผู้ใช้ ส่งออกได้เสมอ ออนไลน์เป็นหลักตั้งแต่ M2" | เจ้าของอนุมัติ 4 พ.ย. 2569 |
| 3 | วิธีล็อกอิน | username + password (ไม่ใช้ magic link / ไม่มี SMTP / ไม่ใช้อีเมลจริง) แปลงเป็น `<username>@users.money-buddy.internal` ผู้ใช้ไม่เห็น | ไม่ต้องดูแลอีเมล · **ยังไม่ยืนยันว่า Supabase รับโดเมนนี้** → spike ต้น M2-B, สำรอง `.invalid` แล้ว `.test` (ไม่ใช้โดเมนจริง: ถ้าหลุดมือแล้วมีคนตั้ง MX อีเมลกู้รหัสจาก Dashboard จะไปถึงเขา) |
| 4 | การสมัครและรหัส | ปิดสมัครเอง ปิดยืนยันอีเมล ปิด anonymous/phone/provider อื่น รหัสขั้นต่ำ 10 ตัว เจ้าของสร้างบัญชีเอง | ผู้ใช้ ≤ 20 คน เชิญเท่านั้น |
| 5 | ล็อกอินครั้งแรก | บังคับเปลี่ยนรหัส **ที่ฝั่งเซิร์ฟเวอร์ (RLS)** ไม่ใช่แค่หน้าจอ · ธงอยู่ใน `profiles` default true · ไม่มีแถว = เข้าไม่ได้ | ผลตรวจ: ธงใน `user_metadata` ผู้ใช้แก้เองได้ และถ้าไม่มีแถวต้องไม่ผ่าน |
| 6 | ลืมรหัส | สคริปต์ `reset-password.mjs` รันในเครื่องเจ้าของเท่านั้น อ่าน service_role/secret key จาก `<admin-env-path>` (นอกโปรเจกต์) ห้ามแสดง/ log ค่า key ห้ามอยู่ในโค้ดเว็บ | ไม่มีอีเมลจึงกู้เองไม่ได้ · ลำดับ: เพิกถอน session → ตั้งรหัส → ตั้งธง → อ่านกลับตรวจ |
| 7 | PDPA | คงหน้ายินยอม ส่งออกข้อมูล ลบบัญชี (M2-E) | |
| 8 | ตรวจช่วงปลอดภัยก่อน M2-C | Ticket **M2-pre**: `periodTotals`, `cashBalance`/`netWorthAt`, `incomeChannels`, `runwayTenths` โยน `RangeError` + จับที่ `LedgerView` | ต่อจาก `2026-11-04-balance-range.md` ข้อ 4 |
| 9 | R15 ฝั่งเซิร์ฟเวอร์ | **แนะนำ** ย้ายกฎเป็น CHECK/trigger บนตาราง (ไม่ใช่แค่ใน RPC) เขตเวลา `Asia/Bangkok` — ตัดสินสุดท้ายตอน M2-A | policy `FOR ALL` เปิดให้เขียนตารางตรงผ่าน REST ข้ามกฎใน RPC ได้ |

| 11 | กฎ deny ใน `.claude/settings.json` | เพิ่ม `Read(./.env*)`, `Read`/`Edit`/`Write` ของ `~/.money-buddy-admin/**` และคำสั่ง Bash/PowerShell ที่อ่าน/คัดลอกไฟล์เหล่านี้ (เจ้าของอนุญาต 4 พ.ย. 2569) | ผลข้างเคียง: `grep`/`cat` ที่มี `.env` ในอาร์กิวเมนต์ถูกบล็อกด้วย · กฎจับจากข้อความคำสั่ง กันไม่ครบทุกรูปแบบ (เหมือนกฎ git push) |
