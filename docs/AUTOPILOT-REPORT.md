## ตัดสินใจเองไปแล้ว (พร้อมเหตุผล)
- สิทธิ์ Supabase ใส่แค่ 4 เครื่องมือ: ชื่อ `get_logs` ไม่มีแล้ว ใช้ `query_logs` แทน
- รัน live-contract ซ้ำ: log เครื่องและ Supabase ช่วง 14:02–14:09 UTC ไม่มี 40001/40P01/deadlock (ตรงเงื่อนไขที่เจ้าของให้รันซ้ำ)
- ตลาด `AMEX`/`OTC` ในไฟล์สำรอง: ปฏิเสธตั้งแต่ตอนตรวจไฟล์ ไม่แปลงเป็น `OTHER` เอง (ปลอดภัยกว่า ไม่เปลี่ยนข้อมูลผู้ใช้เงียบๆ · ฐานข้อมูลไม่เคยเก็บสองค่านี้ได้)
- ข้อความปุ่มหาย: แนะการล้างข้อมูลเฉพาะเมื่อไฟล์มีสินทรัพย์ลงทุน และให้แจ้งผู้ดูแลก่อนถ้าไม่แน่ใจ (การล้างย้อนกลับไม่ได้)
- หน้า Categories ลบหมวดไม่ได้เมื่อยังไม่มีหุ้น: แก้ข้อความให้ตรงความจริงก่อน แยกการแก้หน้า Categories เป็นงานถัดไป (1 งาน = 1 PR)
- #282 ไม่แก้ข้อระดับต่ำจากผู้ตรวจ (รายการหุ้นที่แสดง `OTHER` ดิบเป็นส่วนที่หน้าปัจจุบันซ่อนไว้)
