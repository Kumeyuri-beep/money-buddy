## รอเจ้าของ (เรียงตามความสำคัญ)

ไม่มีงานเร่งด่วน และไม่มี PR ค้าง

1. **ลองบนคอม (บัญชีทดลองเท่านั้น):** เปิดสองแท็บ แท็บที่สองออกจากระบบแล้วเข้าอีกบัญชี กลับแท็บแรกสั่งล้างข้อมูล ต้องขึ้นว่าบัญชีเปลี่ยน ไม่มีอะไรถูกลบ
2. **ภายหลัง:** อนุมัติ migration ถอนสิทธิ์ฟังก์ชันเดิม (ไม่มี `_as`) หลังเว็บรุ่นใหม่ใช้งานสักระยะ · ระหว่างนี้แท็บที่เปิดค้างจากรุ่นเก่ายังเรียกทางเดิมได้จนกว่าจะรีเฟรช
3. **เลือกว่าจะทำไหม:** ครอบทางบันทึกรายการ บิล การลงทุน และค่าตั้งค่า ด้วยการตรวจผู้ใช้แบบเดียวกัน (ต้องมี migration)
