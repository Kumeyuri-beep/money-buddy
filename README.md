# Money Buddy Pro 2.0

สถานะ: **M0 (ฐานราก)** เสร็จแล้ว

| ส่วน | สถานะ |
| --- | --- |
| ไลบรารีเงิน (สตางค์, ปัดเศษ, micro-units ด้วย BigInt) | เสร็จ พร้อมเทสต์ |
| สมุดบัญชีคู่ (Entry/Line, ยอดคงเหลือ, รายรับรายจ่ายไม่นับซ้ำ) | เสร็จ พร้อมเทสต์ |
| Integrity Check | เสร็จ พร้อมเทสต์ |
| หน้าจอ "วันนี้" แบบ Glassy (ข้อมูลตัวอย่าง) | โครงขั้นต่ำ |
| CI (GitHub Actions) | เสร็จ |
| ที่เก็บข้อมูลถาวร (IndexedDB ผ่าน Dexie) พร้อมสำรอง/ล้างข้อมูล | M1-A เสร็จ |
| หน้าตั้งต้นใช้งานครั้งแรก (ยอดยกมา) และหน้าวันนี้อ่านข้อมูลจริง | M1-A เสร็จ |
| บันทึกรายจ่าย/รายรับ/โอนเงิน พร้อมปุ่มเลิกทำ | M1-B1 เสร็จ |
| หน้า "รายการ": ค้นหา กรอง แก้ไข ลบ พร้อมเลิกทำ | M1-B2 เสร็จ |
| พิมพ์สั้นๆ (Quick Text), สแกนสลิป | M1-B3, B4 ถัดไป |

## เริ่มใช้งาน

```bash
npm install
npm test
npm run dev
```

## ขั้นต่อไป (M1)

บัญชีและกระเป๋า, เพิ่ม/แก้/โอนรายการ, Quick Text, OCR สลิป, ที่เก็บข้อมูล IndexedDB (Dexie)
อ่านรายละเอียดทั้งหมดใน `CLAUDE.md` และ `docs/`
