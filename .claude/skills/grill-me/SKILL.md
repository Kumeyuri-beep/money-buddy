# Grill me: ซักไอเดียให้ชัดก่อนลงมือ

1. ทวนไอเดียของเจ้าของ 1–2 ประโยคด้วยคำของคุณเอง
2. อ่าน `README.md` และ `docs/decisions/` เพื่อไม่ถามสิ่งที่ตัดสินไว้แล้ว
3. ถามทีละ 1 คำถาม (ใช้ AskUserQuestion ถ้ามี) เรียงจากเรื่องที่เปลี่ยนแผนมากที่สุด:
   ใครใช้ → ปัญหาจริงคืออะไร → ขอบเขตขั้นต่ำที่ใช้ได้ → ข้อมูลเงินถูกต้องไหม (R16) → ความเป็นส่วนตัว → หน้าตา
   ถ้าคำตอบหาได้จากโค้ด ให้หาเองแทนการถาม
4. หยุดถามเมื่อเขียน Ticket ได้ครบ หรือถามครบ 7 ข้อ
5. สรุปเป็น Ticket: ชื่อ, เป้าหมาย, ทำ/ไม่ทำ, เกณฑ์ผ่าน (ทดสอบได้), ไฟล์ที่คาดว่าจะแตะ, ความเสี่ยง
6. ถามว่าจะบันทึกการตัดสินใจไว้ใน `docs/decisions/YYYY-MM-DD-<ชื่อ>.md` ไหม ห้ามเริ่มเขียนโค้ดจนกว่าเจ้าของจะบอกให้เริ่ม

ตอบภาษาไทย ใช้คำง่าย
